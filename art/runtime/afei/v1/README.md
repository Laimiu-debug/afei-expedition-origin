# 阿飞分层游戏美术 v1

日期：2026-09-26。用途：PC 原版《战场兄弟》＋官方 DLC 的美术接入与测试。正常、蛤蟆人、嘉豪三套基础造型，飞碟为独立头顶装饰。**当前仅为格式与静态验证通过的试验包，美术验收未完成；本轮未启动游戏，实机外观与存读档均未验证。**

## 使用入口

- [美术试验包 mod_afeix_art_v1.zip](dist/mod_afeix_art_v1.zip)：ZIP 根目录含 brushes、gfx、scripts；用于后续接入检查，不能视作已通过美术验收的发布包。
- [安装与代码接入](INTEGRATION.md)：依赖 Legacy Modding Script Hooks；手动新建“阿飞美术验收（测试）”起源查看四形态。
- [图层与装备对照](build/preview/index.html)：本地离线预览，使用导出的真实图层和坐标，不是游戏截图。
- [构建检查记录](build/report.json)：导出尺寸、锚点、原图校验值、打包解包比对和 ZIP 信息。
- [完整生图提示词](PROMPTS.md)与[机器可读生成记录](generation-prompts.json)：14 张原始透明 PNG 全部保留。
- [导出清单](manifest.json)与[16 个游戏精灵 PNG](sprites/)：可继续调整锚点和重新打包。

## 对旧版的改进

旧版将完整人物胸像放在 body 层，同时隐藏 head、hair、armor 和 helmet。这里将头与基础衣装分开；头盔、护甲、升级附件、武器盾牌仍由原版控制。穿上装备后，基础衣装被覆盖是预期行为。不是把三张大图缩小后称作全部适配完成。

- 人类头保留斜眉、低眼睑与轻微歪嘴笑；使用原版短侧分黑发，戴盔时沿用原版显隐。
- 蛤蟆头保留宽嘴、眼眶与浅色下颌，收短喉部；独立身体有小片护肩。
- 嘉豪身体保留短立领、棕色皮甲、暗红披肩边，正常和嘉豪共用同一张人类脸。
- 飞碟使用单独画刷；正常与飞碟测试形态不会因为新增飞碟而缩放整个人物。
- 补绘闭眼倒地头、三套倒地身体、两级蛤蟆头伤痕和一张共享身体血污。死亡图不再复制站立图，受伤层不再为空白。

## 资源组成

| 内容 | 画刷数 | 说明 |
| --- | ---: | --- |
| 人类、蛤蟆活头和死头 | 4 | 共享人类头用于正常／嘉豪／本轮飞碟测试 |
| 三套活身体和倒地身体 | 6 | 普通、蛤蟆、嘉豪分别制作 |
| 身体受伤覆盖 | 3 | 三个游戏资源名有意共用同一张透明血污，叠加在基础身体上 |
| 蛤蟆轻／重伤覆盖 | 2 | 与身体分离，不涂满或替换整张脸 |
| 独立飞碟 | 1 | 生前附加，死亡消失 |

人类头发、头部血污、装备和原生伤势特效直接引用游戏内画刷；这些原版资源不装进发行 ZIP。原图生成使用内置 image_gen，导出脚本只进行透明边裁切、等比缩小、画布定位和图集打包。

## 重建

仓库需要完整的 Git LFS 旧工程归档。旧 I 盘在本轮打包期间不可访问，因此已经从保存的归档恢复构建工具与原版检查素材到忽略目录 `.cache/afei-art/`。

在仓库根目录，使用已安装 Pillow 的 Python：

```powershell
python tools/restore_afei_art_tools.py
python tools/build_afei_art.py
```

恢复脚本只提取构建工具、原版图层检查资料与原来已保存的少量反编译资料；不写游戏安装目录。新资源名采用 `afeix_v1_`，保留旧归档与前一轮概念母图。

## 验收范围

构建验证透明通道、16 个画刷名称、坐标和打包解包的 RGBA 像素一致性。接入脚本另做 Squirrel 语法检查。这些结果证明资源格式和静态接入检查通过，不代表图层造型已验收，也不能替代启动游戏后的运行验证。

当前离线图层检查已发现两项未修复问题：

- 人类倒地头与原版 `hair_black_02_dead` 的方向不匹配，叠加后头发遮挡脸部；正常、嘉豪及本轮飞碟测试形态共用此组合。
- 蛤蟆活头与身体衣领的接缝仍需调整，当前存在头颈衔接空隙；相关头部伤痕位置也需随最终方案复核。

因此当前 ZIP 保留为试验记录。先研究其他起源的美术组织与接入方式，再确定修正方案；本次状态收尾没有修改图片、锚点或包代码。

仍需实机查看：宽蛤蟆头与各类头盔、头顶飞碟在名册与状态标记附近的裁切、永久伤势／碎头／断头特效、战斗翻转、读档和昏迷恢复。测试起源不包含正式转职技能、六根任务或十人编队规则；美术试验包不代表这些玩法已实现。

## 验收边界

- 正常形态 v02 保留短黑发、斜眉、低眼睑、轻微不对称的闭嘴笑、灰米棉甲和黑色短披肩，较 v01 明显减少纹理。用户对方向反馈“不错”，不等于已确认全部细节或实机效果。
- 当前检查了大图内容、构图和透明通道，并提供浏览器缩放观察页；原尺寸与原版角色的严格并排、灰度辨识、装备遮挡与游戏内融合度仍未验收。
- 飞碟图是一次生成编辑的整体预览，主体像素与画布并非和嘉豪原图完全相同；不能从这张图宣称已实现独立叠层。右侧轮廓少量像素触边，正式制作用图需重新检查留白。
- 旧工程的 114×142 整体胸像会隐藏头、头发、护甲与头盔层；不能只把母图缩小就视为支持换装的新资源。说明见 [旧素材索引](../../../docs/art/legacy-asset-index.md)。
- 确认造型后，再确定图层坐标、画布、受伤与死亡表现，最终进入游戏验证。

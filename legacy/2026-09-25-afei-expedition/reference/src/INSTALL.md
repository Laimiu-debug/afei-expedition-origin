# 安装说明 · 大飞午远征团（`mod_afei_expedition`）

面向玩家的安装与上手指南。设计与规则细节见 `README.md`。

## 需要

- 《战场兄弟》（Battle Brothers）**1.5.2.3**（Steam / GOG 均可）
- **Legacy Modding Script Hooks**（俗称 `mod_hooks` / “Battle Brothers Modding Script Hooks”），先于本 MOD 安装

不需要 Modern/MSU；本 MOD 未在 MSU 环境下测试，不建议混装。

## 安装步骤

1. **先装 mod_hooks**：按其自身说明安装。
2. **再装本 MOD**：将完整的 `mod_afei_expedition.zip` 放入游戏的 `data\` 目录，**不要解压**。最终目录结构如下：

   ```
   Battle Brothers\
   └─ data\
      ├─ <mod_hooks 的安装文件>
      └─ mod_afei_expedition.zip
   ```

   Steam 默认路径示例：`C:\Program Files (x86)\Steam\steamapps\common\Battle Brothers\data\`
   GOG 版同理，定位到游戏安装目录下的 `data\`。

3. 启动游戏，**开新战役**，在起源（Origin）列表中选择 **「大飞午远征团」**。

## 快速上手

- **三队长开局**：阿飞（固定团长，不可解雇）、抹茶、王大谋；阿飞初始偏弱，成长线见人物页。
- **伙伴会主动找你**：新的主线节点、到期的成长回访、循名而来的候选伙伴，都会以对话事件找上门；想主动办理时按 F8 翻开黑旗名册。
- **第 1 日**：开场对话后可接一份**可拒绝的安全送账**委托（报酬 180 克朗，计 1 份有报酬契约），完成后瓶队小酒瓶会找上门来。
- **世界地图按 F8** 打开「黑旗名册」：查看招募日志、驻营管理、代理队长指定与个人成长进度。
- **招募节奏**：按日期与已完成的有报酬契约数逐步迎来新的伙伴；线索出现后候选人会一直保留，不会因缺钱或满员消失。
- **阿飞饰品**：电子烟（战斗中回血 20，每回合一次）；自行车——小酒瓶会在阿飞完成个人成长或第 60 日找你夜话，选择放手后经「回马灯」可决定遗弃自行车，换取阿飞经验获取 ×1.5（全战役一次）。

## 已知限制

- 数值为设定稿首轮设计值，**实机平衡仍在验收中**；遇到明显过强/过弱欢迎反馈。
- 必须新开战役才能选择本起源；不支持中途加入已有存档。

## 卸载

删除 `data\mod_afei_expedition.zip` 即可。基于本起源的存档在卸载后不建议继续游玩（技能与事件均来自本 MOD）。

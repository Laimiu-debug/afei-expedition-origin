# 斗鱼剧情杀实机边界测试

仅本地开发测试，不进入主包。先备份存档，退出游戏后安装主包和此测试ZIP。

在阿飞起源世界地图按F6，直接进入第四幕；这会在测试战役中修改梦境进度并产生幕前自动存档。F7仅用于强制斗鱼原生死亡，验证提前击杀后仍发生全队剧情杀；这不能证明正常战斗难度或现实战的胜率。F9跳过玩家行动，将回合交给原版斗鱼AI，验证预警、攻击与第四轮剧情杀。普通菜单撤退也应接入同一结局。

F10开启完整原生对战：仅取消梦境的三轮限制，让现有十名11级传奇配装角色由原版角色AI行动。斗鱼、人物、装备、命中、AP、疲劳与死亡数值均不重设；回合与胜负写入日志。测试不是现实战役通关，不能以一个AI样本推断玩家胜率，且没有验证原生AI是否合理使用所有专属技能。第30轮停止仍未结束的测试。

F12在下一名临时角色的原生回合开始回调结束时强制其死亡，再配合F9推进；只用于重现并验证回合条的死亡锁修复，不能计入正常战斗伤亡。应出现`TURNBAR_RECOVER`，随后仍推进至第四轮梦醒。F10完整对战不得同时使用F7或F12。

日志应出现 `REALITY_RESTORED=true roster=3 status=complete`。比较现实三人的等级、经验、生命、疲劳、装备ID和耐久，以及资金、工具、药品、弹药。剧情杀后继续阅读梦醒与启程，再确认世界地图能正常操作。测试结束后退出游戏，移除测试ZIP，并按字节还原备份存档。

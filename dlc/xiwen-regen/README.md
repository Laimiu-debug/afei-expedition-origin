## 本版内容

- **希文**：独立可招募角色，归入「DLC同行者」。第 35 日起，参战历史最高值 ≥14、非送信付费履约 ≥5、不同合格城镇 ≥6、历史最高等级 ≥5 全部满足后，进入主包现有招募队列，在原版招募界面雇佣；沿用三个候选位、轮换与刷新间隔。补级上限 2 级，入队等级 2，基础报价 590 克朗；一级日薪 9 克朗，2级按原版增长为9.9。最终报价受城镇倍率影响。第35日是最早入池日，不保证立即轮到；补级不赠个人战斗记录。
- 轻装剑盾配装：短剑、小圆盾、厚布衣与**希文的圆圆化妆镜**；生命 52、疲劳上限 97、本体决心 21、先攻 111、近攻 51、远攻 36、近防 4、远防 3；近攻二星、先攻二星、近防一星，固定原版特质为聪慧、健步如飞。镜子仅希文装备时决心 +20，因此一级戴镜决心 41；无负重、不可出售。
- 7 级从《识隙札记》《同行守则》《长路笔记》中三选一，对应看清破绽、同行照应、行路留力；11 级精通已选方向，不占普通专长点。运行规则与主包一致，详见 [V2.2招募与培养](../../docs/design/balance-v2/V2.2重甲与招募.md)。
- 希文有专属背景、三级且参战三次后开启的两选一个人成长，以及富足退隐、清贫退隐、阵亡纪念文本。头像按用户提供的三张照片原创绘制，已导出身体、头部、完整胸像与尸体头部四个画刷。
- **战犬里根儿**：阿飞的战犬里根儿。赶路时爱绕着队伍撒欢，歇脚时总要挨着阿飞的靴子趴下。平日里一块肉干就能哄得尾巴打转，真有人冲向阿飞，它却比谁都先露出牙。他很怀念在环世界动物园中与飞碟一起度过的日子，一步一步，不忘来时路。
- 新建「阿飞远征团」战役后，在队伍仓库查看里根儿。战前给任一队员装备，战斗中使用原版释放战犬技能放到相邻空地，再由原版 AI 行动。存活时战后返回；放出后饰品显示「里根儿的项圈」。
- 里根儿沿用原版战犬外观、数值与生死规则，无须招募或购买，不占佣兵名额，也不另加工资。失去、售出或阵亡后不会在读档、转职、回城时重新生成。旧战役不会自动补发；请以新战役验收开局陪伴。

用户确认的是角色名字、照片参考、战犬的名字与归属、开局陪伴及分支边界。希文的属性、特质、招募条件、技能书与化妆镜已按用户确认的 V2 表格实装，照片不作为现实生平、性格或性别设定的证据。里根儿未指定犬种，因此本版复用原版战犬资源。

## 继续开发与重建

所有新增源码都在本目录 `src`，构建器只打包这里的文件。它读取传入的主包工作区，并在当前分支 `.cache` 内复制测试环境；不会改写主包、自动安装或发布。

```powershell
python dlc/xiwen-regen/build.py --base G:/CODE/afei-xcpedition
```

`--base` 需要当前 v0.26.0+ 源码、匹配的测试与原项目已有本机原版测试夹具；Git 中较老的 main 提交不满足此条件。工具包默认取 `--base/.cache/afei-art/bbros-modkit-v9/bin`，可用 `--kit` 指定；游戏目录可用 `--game` 指定。Python 需 Pillow。原版测试夹具可在相应主包工作区使用其既有 `tools/check_gameplay.py` 准备。

首版使用过忽略目录 `.cache/base-v0240` 的固定基线；当前版本不再以该旧基线构建，请使用上面的当前主包路径。

本次合并仅引入本目录新增内容，原工作区修改完整保留。可选DLC仍使用独立ZIP与构建入口；如果后续改为内置角色，需要整合加载入口和主包数据生成流程，并停用独立包以免重复登记。

# DLC：希文与里根 · 0.1.0

2026-09-28，独立开发分支 `codex/dlc-xiwen-regen`。本目录包含已实现的首版 DLC；未合并 main、未上传发布、未安装到本机游戏。

## 本版内容

- **希文**：独立可招募角色，归入「DLC同行者」。首次访问友好的非军事城镇后进入主包现有招募队列，在原版招募界面雇佣；沿用三个候选位、轮换与刷新间隔。招募费 280 克朗，日薪 9 克朗。
- 首版采用轻装剑盾：短剑、小圆盾、厚布衣；生命 52、疲劳上限 97、决心 41、先攻 111、近攻 51、远攻 36、近防 4、远防 3；近攻二星、先攻二星、近防一星。保留原版技能树，未指定新专属战斗技能。
- 希文有专属背景、三级且参战三次后开启的两选一个人成长，以及富足退隐、清贫退隐、阵亡纪念文本。头像按用户提供的三张照片原创绘制，已导出身体、头部、完整胸像与尸体头部四个画刷。
- **里根**：阿飞的狗。新建「阿飞远征团」战役时，完成三位队长创建后，直接放入阿飞的饰品栏。从开局随身携带，不需要招募或购买。战斗中使用原版释放战犬技能，放到相邻空地；随后由原版 AI 行动，存活时战后返回。平时显示「里根」，放出后饰品显示「里根的项圈」。
- 里根沿用原版战犬外观、数值与生死规则，不占佣兵名额，也不另加工资。失去、售出或阵亡后不会在读档、转职、回城时重新生成。旧战役不会自动补发；请以新战役验收开局陪伴。

用户确认的是角色名字、照片参考、狗的名字与归属、开局陪伴及分支边界。希文的职业倾向、属性、招募条件和剧情是本轮可继续调整的首版游戏设计，照片不作为现实生平、性格或性别设定的证据。里根未指定犬种，因此本版复用原版战犬资源。

## 继续开发与重建

所有新增源码都在本目录 `src`，构建器只打包这里的文件。它读取传入的主包工作区，并在当前分支 `.cache` 内复制测试环境；不会改写主包、自动安装或发布。

```powershell
python dlc/xiwen-regen/build.py --base G:/CODE/afei-xcpedition
```

`--base` 需要当前 v0.24+ 源码、匹配的测试与原项目已有本机原版测试夹具；Git 中较老的 main 提交不满足此条件。工具包默认取 `--base/.cache/afei-art/bbros-modkit-v9/bin`，可用 `--kit` 指定；游戏目录可用 `--game` 指定。Python 需 Pillow。原版测试夹具可在相应主包工作区使用其既有 `tools/check_gameplay.py` 准备。

本次为隔离并行开发，固定主包与匹配测试保存在本工作区忽略目录 `.cache/base-v0240`。复现本轮验证命令：

```powershell
python dlc/xiwen-regen/build.py --base .cache/base-v0240 --kit G:/CODE/afei-xcpedition/.cache/afei-art/bbros-modkit-v9/bin
```

之后合并 main 时，只需审阅本目录的新增内容；原工作区的其他未提交改动不在这个分支提交里。合并不会自动把可选 DLC 塞入主包 ZIP，本目录仍有独立构建入口。若之后决定改为内置角色，可再整合加载入口和主包数据生成流程，同时停用独立包，避免重复登记。

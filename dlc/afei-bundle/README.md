## 安装

需要阿飞远征团主包 **v0.28.12（内部版本 62）或更新版**，以及 Legacy Modding Script Hooks。

1. 完全退出游戏。
2. 将游戏 `data` 目录内原来的 `mod_afeix_dlc_afei_voice*.zip`、`mod_afeix_dlc_afei_skins*.zip` 和旧版 `mod_afeix_dlc_afei_bundle*.zip` 移到游戏目录外。
3. 把本版整合 ZIP 原样放入 `data`，不解压。主包和整合包各只保留一个版本。

**整合包不能与原独立语音包或原独立皮肤包同时安装**，否则会加载重复的组件入口。希文与里根儿等其他 DLC 按各自安装说明保留。

## 使用

在阿飞远征团战役中打开 **F8 → 战团事务 → 阿飞外观**，点击立即换装。六套外观、恢复原有阿飞、双 CG 前后翻页、地图头像和随战役保存的皮肤选择均沿用衣橱 0.1.1。

阿飞受伤时自动播放音量增强版的五段原声，相邻两次避开重复片段。换皮肤后仍使用这些原声，原声音高与语速保持不变；其他角色、阵亡及护甲受击声音沿用原有处理。

整合包保留原皮肤旗标 `afeix_dlc_afei_skins_style`，已有选择无需转换。两个组件的原有入口与 ID 均保留在同一个 ZIP 内，兼容性身份保持原样；主包内容和版本不变。实际旧档效果仍需实机检查。

## 构建与验证

在仓库根目录执行：

```powershell
python dlc/afei-bundle/build.py
```

组件源码仍在 `dlc/afei-skins` 与 `dlc/afei-voice`，整合构建自动核验并打包两者，然后将包内文件按原安装路径放入一个 ZIP。它直接包含运行资源，不是把两个 ZIP 再套一层压缩。

当前包共 **22 个条目、6 个运行脚本、48 个皮肤画刷、两张 CG 与五段 WAV**。对主包 v0.28.13 复测后，两个组件通过 **6,617 条离线断言**；皮肤先加载和语音先加载分别通过 **6,661 条组合断言**。组合断言包含复用的主包外观回归，不按三个数字相加计算独立用例数。原有阿飞沿用主包的头发分层，六套独立皮肤保留衣橱的完整贴图。

验证覆盖两个真实组件入口的加载与重复初始化、六套外观及原有阿飞下的受伤音效、原版声音及资源预载、其他角色和起源、存读档、菜单及双 CG。两个组件的独立回归另覆盖尸体、复活、断头、装备、分页和资源回退。全项目文件路径、Mod ID 和加载依赖审计通过；ZIP 的 CRC、完整条目集合及组件资源字节一致性通过，主包 `src` 指纹保持一致。

`--check` 执行同样核验并刷新报告，不写入整合 ZIP；它仍会刷新原组件的本地包和报告。

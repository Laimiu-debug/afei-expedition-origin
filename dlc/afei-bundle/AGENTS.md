# 阿飞衣橱与哇哇叫整合包开发约定

- 本目录交付一个可选 DLC ZIP，整合 `../afei-skins` 与 `../afei-voice`，不写入主包 `src`、根版本或根 `dist`。用户没有要求安装或发布时，构建只产出本地包。
- 两个原目录是各自功能和资源的唯一源码来源。修改皮肤时遵守 `../afei-skins/AGENTS.md`；整合目录不复制一套运行源码，也不重新处理已核验美术与音效。
- 一个 ZIP 内保留两个既有 Mod ID、入口、主包依赖、画刷名、声音路径与皮肤存档旗标。不得再加整合 Mod 注册或相互加载依赖，避免重复钩子和加载环。
- 安装说明必须要求移走独立语音和独立皮肤包的所有版本，主包与整合包各保留一个 ZIP；不允许整合包与任一原独立包并装。
- 构建入口为 `python dlc/afei-bundle/build.py`；`--check` 不写整合 ZIP，但会刷新两个组件的核验包和报告。构建先验证组件，再按安装路径合并包内条目，禁止嵌套 ZIP 和条目覆盖。
- 保持组件源码、组件 ZIP 和整合 ZIP 逐字节一致，核对 CRC、条目集合、来源版本与 SHA-256。组合回归必须覆盖两个组件的两种加载顺序、重复初始化、全部外观下的声音、其他角色、存读档及双 CG。
- 实机验收与离线核验分开记录，不把资源预览叫作游戏截图，不承诺未实际测试的旧档或第三方 Mod 组合。

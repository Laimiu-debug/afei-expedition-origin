## 本版效果

- 只为「阿飞远征团」起源中身份为阿飞的角色替换受伤叫声；改名和转职仍按角色身份识别。
- 沿用游戏原有受伤音效触发时机与伤害音量变化。0.1.2提高五段音频响度，播放系数由0.85恢复为1.0；游戏音效音量设置继续生效。护甲撞击、攻击、阵亡与其他角色声音由原版处理。
- 多段原声随机播放，相邻两次避免选中同一段；只有一段时正常播放。
- 独立加载并预载音效，不新增存档技能、物品、背景或序列化字段。移除 DLC 后的实际读档和声音恢复仍需实机验收。

## 试听安装

完全退出游戏，将本 DLC ZIP 整包放进游戏 `data` 目录，保持 ZIP 原样，主包与本 DLC 各只保留一个版本。替换时先移走旧的 `mod_afeix_dlc_afei_voice.zip`，避免与带版本号的新包并装。它依赖主包 v0.26.2（内部版本 36）或更新版，当前离线核验基线为主包 v0.28.11。本机游戏正在运行0.1.0，本次未覆盖运行中的旧包，退出后才能替换。

本版仅改声音，不新增存档类；撤下 DLC 的实际读档仍需验收。按项目约定先用新建战役检查，尤其确认受击叫声触发、音量、底声及其他角色的原声。

## 独立检查与打包

在仓库根目录执行：

```powershell
python dlc/afei-voice/build.py --check
```

检查器只读取主包和本机原版游戏资源，编译本 DLC 脚本，并使用原版人类播放函数与角色资源预载函数做隔离回归。结果写入本目录 `report.json`；不修改主包源码或 ZIP。

执行 `python dlc/afei-voice/build.py`，输出 `dist/mod_afeix_dlc_afei_voice v0.1.2.zip`。没有登记声音时，打包器会拒绝生成空音效包。包内路径必须与主包完全无冲突，完整条目集合、CRC 和源码字节一致性均需通过检查。

需要重新裁剪这两段原视频时，执行 `python dlc/afei-voice/tools/prepare_clips.py`。默认读取工作区的冰牛完整视频和 `哇哇叫.mp4`，也可用 `--source`、`--short-source` 指定路径；需要 FFmpeg（可用 `--ffmpeg` 指定）。工具核对原视频校验值后重建 5 段 WAV、试听连播和音效列表，仅写入本 DLC 和忽略的 `.cache` 目录。

本轮原视频已不在工作区，使用留档原声包复现音量调整：

```powershell
python dlc/afei-voice/tools/prepare_clips.py --from-original-package 'dlc/afei-voice/dist/mod_afeix_dlc_afei_voice v0.1.0.zip'
```

工具先核验0.1.0包和每段原声的校验值，再提高响度。调尖试验版0.1.1未作为本版来源。官网本轮只确认版本、说明和下载链接，按用户要求不再下载公开ZIP检验本地包一致性。

打包器不安装、不发布。最终还需在游戏中检查阿飞受伤、其他成员受伤、护甲受击、转职、存读档，以及撤下 DLC 后恢复原声。

## 安装和使用

需要阿飞远征团 **v0.28.12（内部版本 62）或更新版**，以及 Legacy Modding Script Hooks。完全退出游戏，将 ZIP 原样放进《战场兄弟》的 `data` 目录，主包和本 DLC 各只保留一个版本，不解压。

在阿飞远征团战役中打开 **F8 → 战团事务 → 阿飞外观**。点击皮肤名称立即切换，留在当前页，不收费、不再确认；每页三款，点击“下一页”继续。可在任意页查看胡雪儿 CG，并返回原来的皮肤页；按 Esc 沿用主包的安全关闭流程。

选择随战役保存，人物栏、战斗胸像和行走时的地图小头像会使用所选外观。扎营仍显示原版帐篷。实际护甲、头盔和武器照常覆盖胸像；想看清造型，可在战团事务中隐藏全队头盔。阿飞的转职路线与外观选择互不覆盖。

胡雪儿 CG 为**衣着遮盖、倒地受伤的普通战斗败北插画**，作为名册画廊资源手动查看。本版不自动触发战败事件，也不修改战斗结算、死亡、俘虏或奖励。早期坐姿图 `art/sources/huxueer-defeat.png` 仅为弃用草稿，不进安装包。

## 兼容与卸载

只作用于阿飞远征团起源中身份为阿飞的在队角色；其他角色、其他起源、属性、技能、装备、费用和转职条件不变。存档只增加 `afeix_dlc_afei_skins_style` 世界旗标，没有增加存档类、物品或序列化字段。

活人存档沿用主包保存时还原原版身体的处理；读档后，在世界旗标就绪时恢复皮肤。普通倒地保留所选头像，复活沿用死时外观；断头走主包已有的原版安全回退。已产生的尸体使用的 DLC 画刷不会被自动替换。

卸载前建议选择“原有阿飞”并保存，然后退出游戏撤下本 DLC ZIP。卸载后的主包忽略 DLC 旗标并恢复原有入口；已有尸体、已复活单位或未知第三方 Mod 的实际卸载读档，仍需游戏验收。

## 构建和核验

在仓库根目录运行：

```powershell
python dlc/afei-skins/build.py
```

构建复用仓库已有透明胸像导出器，生成每套头、身、完整胸像、倒地头部、三档倒地伤势和地图头像，共 **48 个画刷**。每个图集精灵打包后重新解包，逐像素和逐锚点比较。安装包包含生成美术与运行脚本，不包含用户原照片、原版装备图、测试图或生成提示词。

当前通过 **4837 条离线断言**，覆盖主包外观回归以及 DLC 点击、分页、存读档、职业、其他角色、缺失资源回退、复活、未戴盔断头、地图扎营和卸载回退。三个运行脚本编译通过；与主包、希文/里根儿、语音和事件 DLC 的文件路径、画刷 ID、Mod ID 和存档旗标未发现冲突。加载关系只为主包 → 本 DLC，不依赖兄弟 DLC。

ZIP 的 CRC、文件集合和源码字节一致；构建前后主包 `src` 指纹一致。上述均为离线检查，**尚未安装或实机验收**。

实机待验收：新战役和旧档六套切换、隐藏/恢复头盔、F8/Esc 和画廊返回、换甲、受伤与战后结算、普通死亡与未戴盔断头、复活、地图移动/扎营/存读档，以及实际安装的第三方 Mod 组合。

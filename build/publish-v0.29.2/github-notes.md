# 阿飞远征团 v0.29.2

酒馆剧情更稳：进酒馆后的剧情相遇会等对话框动画放完再弹（最多约 5 秒），不再因为动画慢一拍漏掉，也不会叠出旧弹窗；在友好城镇的酒馆里，城外有敌人也能看交谈记录、做个人成长和根脉剧情的选择；剧情被打断后，在酒馆里按 F8 直接回到那段剧情。另外删掉梦里阿飞那句“三、二、一，放轻松”，抹茶的回话改成“说得轻巧”。

剧情走向、数值、费用和触发条件不变。151 份脚本、46,736 条离线断言和 332 个包条目检查通过；酒馆弹窗时序和新文本还没在游戏里实机验收。装了 0.29.1 的直接替换主包，存档兼容。

安装：退出游戏，把完整的 mod_afeix_expedition.zip 放进 data，不用解压，只留一份主包；可选 DLC 另装。

# 原画脸与头发分层

保留 `portraits-v05` 全部原画像素，按 `contours.json` 的114×142坐标轮廓分离脸、颈部、头发与衣服。主包34人中，小龟禁戴头盔，其他33人各生成7个画刷：裸脸、裸身、头发，以及4种裸脸尸体/伤口状态。原完整贴图留作资源缺失和可选DLC外观的回退。

v0.28.14 修正浅帽下额头被切空的问题：脸层保留帽沿开口内的原画短刘海，不生成原画中不存在的秃头皮肤；外侧头发和逐人描出的长发尾进入头发层，脸颈与衣领不再按共用衣服多边形归入头发。其余衣服像素回到身体层，位于原版护甲下面。`guards.json` 独立记录额头、脸、颈部、衣服和发尾的像素检查点，避免仅凭裸头像素还原通过就判定戴帽正常。

运行 `python tools/build_helmet_layers.py` 重建分层、图集和装备预览；完整资源构建也会调用此工具。运行 `python tools/check_gameplay.py` 校验实际 `src` 图集、原画哈希、裸头合成像素与原版锚点。

`sprites`、`package` 和 `build/report.json` 保存生成结果；`pack` 与 `build/roundtrip-*` 是可重复生成的临时目录。运行时使用原版 `hair` 图层与 `HideHair/HideHead/IsHidingHelmet`，保存及断头前恢复原版头发，戴盔尸体选择去发的对应伤口贴图。可选DLC独立美术不在这套轮廓中。

装备预览是离线合成，保存至 `build/helmet-fix-20261002/review-1.png` 至 `review-5.png`，覆盖全部33人；各列为兜帽、绗缝帽、鼻盔、全罩盔、恢复头发。具体头盔、战斗/人物界面和存读档仍需实机验收。

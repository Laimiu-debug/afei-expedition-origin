# v0.20.0：随机事件第二批

日期：2026-09-27。基于当前 v0.19.1，新增 **10 个可重复事件、30 个选项及各自后续**。本批为“继续添加随机事件”要求下的原创扩写，沿用现有人物性格；完整旅途对白合计 32 段、75 个选项，见 [从实际脚本导出的对白](design/encounter-dialogues.md)。

## 触发与结算

- 只在阿飞远征团起源、第 3 天起进入原版事件池。世界地图附近存在敌军、战斗中或正要进入战斗时不触发。
- 行军事件要求队伍正在移动且不在安全管理地点；营地事件要求安全扎营或友好城镇附近；抹茶查账只在友好城镇附近出现。出场人物必须仍存活在册，包含预备队。
- 继续共用普通相遇的 **1.5 游戏天间隔**，每个新事件另有 8～10 天冷却。冷却结束恢复抽选资格，不保证按时弹窗；伤后提示、待领补给、首购和已开放人物续篇保留原有优先级。
- 原版弹窗会暂停移动和扎营，选择时只重新检查安全、人物和资源，不因弹窗暂停而取消选项。金钱不足或当事人已离队时不结算；失败页保留其他选项及结束谈话按钮。
- 全队心情只影响当前存活在册者，包括普通佣兵和预备队；个人心情只影响选项标出的角色。心情沿用原版恢复机制。
- 工具和药品按原版公共储备容量完整发放，保留小数储备；装不下不发部分奖励、不扣交换费用、不消耗该事件结算凭据。可改选或退出后等待再次相遇，本批不新增待领取包裹。
- 成功选项（包括拒绝）才开启共享及单事件冷却。同一弹窗重复点击不再次领奖、扣款或改变心情。

## 存档、文档与交付

新增事件复用世界存档标记中的冷却和结算凭据；旧档没有对应标记时按默认未触发处理，不要求重开战役，不重置原剧情。存档结构版本仍为 8，Mod 内部版本升为 22，包版本为 v0.20.0。

34 人名册、40 人容量、最多 10 人出战、7 级三选一及 11 级精通规则沿用现版。本批没有新增招募角色、六根门槛或美术资源。

源码入口为 `src/scripts/mods/afeix/ideas_random.nut`，通过真实预载入口接入现有事件调度。对白审阅页从同一批数据导出，也列出各段人物、地点、冷却和权重，避免设计文案与游戏运行内容分成两份。

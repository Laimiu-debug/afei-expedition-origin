# 水友三派与儿飞派“六根”隐藏支线

日期：2026-09-25。状态：用户方向已记录，具体事件和数值讨论中；未实现代码、未生成图片。

## 已确定的内容

- 用户将阿飞的水友群体分为保飞派、儿飞派、倒飞派，希望三派通过代表人物参与游戏。
- 儿飞派水友代表：**小原大人、哈曼卡恩、四哥**。
- 加上已有主播人物 **可可、溺水小龟、余初九**，构成六人“六根”。
- **六个人各自的隐藏支线都触发后，激发隐藏转职“飞碟”。**
- 这里严格记录用户的“触发”，不擅自改成六条全通关、六人同时在队、六人一起出战或必须无伤存活。
- “飞碟”是用户指定的准确名称，不自动改写为其他谐音名。
- **飞碟外观已确认：在人物头顶加一个飞碟。**保留人物主体；悬浮距离、颜色与大小为后续美术提案。

三派所属来自用户的游戏创作要求；本文件中的剧情、职业、行为与美术提案不作为现实人物性格或经历的认定。

## 三派怎样参与（助手提案）

先让水友代表成为有名字、反复出场、有个人支线的营地或城镇联系人。是否可招募、能否参战另议；不因为添加剧情人物就自动增加出战人数。

| 派别 | 可讨论的游戏参与方式 | 代表名单状态 |
| --- | --- | --- |
| 保飞派 | 战后慰问、补给援助、替队伍介绍委托；帮助带有明确来源与有限成本 | 待用户指定，不编造姓名 |
| 儿飞派 | 熟人互动、个人请求、队内外相互呼应的隐藏支线；六根共同关联阿飞的秘密转职 | 已指定六人，见下表 |
| 倒飞派 | 发起挑战、质疑战报或提出赌气式委托；完成后也可获得认可与收益 | 待用户指定；不直接当作永久敌对势力 |

三个派别都可以产生有用内容与不同笑点。暂不加入强制选边、好感条或互斥阵营锁，也不把保飞派当作永远正确、倒飞派当作只能消灭的敌人。

## 六条支线怎样触发（入口提案）

六个人各有自己的事件，玩家能感受到他们对队伍的具体影响。暂不把六根指定为六个身体器官、六件装备或六项固定属性；这些象征是否采用需另议。

下表只是六种入口的讨论素材，不视为人物已经确定的性格，也不是六项额外解锁门槛：

| 人物 | 可讨论的入口 | 首次实际进入的剧情 |
| --- | --- | --- |
| 小原大人 | 在营地收到来自水友圈的口信，可主动追问寄信人 | 小原的专属会面／委托开场 |
| 哈曼卡恩 | 在友好城镇收到一份署名邀约，可约定会面 | 哈曼的专属邀约开场 |
| 四哥 | 经水友代表介绍，在酒馆留下一个可以继续追查的联系人 | 四哥的专属对话开场 |
| 可可 | 随队时出现与阿飞有关的个人话题，玩家在安全节点回应 | 可可的隐藏支线开场，区别于普通招募对白 |
| 溺水小龟 | 结合旧稿工兵／退路方向，出现一条需要专门商量的路线线索 | 小龟的隐藏支线开场 |
| 余初九 | 结合旧稿斥候方向，主动递来一份与普通契约不同的侦察报告 | 余初九的隐藏支线开场 |

建议三位水友代表提供队外入口，三位已有伙伴提供队内回应。每条支线可以有自己的选择、后续和奖励；秘密转职计数与支线完成奖励分开。

隐藏性来自线索和意外关联，入口不只靠无限刷营地随机数。已发现但暂未处理的邀请保留后续入口，不用一次关掉窗口就永久失去线索。

## 触发与解锁规则

用户规定的核心条件可直接写为：

```text
六根齐备 =
  小原隐藏线已触发
  且 哈曼隐藏线已触发
  且 四哥隐藏线已触发
  且 可可隐藏线已触发
  且 小龟隐藏线已触发
  且 余初九隐藏线已触发

六根齐备 → 解锁阿飞的隐藏转职：飞碟
```

以下为落实这一条件的技术和交互提案：

- “已触发”定义为实际进入对应专属剧情的开场，事件仅被加入待处理队列或只收到普通招募介绍不算；六个入口各计一次。
- 不依赖顺序；同一人物反复对话不能替代另一人。不额外要求同时招募、同时出战或携带六件物品。
- 支线可以继续发展，但不把“必须全部完成”暗中加入飞碟门槛。
- 最后一个标记记下后保存永久解锁状态，再在下一个合适安全节点出现揭示事件／转职入口；不是再随机抽中一次才有资格。
- 建议解锁后由玩家主动选择转职，不突然强制替换当前蛤蟆人或嘉豪技能。
- 六根触发记录随存档保存，普通转职重修不清零。读取存档或重进事件不重复发奖励。
- 隐藏线未触发前相关伙伴阵亡／永久离开时，是否提供遗留线索，需单独决定；不在未讨论前承诺总能补齐，也不通过复活复制角色来补进度。

## 飞碟与普通转职的关系

飞碟作为独立隐藏转职记录，接入 [阿飞转职结构](afei-promotion.md)。不预先要求同时掌握蛤蟆人和嘉豪，不自动继承两条路线的全部技能，也不擅自提高十人出战上限。

普通转职已有“后期可付出代价重修”的用户方向；建议飞碟解锁资格永久保留，并考虑纳入同一重修入口。飞碟的首次转职成本、等级限制、专属技能与重修细节仍待讨论，不偷偷加到“六根齐备”的解锁判定里。

两条普通路线继续可玩。飞碟可以拥有更独特的能力或组合方式，不必是所有属性全面更高的唯一正确路线。

## 美术与人物资料

- 飞碟采用头顶附加物，不另做整个人物变成飞船的造型。建议保留转职前的身体外观，头顶增加一个小飞碟；这不代表继承原分支全部技能。
- 飞碟使用《战场兄弟》的深色轮廓、概括阴影与低饱和配色。首版建议静态悬浮，随角色移动；轻微浮动或旋转留待后续决定。
- 小原大人、哈曼卡恩、四哥的种族、体形、个人标记与职业待用户提供。不能仅凭昵称套用动漫人物脸或假定外貌。
- 可可、溺水小龟、余初九增加隐藏线关联，不因此重建三个人物或预先重画其造型。
- 所有具体提示词继续只写进 [人物造型与生图提示词](../art/character-art-prompts.md)，保持《战场兄弟》的战斗胸像画法。

### 头顶飞碟的接入方案（可行性判断，尚未实现）

建议制作一张透明背景的小飞碟贴图，打包为独立精灵资源，附着在阿飞战斗实体上，设置头顶偏移。进入飞碟职业时显示，离开该职业时隐藏；解锁资格与外观显示分开保存。飞碟不占头盔装备栏，也不额外占出战席位。

依据与限制：

- [官方分层说明](https://battlebrothersgame.com/dev-blog-33-character-generation-hiring-shopping/)介绍了脸、头发、胡须和护甲独立组合的渲染结构。本机此前提取的原版 `scripts/entity/tactical/player.nut` 也能看到 `addSprite`、`setBrush`、`setSpriteOffset` 的使用；这些调用例出现在尸体处理段，证明精灵添加和偏移接口存在，不能代替活体挂层原型验证。
- [旧工程外观逻辑](../../legacy/2026-09-25-afei-expedition/reference/src/scripts/mods/afei/rules.nut) 的 `applyLook` 会隐藏原版头盔、头部和护甲层。新版需调整该逻辑，不能直接沿用后宣称换装已经兼容。
- 入场时按职业状态重建飞碟层，读档或重复刷新不得叠出多个飞碟；死亡、离队和重修时处理显示清理。
- 进游戏后校准头顶距离与绘制顺序，检查高头盔、士气／状态标记、相邻单位、不同地形高度及名册预览裁切。首版不把独立悬浮物算入受击部位或碰撞。

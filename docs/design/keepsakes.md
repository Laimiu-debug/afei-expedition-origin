# 自行车与电子烟｜v0.11

本轮按用户“做自行车和电子烟”的要求，将旧项目资源接入当前起源。下列参数为当前实现，可继续根据试玩调整。

## 电子烟

- 阿飞的专用饰品，新战役开局自动装备；旧存档读入时补发一次。如果饰品栏已占用，放入公共行囊，不替换原装备；行囊已满则在下次进入城镇时重试。
- 装备到饰品栏后获得“抽一口”：战斗中回复最多 20 生命，消耗 3 行动点、5 疲劳，每回合一次，不消耗物品。
- 满生命时不能用；其他角色不能用；放在行囊或背包里不能用；只回复生命，不修复护甲、不移除伤势。
- 冷却记在阿飞本人身上，重新装卸、换一件电子烟都不能在同一回合多用。新战斗重新计次。
- 不能出售。手动遗失或丢弃后不会通过读档、进城无限补发。
- 该效果是 Mod 中的虚构战斗能力。

## 自行车

- 小酒瓶首次加入后，公共行囊增加一辆旧自行车；它是实际物品，有旧版图标和说明，不能穿戴或出售，不提供骑乘模型或地图移速加成。
- 满仓时保留补发资格；下次进入城镇、有空位时补入。旧档若已有小酒瓶或自行车剧情记录，同样迁移一次。
- 阿飞 7 级、小酒瓶完成个人成长、两人存活在队，在友好城镇触发原有夜话。物品说明不预告离队、选择和奖励。
- 挽留：小酒瓶继续同行，车留下，不给告别奖励。
- 放手：按原有确认步骤让小酒瓶离队，原装备逐件回收入公共行囊；读过回忆后再选留下车或推下山坡。
- 留下车：保留实际物品，阿飞获得原有一次性纪念特性（决心 +4、生命 +2）。
- 推下山坡：移除实际物品，阿飞获得原有一次性告别特性（耐力 +5、先攻 +3），读档不会把车补回来。
- 继续沿用当前版本的纪念特性，不恢复旧稿的永久经验 ×1.5。物品移除或特性更新失败时撤回选择并保留物品。

复用旧项目自行车、电子烟与“抽一口”技能图标，所有像素原样保留。[美术来源与校验](../../art/runtime/keepsakes-v11/README.md)。

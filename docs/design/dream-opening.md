# 三人同梦与斗鱼终局

2026-10-03，官网试玩版 `0.29.0-preview.3`。按确认的十人、全员11级、传奇装备与《战场兄弟》风格制作，接入现实大陆据点与三件传奇掉落，并采用原版新战团教程式的故事弹窗。

## 从梦境回到黑旗

阿飞、抹茶、大谋在大陆旅途中围着营火看地图。夜里三人走进同一个梦：刀一十人已经齐聚，站位、装备与技能呈现各自成长后的样子。

新建“阿飞远征团”战役后自动出现序章。先在同一个原版事件窗口里阅读“黑旗未满”和“三人同梦”：夜营插画配阿飞与大谋头像，梦中海兽插画配阿飞与抹茶头像。按钮逐页推进，再进入梦境战斗。

梦境依次遭遇5只蜘蛛、4只恐狼、1只林德虫与斗鱼。四幕都使用原版沼泽地图模板形成独立梦沼，采用普通战线部署；每幕重新生成完整的十人和装备。前三幕获胜后继续推进；斗鱼一幕在第三轮结束时由梦潮剧情杀，全队倒下后醒来。提前击杀斗鱼、任何一幕败战或撤退，也由同一梦潮收束，不能取得梦境通关。幕间跳过保留全军覆没的结局文字，再进入启程。

梦境中的人物、装备、经验、伤亡、克朗与统计留在临时战斗里。梦醒后接回现有三人黑旗起源的原始队伍、装备、资源与世界时间，原有招募条件照常运作。

梦醒后，弹窗由“黑旗初醒”继续翻到“黑旗启程”，交代三人接下来在大陆找人、补给、组队的目标，以及F8名册、城镇招募与梦潮祭场的位置情报。略过梦境战斗先阅读剧情杀梦醒页，再进入启程页。阅读期间世界地图暂停，按Esc可暂时收起故事，不会下一帧再次弹出；F8“再赴梦潮”可继续未读页。开局页游标和启程待阅读状态随存档保留。已读后可只读回看“黑旗启程”，不启动战斗或发放奖励。

故事正文编辑入口为 `src/scripts/mods/afeix/dream_ledger.nut` 的 `opening`、`opening_dream`、`wake`、`departure` 分支。页面切换沿用原版事件按钮，插画复用原版 `event_33.png`、`event_16.png` 及本项目斗鱼图；人物头像在原生页面 `start` 回调中填入，支持旧档队长已经离队或阵亡的情况。

玩家可见的启程、名册与祭场介绍只提供背景、方位和挑战准备，不提前透露装备奖励的名称、数量或取得条件。祭场深处的秘密留待玩家亲自探索；下文奖励内容供制作与验收使用。

梦里的十人提供成长目标。现实允许自由招募、培养与选择队伍；不要求复刻梦中名单、属性或路线。大陆上生成唯一传奇据点“梦潮祭场”，可带当前队伍亲自前往挑战斗鱼，最多十二人，采用正常战斗伤亡、消耗和撤退规则。F8黑旗名册“再赴梦潮”提供邻近城镇与方向情报，“把祭场方位记在地图上”揭示并聚焦地图，随后需要正常行军抵达。地点不随队伍等级缩放，建议11级与完备配装后挑战。

现实击杀斗鱼时，按原版战利品流程掉落深渊鲨衣、断潮鱼翅、破浪鲨牙各一件。梦境没有这三件掉落，也不会影响现实击杀记录。击败后据点消失，不再生成Boss或重复发放装备；未击杀时撤退可回来再战。详见[现实据点与传奇装备](douyu-world-and-trophies.md)。

旧战役不会自动插入序章，可在F8“再赴梦潮”中主动回看。梦境战斗期间禁止保存；每幕开始前保留正常战役自动存档，读取后重进该幕。

构筑以现行V2总表为基础：十次升级、30项普通属性选择，每人10项原版天赋；天才加点单独计算。专属技能每人只选择一项并达到11级精通，阿飞使用现有晋升路线。人物起始值、固定特质和成长加成不重复叠加。

主战武器、护甲、头盔和盾牌采用传奇装备；箭袋、投掷网等用品保留原版类型。轻重甲按岗位配置，不把轻甲人物套成重甲。梦中武器数值使用稳定的原版传奇生成结果，护甲数值保持原版合法范围。

可编辑构筑：[data/dream-roster.json](../../data/dream-roster.json)。运行时：[dream_roster.nut](../../src/scripts/mods/afeix/dream_roster.nut)，运行 `python tools/render_dream_roster.py` 同步，`--check` 检查源数据与生成内容一致。

## 斗鱼：深渊之主

以斗鱼“鲨鱼君”的大眼、灰白躯干、尖牙与橙色火箭为识别点，转换成战棋里的传奇海兽。活体、尸体、事件插图和三项技能图标已经制作；采用手绘明暗、粗轮廓、旧金属与骨质装饰。原版海怪与林德虫仅作为绘画风格和图层尺寸参考，不作为新增资源分发。

品牌参考来源：[斗鱼品牌形象报道](https://dj.sina.com.cn/article/nheqixk7164641.shtml)。参考图保存在 `art/references/2026-10-03-douyu/`。生成提示和源图分别保存在 `art/runtime/douyu-v01/` 的 `prompts.json`、`icon-prompts.json`、`dead-prompt.json` 与 `sources/`。

| 行动 | 预兆与应对 |
| --- | --- |
| 撕咬 | 普通近战；用前排承接、护卫与换位管理阵形 |
| 房管点名 | 标记角色，下一次斗鱼行动时扑击；离开其三格攻击距离可避开 |
| 弹幕洪流 | 七格危险区提前一回合显示，命中最多三名仍留在区内的人；撤出区域或集中攻击打断 |
| 超级火箭 | 七格危险区提前一回合显示；撤离或累计700点实际生命与护甲伤害打断蓄力 |
| 半血组合 | 一次火箭加点名组合，仍有预告；同一目标不会被两项重复重击 |

火箭释放或蓄力被打断后，斗鱼短暂露出破绽，受到的伤害提高35%。不回血、不召唤；终局可正常击败。preview.6固定数值为4800生命、600/450护甲、9行动点，近攻110、远攻85、近防22、远防14。半血后输出提高20%，不增加行动点；组合重击仍只触发一次并避免同一目标重复受击。普通撕咬110–135，点名110–135，弹幕45–65，火箭125–155。打断门槛700按实际生命与护甲伤害合计，要求多人配合。打断后下一次斗鱼回合只用原生撕咬，随后才重新蓄力，避免集火把所有行动持续打断；9AP最多支持两次4AP撕咬，没有额外行动。破绽仍在下次自身回合开始时结束，毒、流血和正常命中判定保留。目标为10–12名11级且配装完整的队伍。配置集中在douyu_combat.nut，离线/定向实机检查不等于最终战役胜率验收。

活体刷、尸体刷与PNG已做实际封装解包，像素、锚点、资源路径和源图指纹均有校验。`art/runtime/douyu-v01/preview.png` 是离线尺寸审阅图，不是游戏截图。

## 验收边界

preview.4已实机验证新开局与原失败存档的F8入口、十人部署、移动、攻击与撤退恢复；preview.6另验证斗鱼幕略过、正常菜单撤退、第三轮结束、强制提前击杀后的全队剧情杀及无奖励剧透的启程介绍。完整原生AI对战只用于确认实际输出与可击败性，不等于玩家胜率或现实祭场战役验收。各包指纹、样本与未验收项见[试玩验收](../playtest-dream-0.29.md)和[preview.6报告](../../build/douyu-balance-0.29-preview.6.json)。离线测试另覆盖临时队伍、存档隔离、阶段推进、异常退出与Boss机制，不能代替对应实机检查。

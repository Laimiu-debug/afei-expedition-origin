陈知含不再出现在现行名单、新相遇、新招募与当前人物结局中。按用户要求，角色、剧情、技能、背景与运行时头像直接移除，不保留旧档兼容分支。历史研究与原始美术归档不进入当前游戏内容。

蓝队继续保留罗一可和刘佳俊／眼子。罗一可使用用户本人照片及“仓鼠”称呼完成头像与剧情；内部键 `xiaohani` 和旧画刷 ID 保持兼容，旧档默认姓名更新，自定义姓名保留。眼子的显示名为“眼子”，别名按用户提供的“刘佳俊”记录。

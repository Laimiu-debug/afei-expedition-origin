## 首版定位与属性（历史）

以双手锤为基础的重型破甲武器，突出第一下砸开防线的反馈。保留马踏蛤蟆造型，游戏名始终为“老马的垂直握把”。

| 属性 | 首版提案 |
| --- | --- |
| 品质／类别 | 红装，双手锤，近战武器，占双手 |
| 基础伤害 | 80～100 |
| 护甲伤害 | 225% |
| 穿透护甲比例 | 50% |
| 装备疲劳惩罚 | -18 最大可用疲劳 |
| 耐久 | 100 |
| 距离 | 1 格 |
| 基础价值 | 12,000 克朗；实际买卖价仍经过原版城镇与关系修正 |
| 技能框架 | 沿用双手锤的单体重击与范围横扫；基础参数需接入时核对本机原版脚本 |
| 单体重击目标消耗 | 6 AP、20 疲劳（未计锤专精等修正） |
| 范围横扫目标消耗 | 6 AP、30 疲劳（未计专精等修正）；维持原双手锤范围与命中规则 |
| 随机属性 | 首版固定上述数值，不再叠加一次原版红装随机增幅 |

80～100、225% 和 50% 是三个独立字段，不表示一次攻击把生命与护甲分别按完整数值各扣一遍。最终生命伤害交给原版流程；范围、命中、击退或踉跄继承哪一段原版行为，在制作时通过实际基础武器脚本锁定。

## 首版专属效果：垂直开甲（历史，当前追加30）

**推荐机制：**使用本武器的单体重击实际命中敌人、完成正常伤害后，对本次命中的同一部位再削减 **40 点护甲**。每次主动施放最多结算一次。

选择此方案的理由：高护甲伤害负责“重锤”，固定追加负责“敲一下就有破甲反馈”，不会因敌方护甲越高而凭空抹去无限护甲。这里把“破甲”明确为额外削减实际护甲；“任何目标一击全甲清零”保留为替代方案，未列入首版。

精确结算约定：

1. 先按原版单体锤击命中、部位和伤害规则结算，落空或攻击被取消时不追加破甲。
2. 读取同一命中部位的剩余护甲，削减 `min(40, 剩余护甲)`，最低为 0；命中头部只处理头盔，命中躯干只处理身甲。
3. 正常伤害后已经没有护甲，追加值为 0；剩余破甲不溢出为生命伤害，也不转去另一个部位。
4. 追加值固定 40，不再被本武器 225% 或其他护甲伤害倍率二次放大；正常部分照常受原版专精、伤势和伤害修正影响。
5. 仅限直接主动的该单体锤击；横扫、反击、借来的成员武器技能、持续伤害、盾牌损耗不触发。以后若扩展适配范围，单独明确技能白名单。
6. 目标在正常伤害中已死亡则不再追加；对没有独立护甲数值的目标只产生正常攻击效果。红装本身没有额外秒杀、流血或眩晕。

| 正常命中结算后 | 专属追加结果 |
| --- | --- |
| 躯干还剩 75 甲 | 身甲降至 35，头盔与生命不因追加而变化 |
| 头盔还剩 18 甲 | 头盔降至 0，多余 22 点不转移 |
| 对应部位已无甲 | 不再扣生命，避免对无甲目标变成固定真伤 |
| 攻击落空或使用范围横扫 | 不追加 40 点破甲 |

受击提示要区分普通伤害与追加破甲，例如“垂直开甲：躯干护甲 -40”；若只剩 18，则显示实际 -18。不可一边扣甲、一边再添加一个重复扣甲的永久 debuff。

## 商店刷新

当前接入友好城镇的集市与武器店，沿用原版商店自然补货。

- 每次实际生成／补充该店库存时进行一次 **5% 独立抽选**；同店一次库存周期最多新增 1 件，库存中仍有本品时不再追加。
- 不要求固定任务、飞碟转职、刘青松在队或特定派别声望；游戏前期也可能看见，但是否买得起由经济决定。
- 抽选结果和库存跟随该店补货周期保存。反复开关商店、走出再进入、读取已生成库存的存档不能重新抽选。
- 不额外缩短补货周期，不挤掉原版全部红装池；保留原版普通库存。
- 允许多周目、多城镇和以后补货再次买到，不设全世界唯一；同一角色不能同时装备两把。
- 已拥有后再买、卖出后买回属于正常交易，不给第二次首次购买事件奖励。
- 只在本起源新增刷新；其他起源不自动刷出。物品实体已有时按正常装备读档，不破坏存档。

5% 的含义是每次合格补货的抽中概率。20 次独立合格补货仍全部没抽中的概率约为 35.8%，所以它不是“逛 20 次店必出”。首轮试玩如稀有到难以体验，优先调到 8%，再观察；不把 5% 写成已实测的最佳值。

## 验收重点

- 双手装备占位、换装、疲劳、锤专精、AP 和疲劳消耗符合说明。
- 躯干、头部、落空、横扫、无甲、死亡与多次伤害回调都不重复追加破甲。
- 固定破甲不因 225% 再乘一次；护甲降低到 0 时没有额外生命伤害。
- 商店补货只抽一次，存读档不刷概率，满库存与已有同款按规则处理。
- 红装数值不再被原版随机红装逻辑二次放大；价格显示与实际扣款一致。
- 图标、持握、翻转、染血和装备叠加可辨认；参考海报不进入正式资源。

平衡对照使用同等级角色与同档位原版红装双手锤，分别打轻甲、重甲与无甲目标，记录平均破甲次数、击杀次数、疲劳和实际价格，完成后再定最终参数。

# 飞李不可

2026-09-30，现行规则为 v0.28.7：仅限酒馆内使用。

## 玩家用法

1. 进入城镇，点击**酒馆**。野外、扎营、城镇主界面及其他建筑均不可加点。
2. 在酒馆黑旗页面选择 **飞李不可**；也可在酒馆内按 **F8**，选择 **战团事务 → 飞李不可**。
3. 选择一名在队角色，核对页面余额和按钮上的属性变化。双攻与双防在“后四项属性”里。
4. **点击属性按钮即支付100克朗，并永久增加1点基础属性**；加点后留在当前页，可连续点击，不再逐点进入确认页。每次点击均显示结果并更新余额。
5. 想换人就点“重新选择角色”；按 **Esc** 可直接合上黑旗名册。

生命、疲劳上限、决心、先攻、近战命中、远程命中、近战防御、远程防御均可选择。开局队长、待命角色、普通雇员和已入队的 DLC 希文使用同一规则。没有每日次数或等级门槛。

费用先保留提议的 100 克朗／点。现有 Mod 送信报酬为 180～450 克朗，刀一早期收费成员的基准招募费为 410～850 克朗；玩家可以逐点调整短板，花费会与补员、装备和日常开支争用资金。作为主动选择的修改器，八项属性采用统一价格，不随角色、等级或重复次数加价。

## 属性与付款

- 加点写入角色基础属性，随后按现有装备、特质、专长、成长和路线能力计算最终面板。巨像等倍率可能使最终生命变化超过 1，但基础生命只加 1。
- 增加生命上限时保留原有受伤量；不移除伤势或疾病。天赋星数、升级待选点、等级、专长、装备和研习选择均保留。
- 浏览角色、翻页和返回不扣钱；点击属性按钮即付款。每次点击重新检查当前酒馆界面、角色、资金、属性及费用；离开酒馆、角色离队或阵亡、接战／战斗开始、加载、钱不足或属性变化都会取消本次操作。酒馆外不显示加点按钮，明确提示进入酒馆；付款结果和失败原因显示在页面上方。
- 每个页面按钮只能提交一次，成功后整页重建，显示新的数值与余额。关闭名册、返回、翻页或换人会使旧按钮失效。属性更新或付款失败会恢复原属性、当前生命和克朗。
- 加点沿用原版基础属性存档字段保存，不在读取存档时重复发放点数。基础属性的原版有符号 16 位保存上限为 32767，到达时拒绝继续付款。

## 实现与验证

业务与分页在 `src/scripts/mods/afeix/attribute_treatment.nut`，入口接入酒馆黑旗页面和战团事务。每页最多六个按钮，40 人和八项属性分别按每页四项翻页；酒馆熟人页面每页三人，为飞李不可入口保留一个按钮。

v0.28.7 按最新要求改为仅限酒馆。检查原版城镇界面的可见状态、当前建筑模块和实际城镇，避免旧酒馆记录或空模块放行；每次付款重新检查地点。专项772条断言覆盖野外、扎营、城镇其他界面拒绝、离开酒馆后的旧按钮失效、酒馆内八项直接加点及提示置顶。酒馆入口分页另有专项检查。见[v0.28.7说明](../releases/v0.28.7.md)。

历史 v0.28.6 曾允许野外加点，该地点规则已被 v0.28.7 替代。其他招募、研习、编队和剧情沿用各自规则。

v0.28.5 缩短了加点交互，并将角色编号按原样匹配，支持有符号编号。当时专项检查通过646条断言，覆盖真实事件输入下所有属性按钮的一次点击付款、连续加点、过期按钮、Esc取消、编号边界和原有属性持久化／回滚规则。旧确认页路径保留供已有事件状态使用，新页面按钮直接加点。见[v0.28.5修复与验证](../releases/v0.28.5.md)。

`tests/gameplay/test_attribute_treatment.nut` 的 406 条离线断言覆盖原版事件按钮复制与点击、40 人分页、八项属性、原版 WeakTableRef、主包／普通／DLC 角色、重复付费、取消与过期确认、安全条件、失败回滚、原版属性序列化及保存边界。功能实现阶段的全量检查通过 124 个 Squirrel 脚本、32,874 条行为断言、原版资源路径及 JavaScript 检查；名称与文案修订后重新运行既有专项检查。

# 飞李不可

2026-09-30，本地实现。

## 玩家用法

1. 到友好城镇附近，或在允许扎营且附近没有敌军的安全地点扎营。
2. 在大地图按 **F8**，选择 **战团事务 → 飞李不可**。
3. 选择一名在队角色，再选择一项属性。双攻与双防在“后四项属性”里。
4. 核对角色、属性变化和费用，确认支付 **100 克朗**。本次只为所选基础属性永久增加 **1 点**。

生命、疲劳上限、决心、先攻、近战命中、远程命中、近战防御、远程防御均可选择。开局队长、待命角色、普通雇员和已入队的 DLC 希文使用同一规则。想继续修改，可以重新选择属性，再付一次费用；没有每日次数或等级门槛。

费用先保留提议的 100 克朗／点。现有 Mod 送信报酬为 180～450 克朗，刀一早期收费成员的基准招募费为 410～850 克朗；玩家可以逐点调整短板，花费会与补员、装备和日常开支争用资金。作为主动选择的修改器，八项属性采用统一价格，不随角色、等级或重复次数加价。

## 属性与付款

- 加点写入角色基础属性，随后按现有装备、特质、专长、成长和路线能力计算最终面板。巨像等倍率可能使最终生命变化超过 1，但基础生命只加 1。
- 增加生命上限时保留原有受伤量；不移除伤势或疾病。天赋星数、升级待选点、等级、专长、装备和研习选择均保留。
- 浏览和返回不扣钱。确认时重新检查角色、地点、资金、属性及费用；角色离队或阵亡、战斗开始、钱不足或选择变化都会取消本次操作。
- 每次选择只能确认一次；关闭名册、返回或换一项选择后，旧确认失效。属性更新或付款失败会恢复原属性、当前生命和克朗。
- 加点沿用原版基础属性存档字段保存，不在读取存档时重复发放点数。基础属性的原版有符号 16 位保存上限为 32767，到达时拒绝继续付款。

## 实现与验证

业务与分页在 `src/scripts/mods/afeix/attribute_treatment.nut`，入口接入现有黑旗名册和战团事务。每页最多六个按钮，40 人和八项属性分别按每页四项翻页。

`tests/gameplay/test_attribute_treatment.nut` 的 406 条离线断言覆盖原版事件按钮复制与点击、40 人分页、八项属性、原版 WeakTableRef、主包／普通／DLC 角色、重复付费、取消与过期确认、安全条件、失败回滚、原版属性序列化及保存边界。功能实现阶段的全量检查通过 124 个 Squirrel 脚本、32,874 条行为断言、原版资源路径及 JavaScript 检查；名称与文案修订后重新运行既有专项检查。

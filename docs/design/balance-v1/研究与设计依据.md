## 2. 原版规则与资料优先级

优先级：当前实际运行的本地脚本 > 当前 Mod 数据 > 开发商机制说明 > 公开设计材料。早期开发博客可能描述旧版本，所以定量公式以本机脚本核验为准。[开发商战术战斗概览](https://battlebrothersgame.com/tactical-combat/)用于确认战斗包含双部位护甲、地形、遮挡、疲劳、士气与永久死亡；它不替代现版实现。

本次从实际 Squirrel 入口执行导出34人、96条当前技能定义，并核查92份本机原版脚本。版本入口的 `Version=31` 是内部登记数字，不等于发布版本 v0.31；当前仓库 README 标注发布版 v0.25.0。源码哈希保存在 `source-manifest.json`，原版资源来源和哈希保存在 `native-manifest.json`。原版反编译文本只保存在本地缓存，不放入设计稿或发布包。

|结论|本机来源及位置|设计影响|
|---|---|---|
|常规命中最终限制在5%～95%|`scripts/skills/skill.nut`，`getHitchance`、`attackEntity`|不能用+命中消除所有随机性；接近上限后额外命中会浪费|

|血伤与甲伤分别抽随机数|`scripts/skills/skill.nut`，`onScheduledTargetHit`|不能用一颗相同伤害骰同时计算血伤与甲伤，二者尾部风险不同|

## 3. 命中、防御和伤害应怎样计算

### 命中

简化场景里，最终命中率 `p=clamp((攻击技能值-有效防御+地形/武器/状态修正)/100,0.05,0.95)`。完整原版还有盾牌适用性、包围、远程距离、遮挡、难度等修正；此式只用于没有这些额外修正的对照。

有效防御的软上限部分为 `D_eff=min(D,50)+max(D-50,0)/2`。例如其他条件相同，65攻击打30防御为35%命中；防御提高到35会降为30%，相对受击次数减少约14.3%，不是“生存只加5%”。65攻击打65面板防御时，先把防御折算成57.5，再受最终命中下限约束。

用 `E[命中次数]=攻击次数×p` 评价持续贡献，还必须看尾部：70%命中的四次攻击全空概率为 `0.3^4=0.81%`。玩家经常打几十场、每场几十次，低概率事件并不罕见。保命机制应允许应对坏运气，不能仅对均值作保证。

### 伤害

令 `R` 为血伤骰经过攻击方修正后的值，`A` 为独立甲伤骰经过武器破甲倍率后的值，`d` 为穿甲比例，`H` 为被击中部位当前护甲。先处理受击方的血伤倍率 `m_HP`、甲伤倍率 `m_A` 和总伤害倍率 `m_T`：

```
R' = R × m_HP × m_T
A' = A × m_A × m_T
本次扣甲 = min(H, A')                 # d < 1 时
剩甲 = H - 本次扣甲
穿透血伤 = max(0, R'×d - 剩甲×0.1)
破甲溢出 = 剩甲<=0 时 max(0, R'×(1-d) - 本次扣甲)，否则0
生命损失 = 原版舍入与最低伤害规则((穿透血伤+破甲溢出)×部位倍率)
```

当 `d>=1` 时，原版走忽略护甲的分支，不扣甲。头部通常还有部位伤害倍率，钢头等效果会改变它。原版还支持固定伤害减免、直接伤害修正及技能最低伤害，因此这段易读式不应拿来覆盖完整 `actor` 方法。

例：`R=80,A=160,d=0.5,H=200`、没有其他修正，扣甲160、剩40、血伤36。若轻装血伤倍率为0.4，则血伤 `32×0.5-4=12`，不是先算36再乘0.4得到14.4。这正是结算顺序的重要性。

轻装：甲与盔的疲劳惩罚合计不超过15时，相关血伤倍率最低0.4；超过时为 `min(1,0.4+(超出15的重量)^1.23×0.01)`。武器/盾牌/包内负重不计入这条轻装甲重公式，但仍影响总疲劳和先攻。

战铸：本次受击前头甲与身甲合计 `S` 时，相关甲伤倍率 `1-S×0.0005`。300/300甲初次倍率0.7，之后随磨损变差。它没有把所有生命伤害恒定减30%，也不会保护流血/毒等所有来源。

## 4. 行动、疲劳、先攻：决定构筑能不能运行

- 常规9AP。4AP单手普攻通常可打两次；6AP双手普攻通常一击后还可移动或做3AP动作。任何返AP、免费攻击、免费换位，都比同量静态伤害加成危险。
- 原版双手锤单击基础15疲劳，专精0.75倍后向上取整为12。平地一步在探路等条件下可能只耗2疲劳，合计14，可落在15恢复以内。但被打、网缚、地形、高差、额外技能、疲劳惩罚都可能打破循环，“疲劳中性”不是永动免控。
- 双手锤专属破甲技如果耗24疲劳，即使面板伤害更高，也未必比12疲劳普通锤击适合长战。必须分别测前三轮爆发与第4～8轮续航。
- 闪避收益取决于当前先攻，先攻受装备和累积疲劳影响。高裸先攻不是整场恒定高防御。刺剑还依赖先攻与移动条件，因此本稿不给每位敏捷成员都默认算满额刺剑伤害。
- 恢复技能占整轮行动；它的价值是把未来回合从疲劳锁死中解放出来。比较恢复与支援时，要算放弃的攻击机会。
- 更换武器受AP、快速换手、双手槽位、包内重量影响。不能一边算持盾防御，一边算空副手双手握持/决斗者收益。

## 5. 早、中、晚期战术与敌人对策

|阶段/对象|先解决的问题|有效手段|常见错误|
|---|---|---|---|
|前10～20日|低命中、脆弱头部、人数不足|低价普通佣兵补线；矛剑提高可靠性；优先补头盔和50～80身甲；后排草叉；集中击杀形成士气优势|为了凑主题名单空等；低近防新兵拿双手武器裸冲；买一个昂贵成员后付不起粮钱|

|50日以后|敌人穿透、士气压制、续航与阵容针对性|成熟双手/决斗/投掷分工；保留2～4轮换；针对敌军换盾、武器和消耗品|认为一套12人能无脑打所有敌人；追求红装而无工资储备|

|古代亡灵|士气免疫、刺穿抗性、队形压迫|用合适斧锤破甲；控制接敌范围；保护长柄；根据敌种换投斧/近战|靠恐惧与狗叫当主要胜利条件；把普通弓当通用高DPS解法|

|地精、远程群|网、毒、遮挡与接近路线|鸢盾/预判、解网、地形遮挡、夜战的利弊评估|射手站在无掩护边缘；把小杰解网误当解所有控制|
|魅惑、恐惧类敌人|精神检定、队友被控|旗手与振奋，足够决心；避免高爆发队员轻易打到己方脆皮|把决心当士气值；认为数值高就完全免疫魅惑|
|野兽与无甲敌人|机动包围、连续攻击|快速清理、保持可救援位置、低AP武器与合理轻装|高破甲红装一定胜过轻武器；所有伤害技都用同一加成|
|传奇地点、危机战|专门机制与阵容准备|单独测试、准备备用装备和撤退路线|用练习靶击杀次数推断真实Boss胜率|

具体怪物的免疫、抗性、AI与生成强度须以目标版本实机核对。本表给出策略方向，不给未验证的某营地必胜承诺。敌人强度也不能仅按天数概括：契约、世界游荡队伍、地点守军有各自生成规则；本 Mod 的12人强度人数上限只是其中一个输入。

## 6. 新设计的判断标准

1. **机会成本明确。** 多一位主题成员，占用战斗席位、工资、经验、装备与操控注意力。经济技能在预备队触发也必须扣工资，不宣称纯利润。
2. **同类比较，情境交叉。** 盾卫比较占位、承伤和救援；输出比较命中后的伤害、破甲、AP与续航；旗手比较士气和防止崩盘。不给所有属性硬凑一个“战力分”后就宣布平衡。
3. **消除组合漏洞。** 技能三选一、转职互斥、同源取高、目标数限制、恢复总上限、减耗下限、候选持久化一起定义。价格再高也修不了免费无限行动。
4. **均值与坏结果都看。** 报告成长P10/P50/P90、攻击次数分布及模型删失。推算队伍现金底线，不只报“平均一天够赚”。
5. **保持弱点可见。** 高远攻成员怕贴身；高防盾卫杀敌慢；高爆发成员怕长战；经济成员消耗战斗位置。九星小酒瓶需要养成，晚到角色用有限补级减少重复练级。
6. **计算帮助缩小范围，试玩决定取舍。** Dormans的开放论文也明确讨论了资源模型无法代表全部战术与关卡。这里通过公式核对只证明计算与假设一致，不证明所有策略已经均衡。

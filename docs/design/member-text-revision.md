# 成员文案润色记录

更新：2026-09-30。

本轮覆盖主包 34 名成员及可选 DLC 的希文。保留既有称呼、人物关系、故事走向和小龟的龟形化身，所有身世和对白仍为 Mod 虚构改编。里根儿的道具介绍、放出后的描述及起源介绍保持原样。

人物介绍改为约 120—140 字，通过日常动作、说话习惯和同伴之间的反应建立区别。专属背景交代此前的生活与习惯，减少与人物介绍逐句重复的内容。招募相遇保留两种谈法，按钮直接标出原价邀请或招募优惠；实际费用、折扣和正式雇用方式沿用原有逻辑。希文仍只有一个相遇选项。

34 人成长场景与 68 段回应改为具体动作和对白，保留原有的成长门槛、选项方向、特长名称与属性奖励。罗一可和眼子的四段后续精简重复解释，保留前次选择的补叙、分支结局和所有触发条件。成员阵亡纪念改用遗物、习惯与伙伴的反应收尾；已有鲜明特点的退隐结局继续保留。希文的介绍、背景、相遇、成长和三种结局同步润色。

小龟的介绍、相遇、成长、故事梗概与结局统一沿用当前确认的“她”，保留壳纹与隐藏血脉的线索。人物身份、头像、种族设定、数值、装备、技能效果、招募节奏和存档字段不在本轮调整范围内。

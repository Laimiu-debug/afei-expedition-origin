# 主播梗库

改游戏文本时查这里，让台词更像水友写的。

来源是 2026-10-07 在 B 站按人名搜到的切片标题，没有逐条看原视频，只能当“水友圈常这么说”用，不能当真实经历写。下面只收好玩、无伤大雅的梗；涉及身材、擦边、合同纠纷、私人感情和节奏事件的一律不用。

## 通用黑话

- **脸色对了 / 脸色不对了**：形容人表情一下变了，团播切片标题里到处都是。
- **开串、串子**：互相拱火、阴阳怪气。
- **开导、谈心、连麦安慰**：团播里队长挨个给队员做思想工作。
- **游龙**：在一群人里来回窜、到处搭话。
- **破防、红温**：急了。
- **尖货**：夸人厉害（只用在本事上）。
- **上就拼，菜就练**：CSTG 主播们挂在直播间标题上的口号。
- **蛤蟆币**：大飞午猪团的团内货币，阿飞自己发的，正面印着他吐舌头的头像，背面一只蛤蟆。

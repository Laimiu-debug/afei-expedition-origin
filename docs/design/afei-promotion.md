# 阿飞：正常形态、分支转职与隐藏转职

日期：2026-09-25。状态：讨论中的设计稿，尚未实现。人物提示词统一维护在 [人物造型与生图提示词](../art/character-art-prompts.md)，本文件记录玩法与剧情关系。

## 用户提出的核心方向

- 阿飞是主角，可以投入更多人物、美术和成长内容。
- 开始使用正常形态；达到一定等级与条件后，由玩家选择转职为蛤蟆人或嘉豪。
- 蛤蟆人的代表技能是“哇哇叫”。嘉豪的代表技能是“豪气冲天”“全力圈”。
- **“全力圈”中的“圈”指圈钱。**技能效果、图标与剧情应围绕获得财富、报酬或赞助展开，不能继续仅按圆形范围号令解释。
- 已生成的蛤蟆人样图方向可以，但用户认为不够帅。保留为早期探索，不能直接作为转职最终形象。
- 转职后**允许在后期付出代价重修**；用户已选择该方向。代价类型、解锁节点和具体金额未定。
- 新增隐藏转职“飞碟”：小原大人、哈曼卡恩、四哥、可可、溺水小龟、余初九六人的隐藏支线各触发后解锁。水友三派与六根记录见 [专门设定](supporter-factions.md)。
- 飞碟外观采用用户指定的“在人物头顶加个飞碟”，人物主体保留；专属能力尚未确定。

用户原话中的“专制系统”结合后文“选择转职”理解为转职系统，不引入政治或统治制度。

## 转职结构

```text
正常形态阿飞（开局；暂按人类理解，造型仍需讨论）
             │
      达到等级门槛＋完成主角成长事件
             │
             ├─ 蛤蟆人：哇哇叫 → 战场声势、阵线支援
             │
             └─ 嘉豪：豪气冲天＋全力圈 → 战斗投入、经营收入

另行记录六人的隐藏支线触发情况，不要求先修满两条普通路线
             │
      六条均已触发（不改成必须全部完成）
             │
             └─ 解锁隐藏转职：飞碟（头顶增加飞碟；技能待讨论）
```

“正常形态起步、条件满足后选择、两条普通路线及技能归属、后期可付代价重修、六根触发解锁飞碟”来自用户。具体等级、事件、奖励、技能效果及重修成本尚未确定。飞碟为用户新指定的隐藏路线，不把它默认归为普通路线的必经终点。

转职应保留同一个阿飞及其经验、伤势、装备、同伴关系和成长记录。视觉变化、技能包与人物称号一起更新；不能用删除角色再招募新人的方式丢失经历。两条路线均占正常出战席位，不突破十人出战上限。

## 两条路线的玩法候选

以下效果均为助手建议，尚非最终规则；暂不写死 AP、疲劳、金额和百分比。

| 形态 | 候选用途 | 代表技能的候选效果 | 需要成立的取舍 |
| --- | --- | --- | --- |
| 正常形态 | 有限的基础指挥与普通武器作战，逐渐承担团长职责 | 基础鼓劲／传令，名称和效果另定 | 开局已有用处，但不能提前获得两条分支的完整强项 |
| 蛤蟆人 | 靠出场位置、决心与喊声稳定阵线 | 哇哇叫：为附近伙伴提供短时决心或抵抗士气崩溃的帮助；先复用旧号令的设计经验，再调整强度 | 战斗内效果直接、无需以克朗支撑；范围、位置、疲劳与号令次数限制使用 |
| 嘉豪 | 能赚钱，也能把钱投入一场关键战斗 | 豪气冲天：实际支付一笔克朗，提供一次短时团队进攻／士气激励；全力圈：嘉豪实际参战并完成合适的战斗契约后，借声望取得额外报酬或赞助 | 豪气冲天存在真实经济成本；全力圈需真实履约，不能靠开关界面或重复结算发钱 |

嘉豪候选循环：完成契约与积累声望 → 全力圈获得额外克朗 → 留作工资装备，或用豪气冲天投入难战 → 争取更有价值的契约。

全力圈首个原型建议以“一份合格战斗契约的一次完成结算”为单位，收益参考实际报酬和声望；是否要求嘉豪亲自参战是平衡提案，不是已确认的强制出场规则。额外收入不等于每场普通遭遇无限印钱，也不以造成圆形范围伤害表达。

两条路线的优势需要分别测试：蛤蟆人在资金紧张时是否仍有价值，嘉豪的收入与支出是否让玩家真正取舍，不能最终变成一个分支在战斗和经济上都更强。两条分支均能完成主线，不把一个写成错误选择。

## 触发条件与故事候选

- **等级门槛：**数值待定，用来保证玩家先经历一段正常形态；不只靠随机事件抽中。
- **共同成长事件：**建议在一次带队经历后，让阿飞选择今后怎样带队。两种选择同场展示，玩家可暂缓。
- **蛤蟆人：**面对撤退或士气危机时，选择用自己的声音把队伍稳住；变形原因和世界观解释另议，不把蛤蟆形态当惩罚。
- **嘉豪：**完成一场有分量的委托后，开始主动经营队伍名声、报酬与排场；保留玩家自主选择，不用当前贫富替玩家锁定路线。
- **公开条件：**达到门槛前可以查看进度，达标后在合适安全节点触发；阿飞受伤或事件被其他事件占用时可延后。

## 美术投入与三形态关系

先规划三套基础胸像：正常形态、蛤蟆人转职、嘉豪转职。角色段共享一套原版风格规范，视角、头身比例、光向、线条和装备材质一致。先完成三套基础造型，再按实际玩法需要增加叫喊或其他状态，不一次把所有表情都生成。

三套造型应保留共同识别点，例如低眼睑与嘴线的关系、同一处黑旗布或领扣；具体选择仍需用户确认。主角的帅气优先用精神状态、清楚的眉眼、挺拔紧凑的姿态和利落衣装表达，不能靠写实俊脸、巨大外扩装甲或特效遮住原版画风。

蛤蟆人保留宽嘴与喉部特征，调整当前样图过圆、松垮的观感；嘉豪暂按正常阿飞的人类进阶形态设计，突出更有自信和排场的团长轮廓。这两点是美术候选，后续可修改。

飞碟隐藏转职增加一张独立的头顶飞碟素材，沿用人物主体，资源规划为“三套基础造型＋一个飞碟附加层”。建议沿用转职前身体外观，但技能按飞碟职业另行定义；外观沿用不等于叠加两条普通路线的能力。首版建议静态悬浮、不占头盔栏，图层接入与实际位置须验证，详见 [六根设定中的接入方案](supporter-factions.md)。

## 后期重修

**已确认：后期允许付出代价重修。**以下为具体实现提案，待进一步确定：

- 完成后期的重修解锁事件，在城镇或营地安全节点操作；先展示目标路线、将替换的技能与费用，再由玩家决定。
- 初步建议成本由一笔克朗与一段休整时间构成；金额、时长及是否另需材料尚未决定。不安排战斗中即时切换路线。
- 保留原人物等级、经验、基础属性、已有伤势、普通 Perk、装备所有权与伙伴关系。普通加点是否随转职提供重分配是独立问题，不默认全角色洗点。
- 移除旧分支专属加成和技能，应用新分支与外观；共享成长只保存一份，重修不重复领取入职奖励、克朗或永久属性。
- 若已有装备不适配目标形态，先明确提示并处理装备去向，再扣费；不能让头盔、物品或人物记录丢失。
- 全力圈的已结算契约与共享号令使用状态不因重修清空；换路线不能重新结算旧收入。
- 两条路线既有专属成长如何保留／恢复，需要在分支成长规则明确后再决定，不默认要求从一级重练。
- 六根隐藏线触发记录与飞碟解锁资格建议长期保留，不因重修重置；飞碟是否通过同一入口重修、需什么费用，尚待讨论。

## 阿飞与旧档

- 正常形态仍保持原来的五颗星；首次蛤蟆人、嘉豪或隐藏飞碟转职均替换为同一套九星天赋，初始疲劳一星不额外保留。
- 转职门槛、专属技能、成长事件和重修费用不变。三条路线共用星位，因此反复重修不会叠加星数或重新抽取升级数值。
- 原版会预先生成普通升级数值。本版在星位变化时同时更新受影响属性尚未使用的普通升级队列，避免只改变界面上的星星。
- 仅更改受影响的属性列；未变星位的列保留已有升级数值。已分配的点数、经验、等级、专长、生命、伤势和装备不重置、不补发。老兵阶段保留原版固定 +1。
- 旧档在世界载入完成后同步指定九人的星位，城镇中已经存在的待雇佣人物也同步。已转职阿飞在同一路径更新；普通佣兵、已移出名单的眼子与其他起源不受影响。
- 同步记录使用人物旗标，不更改原有 Schema 8。既有全员档无需重建，重启游戏并读取即可应用；本轮未重新实机读取。
- 发生转职失败时，星位、升级队列、路线与技能一起回滚，未扣款。

# v0.20.1：战斗崩溃、理发店与专属背景修复

日期：2026-09-27。内部 Mod 版本 23，存档结构仍为 8。

- 战斗：原版伤害结算可以在 `onTargetHit` 前将死者移出地图；原先 `catalogNearbyPlayers()` 无条件调用目标 `getTile()`，导致截图中的原生异常。现在提前记录邻近人数，移出地图后不再读取目标格子，击杀仍正常消耗命中效果和结算疲劳恢复，不再向死者添加命中记录或刷新其属性。
- 理发店：原版用不带人物身份的临时人类模型预览，导致原版头发、胡须和纹身叠在专属胸像上。预览现在隐藏这些图层；34 人的完整专属外观显示说明并禁用不适用的编辑及接受按钮，后端也阻止这些修改。普通佣兵、其他起源及资源缺失时仍沿用原版理发流程。
- 背景：将已有的 34 人设计接入独立背景类。阿飞为“黑旗发起人”，王大谋为“游历盾师”，午夜抹抹茶为“随军账房”；其余人物见[完整背景表](design/character-backgrounds.md)。背景悬浮信息和人物介绍同时显示新文案。
- 旧档：在完整世界读档后，仅替换具名人物原有的短工／民兵／偷猎者背景，不重建人物，不重掷属性、天赋、装备、等级和特性。工资倍率、个人路线与专属研习记录保留；城镇待招募伙伴走同一迁移入口。
- 皈依：已皈依者保留原版 `background.converted_cultist` 机械身份，显示原经历与皈依状态；外部模组替换的其他背景不覆盖。转化生成纹身时临时使用原版身体，结束后恢复专属外观，避免请求不存在的专属身体纹身资源。

背景数据源是 `data/character-backgrounds.json`，`tools/build_backgrounds.py` 生成背景数据表及 34 个继承原模板的类。导出的 `build/characters.json` 同时记录运行时背景与基础模板，便于审阅。

验证使用本机原版理发模块、背景创建／序列化方法和实际模组钩子，覆盖专属预览、六类编辑按钮、接受、退出、普通佣兵回归、34 人新类、模板属性一致、旧档迁移幂等性、读写往返、皈依与其他背景保留；战斗回归模拟原版先移除死者再触发命中回调，覆盖近战及远程击杀。UI 按钮状态另以 JavaScript 测试验证。

完整构建、脚本编译、原版资源引用、行为测试、ZIP CRC 和逐文件源码比对已通过。具体数量与 SHA-256 见 [构建报告](../build/gameplay-package.json)及[验证报告](../build/gameplay-validation.json)。这些是离线及原版脚本测试；尚未实机验收画面和战斗。

更新后需完全退出并重启游戏，再读取旧战役；无需重新开局。本次更新包为 [mod_afeix_expedition.zip](../dist/mod_afeix_expedition.zip)。安装前旧包备份位于 `build/hotfix-v0.20.1/baseline/`。按用户后续要求已同步发布到 BBMOD 网站，公开下载与本地包逐字节一致，见[发布记录](releases/publication-0.20.1.md)。

历史说明：当前版本已扩展为 [v0.2 全员招募试玩](playtest-0.2.md)。以下保留五人原型的行为与限制，旧包位于 [v0.1 归档](../dist/archive/v0.1/mod_afeix_expedition.zip)。

日期：2026-09-26。目标环境：PC 原版《战场兄弟》＋官方 DLC。用户已选择先做三队长开局、任务招募和十人编队；美术暂停制作，试玩使用原版外观、装备和事件图片。

本版已形成独立源码和测试包，完成语法、资源引用、模拟环境行为与打包检查。**尚未启动游戏验收，离线检查不等于实机运行通过。**

## 安装与开始

1. 将 [v0.1 mod_afeix_expedition.zip](../dist/archive/v0.1/mod_afeix_expedition.zip) 整个放进游戏 `data` 目录，不解压。
2. 需要 Legacy Modding Script Hooks 环境，提供 `mods_registerMod`、`mods_queue`、`mods_hookExactClass`、`mods_hookNewObject`、`mods_hookBaseClass` 与 `mods_registerJS`。[Hooks 说明](https://github.com/jcsato/modding_script_hooks)列有安装方式。中文文本还需要可用的中文字体／汉化环境。
3. 新建战役，选择 **“阿飞远征团：起步试玩”**。这是独立新起源，不接管旧版或其他起源的存档。
4. 开局为阿飞、王大谋、午夜抹抹茶。世界地图按 **F8** 打开黑旗名册；战斗、过场或其他事件中不能打开。开场若正处于加载画面，稍后手动按 F8。

本机只读检查发现 `F:/SteamLibrary/steamapps/common/Battle Brothers/data/mod_bbmod_zhcn.zip` 内已有 Hooks 相关入口；本轮没有验证其运行版本，没有替换它，也没有向游戏目录安装新包。不要仅因这里提及依赖就重复覆盖已工作的 Hooks。

本包不依赖阿飞美术测试包，不包含旧版自定义胸像。本轮未验证与其他编队、起源或装备 Mod 的组合。

## 第一轮怎么玩

1. 到一座友好城镇附近，F8 → **查看任务与交付** → **领取送信委托**。
2. 名册显示收信城镇及地图格，并揭示目的地附近地图。抵达后再次打开任务页交付，首次获得 **180 克朗**。
3. 在 **查看伙伴与招募** 中分别邀请白小帅子、小酒瓶。没钱或满员时保留线索；暂缓不需要重新抽随机事件。
4. 在 **选择出战成员** 中勾选名单，核对后确认。未选成员待命；取消不会改变现有阵容。原版人物栏可继续摆站位、换装备。
5. 可雇用普通佣兵扩成超过十人的名册。本版为 **20 人在册，1～10 人出战**，换人须在友好城镇附近或安全扎营；原版人物栏沿用自己的操作时机。

送信是黑旗名册中的入门委托，不占原版契约栏，不强制生成伏击。正常敌军、路程、工资和补给仍然存在。若不想送信、没有可达目的地或目的地无法交付，**成功结算一份实际收到克朗的原版契约**同样开放两条招募线。取消契约和未收款的结束不计入；本 Mod 不为原版契约额外发钱。

## 试玩参数与范围

以下为可调整的试玩参数，不是最终定案。

| 人物 | 入队方式 | 招募费 | 起步日薪 | 起步玩法 |
| --- | --- | ---: | ---: | --- |
| 阿飞 | 初始队长 | — | 8 | 属性明显偏弱，使用普通武器，没有开局哇哇叫或完整辅助技能 |
| 王大谋 | 初始队长 | — | 15 | 较强近战与防御，撑起前排，不预设后期变弱 |
| 午夜抹抹茶 | 初始队长 | — | 10 | 普通水平后排弓手，可自由换装 |
| 白小帅子 | 任务解锁后邀请 | 200 | 9 | 可培养的持盾前排 |
| 小酒瓶／蛤妈 | 任务解锁后邀请 | 220 | 10 | 后续招揽的队员，保留她与阿飞的关系设定 |

初始资金 1,800 克朗，工具 30、药品 15、弹药 25，另有两份粮食。工资受等级、特性等原版因素影响，以人物页面实际值为准。

阿飞转职、共享号令、伙伴专属成长、六根、自行车剧情和其余人物尚未接入。十人上限在试玩阶段直接可用，但只发三名开局成员；这不等于最终版已决定开场就开放十席。20 人名册也是首轮范围，没有取消最终 35 人收集与轮换目标。

换人保留原实体、装备和普通升级记录，阿飞也可待命。工资、食物和经验沿用原版；没有新增待命免粮、工资折扣或追赶经验。战术友军和契约临时单位属于原版额外实体，不是可自由招募的十名成员。

命名队员阵亡或被辞退不能重新领取。阿飞死亡不会单独结束公司，存活成员可继续任务和招募；全队覆灭仍遵循原版规则。原版外观仅为占位，不代表女性队员的正式造型。

## 实机验收清单

| 操作 | 应观察到的结果 |
| --- | --- |
| 新开局 | 只有三队长，阿飞弱于大谋，F8 可重访 |
| 正确城镇交付、再次点击 | 只领一次 180 克朗 |
| 放弃送信或先做正常契约 | 不发放弃奖励，仍有后备招募入口 |
| 没钱、满员时邀请 | 不扣钱、不创建人物，之后可重新办理 |
| 先招一人，保存再读档 | 原人物保留，另一人的邀请仍在，不能重复招人 |
| 名册超过十人 | F8 和原版人物栏可安排待命，战斗最多部署十名常备成员 |
| 二十人在册，只选一人 | 其余十九人都有位置，人物栏可滚动，没有覆盖或丢人 |
| 多页勾选后取消 | 阵容保持原样，确认后才改变 |
| 换下再上场、保存后重读 | 装备、等级、伤势和工资优惠保留；命名队员基础日薪与人物介绍恢复正确 |
| 保存、读档、撤退后再战 | 阵型、上限、任务与招募记录一致 |
| 昏迷、永久死亡与辞退 | 昏迷幸存者不被记为死亡，真正失去的人不再生成 |
| 进入其他原版起源 | 没有阿飞任务，恢复原版人数与人物栏尺寸 |

重点实测新增预备位滚动、拖放、战前界面和原生序列化。十人限制尚未配套重做所有敌军规模；保留原版规模参数，难度仍需试玩调整。

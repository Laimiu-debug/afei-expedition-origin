## 身份与参考图

**采用“真人脸部辨识度＋中世纪佣兵装备＋《战场兄弟》画法”。**当前文本未逐人验证五官，也尚未配齐参考照。以下是参考图驱动的完整提示词；每次使用时，需要附上该成员清晰、无遮挡的真人照片。只有名字和文字不能保证画得像本人。

- 图 1：本人正面或轻微侧面的参考照。脸型、眼距、鼻口比例、发际线、肤色、年龄感和惯常发型以它为准；有多张照片时，先选定同一时期的一套，不混用明显不同年龄的照片。
- 图 2（可选）：《战场兄弟》原版角色图，只用于轮廓、色块、材质与半身构图，不借用其中角色的脸。
- 保留真实身份特征，表情可按剧情调整。若本人戴眼镜，保留镜框形状和戴镜特征，将材质简化为暗旧金属；去除耳机、麦克风、品牌标识。现代发饰可换为素布或旧金属，头发轮廓仍然保留。
- 体型、性别呈现以对应真人参考照为准；不得从“小胖”“小虎”“童猪”等名字推断身材、性别或动物外形。王大芷的参考照不能仅凭“芷芷”昵称代替；瑶瑶牙不得用一凹瑶照片；余初九和余想分别建档。
- 下文道具、服饰和表情属于原创角色设计，不表示真人曾穿戴或表现如此。

## 画风与统一规格

官方对角色画法的说明强调手绘半身棋子、较大的头部和鲜明五官，以及可辨认的独立装备图标；因此本稿采用接近游戏角色的紧凑轮廓。[官方角色美术说明](https://battlebrothersgame.com/dev-blog-5-concept-art-explaining-battle-brothers-character-art-style/)

以下尺寸、光向和背景是本项目的制作建议：

| 项目 | 本稿规格 |
| --- | --- |
| 用途 | 名册用单人半身头像；服装为入队初期的设计 |
| 视角 | 身体正面，头部最多轻微转向；整组保持相同观察高度 |
| 裁切 | 完整头顶、双肩和短上胸；不画手臂、手、腰部与腿 |
| 比例 | 适当放大成人头部，保留真人五官比例的关系；避免幼儿化 |
| 色彩 | 土黄、灰褐、旧布灰、暗钢为底，每人一处低饱和强调色 |
| 笔触 | 实色块、简洁阴影与少量笔触；脸部不被泥点、颗粒或厚重阴影淹没 |
| 表面 | 用过的布、皮、铁，磨损克制且有理由；不人人添伤疤、血污或黑眼圈 |
| 光线 | 左上方统一柔光，无逆光光圈、彩色霓虹、镜头景深 |
| 画布 | 建议 1024 × 1024 母图；头顶与肩侧留出裁切余量 |
| 背景 | 优先透明；生成器不支持时，改为纯暖灰色，不画假透明棋盘格 |
| 识别 | 第一层靠真人脸和发型，第二层靠领口与肩部轮廓，第三层靠一件个人标记 |
| 装备 | 先画能看清脸的基础头像，不用封闭头盔；武器与盾另做装备图标 |
| 道具上限 | 每人保留一组简洁标记；画面太小时先删小装饰，不牺牲脸部 |
| 成长版本 | 同一张脸、同一发型与同一核心标记，主要改神态、穿戴方式和合理修补 |

本稿默认无底座的名册头像。若另做战场棋子，可在头像外组合低矮底座和独立装备图标，避免让角色摆出持握双手武器的全身动作。原版角色采用分层组合，后续可据此拆分脸、头发和装备；**这些提示词用于制作美术母图，本轮尚未生成画像，也未制作可直接导入的游戏图层文件。**[官方角色分层说明](https://battlebrothersgame.com/dev-blog-33-character-generation-hiring-shopping/)

## 使用方法

每位的“完整提示词”可单独复制，与本人参考照一起使用。若生成器有负面提示词栏，可追加下方通用负面词。定下一张初始画像后，再把“成长版修改词”与该画像一起用于编辑，避免重新生成另一张脸。成长版是可选分支，不代表所有角色都必须永久留队。

**通用负面提示词：**

```text
真人照片质感，电影写实，3D 模型，塑料皮肤，磨皮美颜，统一网红脸，改变本人五官，改变性别呈现，幼儿比例，日漫大眼，像素画，全身像，手臂和手掌，动态攻击姿势，华丽卡牌边框，大场景，金色光环，发光魔法，过度装饰，现代耳机与麦克风，文字，姓名，水印，品牌标志，假透明棋盘格，脸部被头盔或道具遮挡，无依据的伤疤，动物化人物
```

## 01｜阿飞

**人物气质**：最怕别人发现自己不行，却最能理解别人为什么会失手。  
**职业方向**：旗手／成长型团长  
**另制装备图标建议**：短柄团旗；本次头像不绘制手持动作。

**完整提示词：**

```text
以随附的【阿飞】真人照片为身份参考，保留本人脸型、眼距、鼻口比例、发际线、发型轮廓、肤色和年龄感，不套用通用佣兵脸；若有眼镜则保留镜框形状，改为朴素旧金属材质，去除耳机和麦克风。

画成《战场兄弟》Battle Brothers 游戏内佣兵名册使用的二维手绘半身像：成年人的头部适度放大，沿真人眉眼鼻口的特征作克制夸张；清楚的深色轮廓，简洁厚实的色块与少量手绘笔触，低饱和土色、旧布、磨损皮革和暗钢材质，左上方柔和统一光线，面部明亮可辨。

褪色黑色短披肩，米灰色旧棉甲，胸前歪缝的一块黑旗布。嘴角努力撑着笑，眉间露出一点紧张；肩膀略提，衣领整理得过于认真。保留脸部亲近感，不添加帝王冠或华丽重甲。

单人正面居中，完整头顶、双肩和短上胸，头顶留白；不显示手臂、手掌、腿脚，不手持武器。方形构图，透明背景，无底座、文字或边框。不要照片质感、3D 渲染、动漫大眼、电影海报光效、全身立绘或华丽魔法装备。
```

**成长版修改词：**

```text
以该角色已定稿的初始画像为编辑基准，保持同一个人的五官比例、肤色、发型轮廓，以及原图的构图、光线、手绘笔触和背景。沿用同一张脸、发型和黑旗布；棉甲修补整齐，肩膀放松，嘴巴闭合，目光平稳地迎向观者。变化来自神态和承担事情的姿态，不靠变壮、变帅或加冕。不添加新人物或大场景。
```

# 自定义角色受伤血迹

2026-09-30，当前 v0.28.3 工作区。新增血迹显示，不改变伤害、伤势、生命或装备规则。

- 角色生命低于上限时，显示原版身体/防具血迹层。原版战斗溅血计数继续保留；因此满血但已溅血的角色在战斗清理前也可能带血。
- 剩余生命不高于67%时显示第一档脸部伤痕，不高于33%时显示第二档；回血跨过阈值后减轻或清除。身体血迹随伤口恢复与原版战斗清理更新。
- 遮脸头盔隐藏脸部伤痕；隐藏头盔后重新显示。血迹跟随角色朝向、缩放，适用于主包成员、可选DLC希文与使用这些立绘的复活角色。
- 原版身体替换型 `injury_body` 仍隐藏，避免索取不存在的自定义 `_injured` brush 和再次覆盖颈部/防具。脸部使用原版透明伤痕层，防具使用原版血迹层；没有额外打包原版图片。
- 死亡时保留受伤时脸上的原版伤痕与溅血：先按站立时相同图层顺序合成到角色头部，再和头部一起执行同一颈部锚点、旋转及缩放。战场尸体与结算共用已转为倒地姿势的brush，避免运行时旋转在UI截图中失效。**已移除上一版贴在脖子上的血泊红斑。**
- 记录最后仍存活时的伤痕档位，致命伤将生命变成0时不覆盖该记录；轻伤、重伤及只有溅血的脸分别保留。此前完全干净的一击致死使用重伤档。满血昏迷使用干净头部，受伤昏迷保留伤痕。
- 覆盖左右朝向与没有战场地格的结算肖像，保留原版血泊、装备、箭矢与尸体数据；斩首、砸碎、吞噬等仍走原版特殊死亡。
- [倒地伤痕转换脚本](../../tools/build_corpse_injury_art.py)导出三种受伤头部状态，保持原有头部轮廓与坐标，不重画人物。主包34人102张，希文3张放在可选DLC自己的独立atlas内。更改立绘、头部锚点或原版伤痕输入后，运行此脚本再检查与打包。

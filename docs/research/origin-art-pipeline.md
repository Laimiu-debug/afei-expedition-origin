# 其他起源如何制作人物美术，以及阿飞的调整方案

核对日期：2026-09-26。目标仍为原版《战场兄弟》＋官方 DLC。本轮暂停继续生图，检查本机原版脚本、旧归档中的 Fate 美术样本、公开 Mod 源码。下文区分已观察到的实现与本项目建议；没有运行这些第三方 Mod，也没有完成阿飞实机验收。

## 当前采用的方案（v0.4）

研究后用户明确选择简化制作：全员用一张包含自绘头发的完整胸像，隐藏原版人物与装备部件。已按此实现，详见 [v0.4](../playtest-0.4.md)及[全员资源](../../art/runtime/portraits-v04/README.md)。实际装备仍影响玩法，画中服装固定；飞碟和战斗提示独立保留。下文分层推荐属于之前的研究结论，不再作为本项目本轮制作约束。尸体先用同图旋转表示，伤口不单画；实机仍待验收。

## 原研究结论（历史建议）

对本项目最有用的方式，是先制作符合原版位置和比例的人物部件，再把它们放进原版的装备与状态系统。仅把独立生成的大图拆成头和身体，仍然会发生头颈接不上、头盔遮挡错误、倒地头发盖住脸等问题。

人物是否有辨识度，取决于实际战斗尺寸下能看清的头型、发型、表情、种族轮廓与少量标记。精细皮肤、衣服上的小纹样，以及只在大图中好看的细节，不应成为主要识别手段。

## 1. 原版起源：使用人物部件与实际装备

直接检查本机 `F:/SteamLibrary/steamapps/common/Battle Brothers/data/data_001.dat` 中的起源、背景和装备脚本。工作副本保存在忽略目录 `.cache/afei-art/origin-audit/`。

| 样本 | 实际做法 | 对阿飞有用的部分 |
| --- | --- | --- |
| 独狼 `lone_wolf_scenario` | 建立玩家角色并设定佣兵骑士背景，给角色装备护甲、头盔、武器；人物外观仍来自背景外貌池与装备层 | 主角可以身份固定，同时保留完整换装表现 |
| 角斗士 `gladiators_scenario` | 三人使用角斗士起源背景；装备角斗士护具、不同护甲附件和 13／15／14 号头盔变体；另在 `miniboss` 层设置标记 | 三位核心人物的差异可以通过原生装备组合表达，不需要把整个人画死 |
| 宣誓者 `paladins_scenario` | 年轻、年长角色继承同类背景；老者改用老年发色，并在头与身体的纹身层叠加疤痕；两人再穿戴各自装备 | 固定人物特征和独立装备可以共存 |
| 猎兽人 `beast_hunters_scenario` | 使用凌乱头发、胡须、强壮身体和疤痕，再以矛网、长叉、弓区分三人 | 职业辨识也可以来自装备与轮廓，不必每个背景都新造身体体系 |

背景脚本的脸、发型、胡须、基础身体池最终分别设置到相应图层。人物身体和所穿盔甲属于不同部件，装备改变时由原版外观逻辑更新。

对应本地证据：[背景组装](../../.cache/afei-art/origin-audit/character_background.nut)、[独狼](../../.cache/afei-art/origin-audit/lone_wolf_scenario.nut)、[角斗士](../../.cache/afei-art/origin-audit/gladiators_scenario.nut)、[老年宣誓者疤痕](../../.cache/afei-art/origin-audit/old_paladin_background.nut)、[猎兽人](../../.cache/afei-art/origin-audit/beast_hunters_scenario.nut)。

还核对了一个容易误解的字段：起源 `IsFixedLook` 在已检查的原版消费位置影响的是**大地图佣兵团棋子**。`asset_manager.updateLook()` 改的是 `World.State.getPlayer()` 的 `figure_player_XX`。不能把这个字段当作战斗人物固定立绘或隐藏装备的开关。

样本具有以下结构：

| 部件 | 已观察到的变体 |
| --- | --- |
| 基础身体 `bust_naked_body_2002` | 正常、受伤、倒地、倒地箭矢与标枪 |
| 四套服装 `bust_body_3000`～`3003` | 正常、损坏、倒地、倒地箭矢与标枪 |

尤其值得参考的是位置约束：四张活头都采用同一组范围 `left=-21, right=29, top=-20, bottom=48`，对应 50×68 的精灵矩形；共享 104×142 的画布参数与 `offsetY=35`。死头另用一套共同范围与偏移。这里的 104×142 是这批资源的画布参数，不是所有 BB 资源唯一合法的 PNG 尺寸。

**借鉴其共用模板、拆层和状态配套方式；画风继续以原版为准。**样本中的动漫发饰、明亮服装和面部处理，不直接成为阿飞的风格标准。资源名 `hair_black_3000` 实际对应金色发型，也说明必须看图片，不能只按名字推断。

## 3. 非人类起源：外形变化必须配套装备规则

### NgGH Magic Origins

核对作者的[可玩哥布林实现](https://github.com/NgGH707/NgGH-Magic-Origins-Mod/blob/main/scripts/entity/tactical/nggh_mod_player_goblin.nut)：身体、身体伤痕、头、头部伤痕和装备分别处理，死亡时也按身体、头、盔甲、头盔等重新组装。其坐骑和非人体形需要额外偏移与显隐逻辑。

作者的[项目说明](https://github.com/NgGH707/NgGH-Magic-Origins-Mod)明确依赖 Legends。此处只研究实现思路，不把这些脚本直接接入我们的原版＋DLC 项目，也不把其专用装备层当作原版已经提供的接口。

### Proper Druid

检查到普通[德鲁伊背景](https://github.com/Suor/battle-brothers-mods/blob/master/druid/scripts/skills/backgrounds/druid_background.nut)复用人类脸、发型、胡须与瘦身体池。兽化的[外观 helper](https://github.com/Suor/battle-brothers-mods/blob/master/druid/druid/helpers.nut)则更换身体、头、头发和受伤层；[兽化技能](https://github.com/Suor/battle-brothers-mods/blob/master/druid/scripts/skills/perks/perk_druid_beastform.nut)及相关逻辑配套处理装备限制。

这提供了另一种明确取舍：非人体形不必保证所有人类装备都适配。但该取舍属于玩法设计，不能为了省美术工作直接替阿飞增加禁穿护甲或头盔的规则。

## 4. 阿飞当前资源的问题与保留内容

旧版将完整胸像放在身体层并隐藏脸、头发、护甲、头盔，角色辨识度比较稳定，但会失去换装的视觉反馈。本轮 v1 已改为拆层并保留原版装备；方向可以保留，几何模板还需要校正。

已确认的问题：

1. 蛤蟆头与衣领之间仍有接缝。只改变画刷位置，没有解决头部短颈与身体领口本身的匹配。
2. 人类倒地头的方向与原版倒地头发不匹配，组合后头发会遮到脸部。单独看死头还可以，合成后不合格。
3. 普通与嘉豪主要靠基础衣装区别，而原版护甲会盖住基础衣装。这是识别设计问题，不能用隐藏所有装备来默认解决。

保留现有原图、提示词、独立飞碟、构建工具和接入试验。当前 ZIP 只通过资源格式、打包解包与脚本静态检查，**不是完成美术验收的发行版**。完整记录见 [v1 目录](../../art/runtime/afei/v1/README.md)。

## 5. 下一版制作建议

以下是研究后的建议，不是新增的用户已确认角色设定。

| 形态 | 建议保留的辨识点 | 制作安排 |
| --- | --- | --- |
| 正常阿飞 | 斜眉、低眼睑、痞帅表情、清楚的黑发轮廓 | 先做一套严格对齐原版的脸、头发和短颈；试穿装备通过后再做其余状态 |
| 蛤蟆人 | 宽嘴、低压眼神、蛤蟆头轮廓 | 优先保持原版肩胸和头盔可容纳的头部范围；若选择更夸张头型，再单独讨论专用头盔或显示规则 |
| 嘉豪 | 与正常阿飞是同一个人，认真时有气势 | 面容与发型保持身份连续；用表情和少量独立标记探索转职识别，不只依赖底层衣服颜色 |
| 飞碟 | 用户指定的头顶小飞碟 | 保持独立附加层；分别检查人物名册裁切、战斗标记、头盔、翻转和死亡表现 |

制作顺序：

1. 从原版参考确定共用模板：眼线、头顶、下巴、颈根、肩宽，以及站立与倒地两套坐标。
2. 只完成一个正常形态样本，并排检查原始显示尺寸与放大细节；不要先批量生成四套大图。
3. 配原版发型、开面盔、全盔、布甲、锁甲和重甲检查接缝、遮挡与身份识别。
4. 以这个模板生成／修改蛤蟆头，再补与同一模板匹配的受伤及倒地资源。头、发、盔的倒地朝向必须共同验收。
5. 最后处理嘉豪附加标记与飞碟；独立附加层也需要明确装备遮挡、死亡、昏迷和读档行为。
6. 在游戏中验证角色面板、战斗、受伤、死亡、存读档。通过后才将资源标为可正式使用。

后续提示词必须同时给出“身份／画风参考”和“准确的部件几何模板”。增加“战场兄弟画风”字样无法代替模板对齐；若输出偏离模板，应退回修正，不能仅靠等比缩放判定合格。

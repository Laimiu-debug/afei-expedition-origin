# v0.15｜补齐全员成员技能

日期：2026-09-27。目标环境：原版《战场兄弟》与官方 DLC。

现有 33 名伙伴各三项，共 99 项成员技能；阿飞继续使用独立转职技能。本次在 v0.14 的 18 项基础上新增 81 项，99 个图标文件逐字节复用旧 PNG。没有生成新图，也没有变更头像、装备图层、基础属性或九星分配。

[全员技能与费用表](design/member-skills.md)及[技能图册](../build/member-skills/index.html)由实际加载的数据生成，只放在作者文档中，不向玩家展示未知人物或隐藏支线。

## 开放方式与旧档

- 重启游戏后读取原有战役即可，包括[34 人审阅档](../dist/saves/afeix_all_34_v11.sav)。世界加载时为在册成员和已出现的城镇候选补技能，重复同步不叠加。
- 每人前两项随入队开放；第三项随该人的现有个人成长选择开放。两种成长选项都能解锁。已经完成成长的旧档人物会自动补齐第三项。
- 旧审阅档没有被修改，也没有强行解锁全员成长。等级、经验、加点、装备、招募和剧情进度沿用原档。
- 主动技能依旧有武器、持盾、射程、冷却或次数条件；暂时无法使用时应查看说明。
- 冷却、每战次数、攻击记录和临时效果支持保存往返；战后清理临时状态。商店折扣和雇佣机会仅在成功交易后记账。

## 这次补齐的机制

- 普通攻击、投掷、标记、接应、士气、站位防守、疲劳恢复及队长邻近条件。
- 护团换位／回头路使用原版换位；舞步、短冲等使用相邻同高空地的一步移动。普通走路才计入“走两格”的奖励。
- 顶上去有条件地拦截一次敌方单体近战攻击；无法选中只在敌人另有合法目标时生效；欧气使用原版士气重掷。
- 小杰解除网缚或消耗工具施加短暂束缚；奶盖嘲讽使用原版 AI 指定对手；工具返还、食物与补给折扣、大谋招募折扣接入现有流程。

这是按现版玩法调整后的完整成员技能组，**不是把旧稿所有设想逐字实现**。地格陷阱、长距离冲锋、额外射箭、世界侦路以及旧磨合／共享号令系统没有恢复；相应技能已有明确替代效果，逐项见[技能表的移植差异](design/member-skills.md#与旧稿的差异)。

## 验证范围

完整构建通过 **17,272 条离线行为断言**，本次新测试 655 条，另保留上一版成员技能的 126 条。54 个 Squirrel 文件语法通过；资源路径、图标指纹、原有美术图集、JavaScript、ZIP CRC 和源文件一致性均通过。

测试使用本机游戏解包的真实技能执行、单次扣费、单手攻击、双手斧双部位伤害、换位、嘲讽、物品价格与商店交易代码；画面、导航落点、命中与伤害落地、AI 实际行为等引擎部分由隔离环境替代。

新增覆盖：33 人解锁与重复同步、99 项技能和各临时效果的保存往返；真实出手而非预览消耗次数；标记按轮到期；普通步行、撤销与异步位移区分；失盾与离开守位；攻击拦截覆盖第二部位伤害；最后一发正常扣弹药；商店预览、缺钱、背包满都不消耗优惠；成功购买后更新价格；实际维修返工具和每日上限；招募折扣七日冷却。

**本轮未启动游戏验证，因此实机读档、图标显示、战斗手感、原版 AI 响应与长期平衡仍待实测。** 本记录不把隔离环境测试算作实机验收。

# v0.17.0：专属技能与开局平衡

日期：2026-09-27。目标为原版《战场兄弟》与官方 DLC，继续依赖 Legacy Modding Script Hooks。

## 专属技能

- 阿飞保留原有独立转职；其余 33 名伙伴共有 99 项候选技能。
- 1～6 级没有成员专属技能。达到 7 级后，在世界地图 **F8 → 研习专属技能**，查看三个方向，再确认学习其中一项。确认须在友好城镇附近或安全营地。
- 不占用原版技能点。选定后不可改选，不会学习剩余两项。
- 达到 11 级自动精通所选项；11 级以后才选择也直接精通。
- 主动技能精通：基础疲劳消耗减少原值的 25%，减免值向下取整且至少为 2。行动点、冷却、每战次数保持原样。零消耗的“尼古丁”改为立即恢复 20 疲劳，原为 15。
- 被动技能精通：保留原有效果，额外增加自身每回合 2 点疲劳恢复。“分你半拍”的近防 +6 改由 11 级触发。
- 个人成长故事及其小幅属性奖励保留，完成故事不再额外获得第三技能。

为避免三选一产生无效选项，“松口气”改为持盾且相邻队友闪避时触发；“下一招换个路”减免后续普通近战攻击的疲劳；“先懂规则”自身提供命中；“小熊出击”和“敲杯为号”无需另一个技能的看懂层数。

完整候选与精通数值见[技能表](design/member-skills.md)。该表供作者审阅，游戏内不会公布未相遇人物。

## 更新与验证

关闭游戏后，将 [dist/mod_afeix_expedition.zip](../dist/mod_afeix_expedition.zip) 替换到游戏 `data` 目录，同一 Mod 只保留一份。旧包备份在 [v0.16.1 归档](../dist/archive/v0.16.1/mod_afeix_expedition.zip)。

旧档加载后撤下原有同时存在的成员专属技能；达到 7 级的成员可重新三选一。普通佣兵、阿飞转职、九星天赋、剧情物品和隐藏支线不受此选择系统影响。34 人审阅档仍为正常 1 级，需要成长到 7 级才有专属技能。

离线构建通过：Squirrel 编译、原版资源引用、99 项候选的等级边界与互斥、确认/取消、冷却与保存恢复、旧档迁移、原有战斗与经济回归、图集像素和坐标回读、ZIP CRC 与源码一致性。断言数量与包指纹见[构建报告](../build/gameplay-package.json)。

本轮尚未完成实机战斗及长期平衡验收。GitHub Release 与网站下载仍为 v0.16.1，未在本轮自动发布。

# 阿飞远征团：成长与转职试玩 v0.3

**历史版本：**当前包与全员整图美术见 [v0.4](playtest-0.4.md)。本页保留 v0.3 的玩法参数与当时美术状态。

日期：2026-09-26。环境：PC 原版《战场兄弟》＋官方 DLC、Legacy Modding Script Hooks、可显示中文的字体／汉化。

本版在 34 人招募与十人编队基础上，接入个人成长、阿飞转职、六根开篇和自行车事件，并加入四张新技能图标与部分人物图层。**这是一份可安装的功能原型，尚未启动游戏进行实机验收。下面的等级、金额与技能强度均为可调整的试玩参数。**

## 安装与入口

把 [mod_afeix_expedition.zip](../dist/archive/v0.3/mod_afeix_expedition.zip) 整个放入游戏 `data` 目录，不解压。替换同名旧包；同一时间只保留一份本项目玩法包，不要同时加载旧工程或 `afei_art_v1` 美术测试起源。需要 [Legacy Hooks](https://github.com/jcsato/modding_script_hooks)。本轮只生成项目 ZIP，没有改动游戏安装目录。

新建战役选择 **“阿飞远征团：成长与转职试玩”**。阿飞、王大谋、午夜抹抹茶三队长开局，初始 1,800 克朗。世界地图按 **F8** 打开黑旗名册：任务、招募、出战编队继续保留；新增 **“成长、转职与伙伴羁绊”** 入口。

优先用新战役验收。原有起源 ID 和人物键保持不变，旧存档按原人物补接特性，不重建人物或清空装备。**原生存读档、旧版升级和自定义图层尚未经过引擎内验证；测试旧档前保留原档与原 ZIP，不要把新版存档当作可安全降级。** [v0.2 包已归档](../dist/archive/v0.2/mod_afeix_expedition.zip)。

## 招募与个人成长

招募仍按累计履约 **1／3／6／9／12** 份开放五章；送信和成功结算且收到实际报酬的原版契约各记一份。小酒瓶、白小帅子在首份履约后直接获得邀请，其余 29 名招募伙伴各有双选项相遇。详细名册见 [34 人配置清单](design/member-implementation.md)。眼子不再开放招募；旧档里已经存在的眼子保留。

每位当前制作名单中的成员，达到 **3 级且本人实际参战 3 次**，可以在安全地点进行一次个人成长选择。从成长目录逐章查看，两个选项会显示各自的特性与数值。共 34 段独立场景、68 个选择结果，覆盖队长和招募成员；待命不增加本人参战次数，已满足条件的人待命时仍可处理事件。

奖励通过一个可查询的个人特性生效，不修改基础属性，不锁定武器或普通 Perk。读档、换编队和重复打开名册不会重复叠加。每人目前只有这一段成长；[故事梗概](design/character-stories.md)中的完整长线并未全部实现。成长文本与数值主文件是 [member-growth.json](../data/member-growth.json)。

## 阿飞转职与战斗能力

在安全的友好城镇附近，进入“阿飞晋升与重修”。三条路线互斥，保留同一个阿飞的经验、装备、普通 Perk 和伤势。

| 操作 | 当前条件与成本 |
| --- | --- |
| 首次蛤蟆人／嘉豪 | 阿飞 5 级、本人参战 3 次、完成个人成长；免费 |
| 首次飞碟 | 六根的开篇全部触发；免费，不额外添加等级或全线完成条件 |
| 已转职后的普通换路，或再次转回飞碟 | 阿飞 9 级、累计履约 12 份、1,500 克朗 |

飞碟首次开放时可以从任一普通路线转入；重修不能清除个人成长选择、复制奖励或累加旧路线属性。能力载入失败时回滚路线与技能并保留克朗。

| 路线 | 常驻特性 | 主动技能 |
| --- | --- | --- |
| 蛤蟆人 | 近战命中 +8，近防／远防各 +5，伤害 ×1.10 | **哇哇叫**：3 AP、15 疲劳，每战一次；自身近战命中再 +12、承受伤害 ×0.80 |
| 嘉豪 | 决心 +10 | **豪气冲天**：4 AP、20 疲劳、80 克朗，每战一次；3 格内自方队员含本人，近战／远程命中与决心各 +10 |
| 飞碟 | 近战命中 +5，近防／远防各 +3，决心 +5 | **飞爹在此**：4 AP、20 疲劳、60 克朗，每战一次；2 格内自方队员含本人，近战／远程命中与决心各 +8；阿飞另获承受伤害 ×0.90 |

这些短效持续到受益者接下来第二次开始自己的回合；战斗结束清除。已使用次数和剩余回合写入技能存档。待命人物、盟军 NPC、中立单位、敌人、宠物和被控制的队员不获得团队增益。资金不足时不能发动收费技能。

**全力圈是经济被动。**嘉豪按有胜战记录、成功完成的付费契约累计实收款取得 **15%** 赞助，飞碟为 **10%**，每份契约最多 **300 克朗**。契约结束时锁定阿飞的路线和资格，阿飞须活着在册，可以待命。分次收款只补赞助差额；取整向下。

普通送信、卖物品、取消或无胜战记录的契约不产生赞助；赞助本身也不能再次触发赞助。升级前已经结清的契约不追溯补发，重修和重读存档不重领。累计赞助在转职目录显示。

## 六根与飞碟

从成长目录进入“六根线索与回信”，明确点击开篇按钮才记录“触发”。仅招募或查看列表不算触发，完成回信也不是飞碟的额外条件。

| 人物 | 开篇出现条件 |
| --- | --- |
| 小原大人 | 累计履约 3 份，在友好城镇会面 |
| 哈曼卡恩 | 累计履约 6 份，在友好城镇会面 |
| 四哥 | 累计履约 9 份，在友好城镇会面 |
| 可可、溺水小龟、余初九 | 对应伙伴曾经入队，在安全地点读留下的便笺 |

三名水友代表是联系人，不是新增的招募角色，不占 40 人名册。伙伴后续阵亡或离队不会抹去已有便笺和开篇记录，也不会因此复活。每根的后续回信可二选一领取一次小额支持，独立记录，不能反复领奖；补给容量不足以完整容纳奖励时不结算，腾出容量后可以再领。

目前是六段独立开篇与一次回信的原型，尚未做成各含多场任务的完整支线。保飞派、倒飞派的代表与完整玩法仍待补充。

## 蛤妈与旧自行车

阿飞达到 **7 级**、小酒瓶完成个人成长，两人存活在队时，在友好城镇打开“蛤妈与旧自行车”：

1. **邀请她继续同行**：小酒瓶继续作为原队员，装备与成长不变；本次夜话结束，没有告别奖励。
2. **放手**：先显示单独确认页，说明永久离队与装备回收。公共行囊必须能放下全部装备和包内物品，转移失败取消离队；成功后小酒瓶不再重新招募。
3. 放手后先读回忆，再选择 **留下旧车**（阿飞决心 +4、生命 +2）或 **推下山坡**（耐力上限 +5、先攻 +3）。只通过个人特性结算一次。

自行车目前是名册中的纪念物记录，不是可以装备、出售或掉落的物品。没有沿用旧版永久 ×1.5 经验；摧毁自行车也不是唯一有收益的选项。告别、回忆与纪念选择都是本 Mod 的虚构改编。

## 本轮美术

使用内置 ImageGen 新生成 **哇哇叫、豪气冲天、全力圈、飞碟** 四张透明图标，保留原图和实际提示词，导出为游戏用 56×56 PNG。采用粗轮廓、有限色块与中世纪图标语言，避免写实肖像。见 [美术与生成记录](../art/runtime/gameplay-v03/README.md)。

阿飞正常／嘉豪衣装、伤口与倒地图层和独立飞碟进入独立图集；头、发型、胡须、头部伤痕以及装备仍沿用原版，穿盔甲会正常遮挡衣装。飞碟使用转入前的身体路线，只在头顶加图层。蛤蟆路线战斗功能已经接入，但旧蛤蟆头接缝没有修好，**本版先使用原版外观**；没有把未通过检查的头部塞进包内。

当前有限衣装组合已在原尺寸拼接检查；图集打包后再解包，检查像素与定位一致。飞碟与头盔、状态标记、名册头像裁剪，以及实际倒地效果仍需在游戏中确认。其余 33 人没有在本轮批量生成新人物图。

## 构建与验收

运行 `python tools/build_gameplay.py`。需要 Pillow、本地原版游戏资源、Squirrel 工具、bbros 图集工具和 Node.js；`--game` 与 `--sq` 可指定路径。构建会同步人物故事与成长数据、导出美术、验证脚本和资源路径、执行行为测试，再生成 ZIP 并核对 CRC 与源码字节。

[代码](../src/) · [行为测试](../tests/gameplay/) · [验证报告](../build/gameplay-validation.json) · [打包报告](../build/gameplay-package.json) · [美术报告](../art/runtime/gameplay-v03/build/report.json)

模拟检查覆盖招募、编队、章节、付费契约、成长重复触发、六根与飞碟资格、重修、战斗技能短效、装备转移和美术生命周期。它们不能替代引擎内验证。首次实机应优先检查：

- 新起源与 F8 中文菜单、34 人成长分页，以及 40 人名册／10 人出战。
- 三条路线的战斗按钮、AP／疲劳／克朗消耗、团队范围和实际回合持续时间。
- 契约分次付款、嘉豪赞助、小酒瓶满仓取消与成功离队的装备回收。
- 六根只开篇不回信也能解锁飞碟，以及已离队伙伴的便笺。
- 世界与战斗存读档、旧版升级、重伤和昏迷幸存者、衣装与头盔、飞碟显示、其他起源隔离。

十人队伍的敌军规模、后期新人的培养成本、收费技能与契约赞助的经济平衡仍需实战调整。

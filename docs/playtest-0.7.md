# v0.7 装备叠加与起源修复

蛤蟆人专用立绘和头顶飞碟已停用。蛤蟆、嘉豪、飞碟转职及其技能、六根解锁、付费重修规则保留；蛤蟆使用正常阿飞外观，飞碟沿用人类阿飞的正常或嘉豪外观。旧蛤蟆画刷 ID 仅保留为人类外观的兼容别名，发行图集不再含飞碟装饰。

34 位成员的胸像内容从最大 108×124 缩到 88×100。现有画作经裁切、等比缩放后，在颈部拆成身体与头部两个互补图层：身体在护甲下，脸和自绘头发在护甲上、头盔下，武器、盾牌与其他装备按原版刷新。没有重新生图。尸体仍沿用整体胸像的倾倒方案，尚未完成与所有装备尸体的适配。

起源名改为“阿飞远征团”，介绍只保留三队长出发的剧情、招募、十人编队及成长分支。修正开局中断：原版基础属性叫 `Stamina`，但天赋枚举叫 `Const.Attributes.Fatigue`；旧代码混用名称导致阿飞创建失败。测试夹具也改用真实枚举。

## 验证

本机游戏 1.5.2.3、官方 DLC、现有中文包内置 Legacy Script Hooks 21.1。

- 已实际创建三队长新战役，进入世界地图，开局 3/40 人与 1800 克朗。
- 最终分层包已进入独立战斗：原版士兵与自绘成员同屏对照，剑盾、锁甲和全盔均正常显示，阿飞攻击后外观正常。
- 战场中的蛤蟆和飞碟路线展示位均为人类，无蛤蟆身体或头顶飞碟。
- 最终安装包再次创建新战役（种子 `LTXXTJFFHI`），正常进入世界地图；队伍界面显示阿飞、大谋、抹茶及其装备，黑旗名册可以打开。
- 测试日志无脚本错误。离线构建完成 16,233 项行为断言、脚本语法与图集像素／锚点校验。
- 用户随后接手操作，本轮没有继续自动执行开局卸装／重新装备步骤，不把这一项算作实机通过。

## 安装与边界

使用 [mod_afeix_expedition.zip](../dist/mod_afeix_expedition.zip)，新战役选择“阿飞远征团”。更新后需要完全退出并重启游戏。开发测试场景不随正式包发布。

已安装到本机游戏 `data` 目录，安装包与发行包 SHA256 均为 `1c50450648a27739dcc5645c48805414773c7a77c478171a6bcbaaa49259d21f`。临时测试 ZIP 已移到工程的 `build/playtest-equipment`，下次重启不再加载。当前游戏窗口留给用户；本局启动时已加载的测试插件要重启才会卸载。旧自动存档与测试前备份的 SHA256 一致。

这是本轮开局与人物渲染的定向验证，不代表长线任务、所有成员与全部头盔组合均已实机验收。小月牙、甜筒、美伢、瑶瑶牙的真人照片资料仍待补齐。

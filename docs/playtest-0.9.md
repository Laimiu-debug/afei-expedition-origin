# v0.9 城镇契约与短途送信

送信从城镇的原版契约栏接取。接受前可以查看目的地；接受后使用原版的活动契约、地图目标栏与收信城镇标记。抵达后弹出交付，确认领取 180 克朗，目标随契约结算清除。放弃使用原版任务界面，遵循原版违约规则。F8 只显示委托记录，不再领取或手动交付。

选点使用原版道路寻路设置，取最近的友好、存活、非军事城镇，实际道路长度上限 **30 格**。没有合适的短途路线就不生成模组送信，仍可接其他原版契约。这里限制的是模组新增的“短途送信”；原版“武装信使”等任务保持原有生成规则。30 格是初版平衡参数，不承诺固定行军天数。

每座城镇同一时间最多保留一份有效的短途送信报价。沿用原版同一时间只能承接一份契约的规则。收信地被毁或变成敌对时，可撤回这份无法履行的差事，不扣公司声誉或派系关系、不发报酬；主动违约仍使用原版处罚。

旧存档中未交付的 F8 送信委托会免罚撤销，随后可在城镇重新接短途委托。已完成送信与其他履约记录保留，新送信由原版契约报酬记录器计一次，不与旧计数叠加。送信途中打赢随机战斗也不产生全力圈额外报酬。

## 延续 v0.8 的探索规则

黑旗名册只收录已经认识的成员与实际触发的经历；成员不再按章节成批开放。各人满足自己的条件后，进酒馆相遇、完成交谈再邀请。转职、隐藏路线、水友来信、自行车在触发前不展示。普通转职文本也去掉了未发现的隐藏路线名称。

保留 v0.7 的人物缩放和原版武器、防具叠加；蛤蟆、飞碟使用人类阿飞外观，玩法保留。

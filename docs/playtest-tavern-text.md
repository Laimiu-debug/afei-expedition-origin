# 酒馆与信件文案修订

2026-09-27，本地文案修订。

## 酒馆里谁先出现

三位联系人按固定顺序介绍：小原大人、哈曼卡恩、四哥，分别要求累计完成 3、6、9 份委托。这里的累计包括本模组送信和原版已领取报酬的委托。每次进酒馆只展示一段尚未看过、且满足条件的故事。

这不等于开局第一次进酒馆必定遇到小原：人物成长对话、阿飞普通转职对话优先。可可、小龟、余初九留下的留言各自在曾经入队后开放，不要求先见过小原。四派随机事件和刘青松相遇使用另外的事件流程。

本次没有改变顺序、条件、奖励或存档标记。新伙伴仍在城镇招募栏雇佣，三位酒馆联系人不入队。

## 文案改动

- 重写小原、哈曼、四哥的酒馆会面，以及可可、小龟、余初九留下的留言，共六段、十二个选项及回应。
- 用具体的带队问题展开对话：听清队员提醒、打不过时撤退、让新人提问、请人帮忙先问有没有空、一起看走位、追击前确认人数。
- 去掉对白中的“承诺的边界”“不修改阵亡记录”等抽象表述和程序说明。三位伙伴的留言都明确是以前留下的文字和补给，离队或阵亡后阅读也能成立。
- 信件页分开显示回应与补给；已回应时显示所选内容和已领补给，隐藏准备回信的提示。
- 名册首页明确说明去城镇招募栏找新伙伴，酒馆用于会面和交谈。

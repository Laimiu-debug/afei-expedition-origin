# 阿飞远征团：完整胸像试玩 v0.4

日期：2026-09-26。环境：PC 原版《战场兄弟》＋官方 DLC、Legacy Modding Script Hooks、可显示中文的字体／汉化。

本版把当前 **34 名成员全部接入自制完整胸像**：每幅图包含自己的头发、脸、脖子与衣装，不再显示原版拼接人物部件。阿飞有正常、蛤蟆人、嘉豪三种主体，共 36 幅外观；飞碟继续作为独立头顶装饰，保留转入前的主体路线。玩法继续沿用 [v0.3 的成长、转职、六根与自行车规则](playtest-0.3.md)。这是完成离线检查的安装包，**尚未启动游戏实测**。

## 安装和入口

把 [mod_afeix_expedition.zip](../dist/mod_afeix_expedition.zip) 整个放入游戏 `data` 目录，不解压；替换同名旧包，一次只启用一份本项目玩法包。不要同时加载旧工程或 `afei_art_v1` 美术测试起源。需要 [Legacy Hooks](https://github.com/jcsato/modding_script_hooks)。本轮没有自动改动游戏安装目录。

新战役选择 **“阿飞远征团：完整胸像试玩”**。阿飞、王大谋、午夜抹抹茶三队长开局；世界地图 **F8** 打开黑旗名册，继续任务招募、十人编队、个人成长与转职。最多 40 人在册，1～10 人上场。眼子不再招募；旧档已存在的眼子保留原状，不计入当前 34 人新美术。

优先新开战役验收。起源 ID 与人物键没有更换，保存时暂时恢复原生外观字段，读取后重新接入自制图。此逻辑有离线测试，但原生存读档和 v0.3 升级没有实机确认；试旧档前备份存档与原 ZIP。之前的 [v0.3 包](../dist/archive/v0.3/mod_afeix_expedition.zip)和[打包记录](../dist/archive/v0.3/gameplay-package.json)已归档；不能据此保证新版存档可降级。

- 装备、技能、护甲值和掉落仍按原版规则计算。换装不会改变这套固定立绘；图中的衣服和装饰不能用来判断实际装备。请看装备栏和技能栏。
- 保留选中底座、行动箭头、士气、眩晕、控制和其他战斗提示。人物栏、招募与战后显示使用角色渲染路径，不另拼原版发型。
- 阿飞三形态使用既有较完整母图；飞碟独立叠在头顶。小酒瓶、李李、余初九沿用检查后的旧自制胸像，其余 30 人新画／按旧图重绘。旧归档不被覆盖。

## 受伤、倒地和复活

受伤继续显示完整胸像，伤势、生命值与状态提示照常；本版没有给每人另画伤口或断头版本。每张图的 `_dead` 与常态使用相同像素、不同中心锚点，运行时尝试旋转并缩小，表现为简化倒地胸像。

死亡回调保留原生掉落、统计、尸体数据和复活规则，只替换视觉装饰，并暂时阻止原版头脸飞散。战场尸体、战后伤亡小人和复活后的敌人均有整图处理。清理同格的 `Corpse` 装饰时，也会移除该格先前叠尸的视觉，不删除地上物品。若引擎不接受尸体旋转属性，保留整图并写警告；真正的旋转、朝向与落点仍需实机验证。

## 验收重点

1. 三队长开局及逐章招募后检查各人：无原版头发、脸或装备露出，头顶及两侧不裁切。
2. 装备／卸下护甲、头盔、武器和盾牌：数值、技能、装备栏改变，固定立绘保持；重伤、绷带、眩晕等状态不露出原版身体。
3. 普通转职及重修：蛤蟆和嘉豪主体正确切换；六根开放飞碟后，原主体保留且飞碟位置合适。
4. 战场阵亡、断头、战后伤亡显示与不死复活：不冒出原版脸、头发、盔甲；尸体位置和朝向可接受；掉落与复活逻辑正常。
5. 新档存读、世界／战斗切换、已备份 v0.3 存档升级；另开其他起源确认不受影响。

## 构建和记录

运行 `python tools/build_gameplay.py`。需要 Pillow、本地原版资源、Squirrel、bbros 图集工具和 Node.js。完整构建要求 36 幅源图都已选定、透明且 SHA256 与审核记录一致；仅技术裁切、等比缩放到 114×142，不补画或拆脸。图集打包后再解包，核对 72 个画刷的坐标和像素，随后检查脚本、行为和 ZIP 内容。

本轮结果：30 份 Squirrel 源码语法检查通过，11 组离线检查共 15,979 项断言通过；36 种外观／72 个画刷逐个解包核对通过。ZIP 共 39 个文件，CRC 与源码字节一致。所有这些均为离线验证。

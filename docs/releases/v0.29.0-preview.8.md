# v0.29.0-preview.8：大斗鱼血条与技能反馈

2026-10-03，内部版本72，完整主包，累计preview.6和本地preview.7的修复。

斗鱼恢复原来的大体型，尸体也保持原尺寸。仅斗鱼将固定原生血条替换为可单独定位的原版画刷精灵，血量和两条护甲放在头顶，圆形状态图标放在血条上方；继续读取原生角色的真实数值，跟随移动与镜头缩放。支持血条显示开关与悬停显示，雾中、死亡或离场时隐藏，头像和回合条不会带入血条。普通角色仍使用原版血条。

梦境阿飞装备真实电子烟，由饰品提供“抽一口”。满生命时不可用，受伤后最多恢复15生命，每战两次、冷却两轮；梦境装备随临时人物清理。

自制临时状态的小图标统一使用原版圆框画刷，技能按钮和详情保留原图。44项成员主动技能与晋升指令按类别补充施放浮标、音效和成功日志，获得临时效果的角色显示状态浮标。电子烟补少量烟雾，斗鱼礼炮补蓄力音、爆炸音与有限粒子；失败施放不会新增反馈或重复扣费。

150份脚本、46,218条离线断言、原生画刷和声音路径及JavaScript检查通过。328个包文件的CRC、完整清单和源码字节一致。独立场景用于定向检查血条位置及显示行为；这不代替完整梦境、现实祭场通关、所有技能逐项实战和音效试听验收。

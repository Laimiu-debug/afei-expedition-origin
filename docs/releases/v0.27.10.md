# v0.27.10 · 老马的垂直握把持握显示放大

2026-09-29 本地更新。主包内部版本49，存档Schema保持8。

用户实机确认v0.27.9的马头朝向已正确，但相较原版双手武器显得偏小。本版将“老马的垂直握把”的**持握显示宽高各放大50%，即1.5倍**，让马头和马踏蛤蟆造型更醒目。

调整作用于持握图集的显示矩形，普通与染血状态同步；现有PNG像素、朝向、角度和背包图标不变。围绕原握柄位置缩放，不以贴图中心放大，避免握柄随放大偏离角色。

技术记录：显示矩形从90×106变为135×159；相对于挂载坐标中的握柄点(0, -35)作1.5倍缩放。边界由left=-65 / right=25 / top=-59 / bottom=47改为left=-97.5 / right=37.5 / top=-71 / bottom=88，完整画布参数从130×142扩为195×213，offsetY保持35。源贴图仍为90×106，显示缩放由游戏引擎完成。

基础价值保持28,888克朗，战斗属性、商店补货、招募改动与其余玩法沿用v0.27.9。

安装包：[mod_afeix_expedition v0.27.10.zip](<../../dist/mod_afeix_expedition v0.27.10.zip>)。替换时只保留一个主包版本，按新建战役验收；DLC继续使用0.2.4。

验证：实际图集解包后的两种持握状态、1.5倍缩放、握柄坐标与画布边界均通过检查。安装包内123个Squirrel脚本语法通过，原版握把武器与商店流程的34条相关断言通过；284个文件的ZIP CRC通过。详见[本次验证记录](../../build/grip-v02710-validation.json)。放大后的游戏内观感尚待实机确认。

本次使用已验证的v0.27.9安装包为基线，仅替换武器brush显示定义和版本入口，其余282个文件逐字节相同。打包期间共享工作区另有招募节奏调整正在进行，配置和总表暂未同步，因此未重新导出该批未完成的招募数据；相关工作区文件保持原状，武器显示改动也已写入正式构建脚本，后续构建可继续保留。

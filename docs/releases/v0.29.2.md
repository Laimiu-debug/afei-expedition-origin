# v0.29.2：酒馆剧情弹窗更稳，删掉梦里的口头禅

2026-10-08，内部版本 80，完整主包。已发布官网和 GitHub，见[发布记录](publication-0.29.2.md)。

- 进酒馆后的剧情相遇不再只等一次：酒馆对话框动画没放完时会再等一会儿（最多约 5 秒），不会因为动画慢一拍就漏掉，也不会叠出旧的弹窗。
- 在友好城镇的酒馆里，就算城外有敌人，也能看交谈记录、做个人成长和根脉剧情的选择；营地和野外仍按原规则。
- 剧情被打断后，在酒馆里按 F8 会直接回到那段剧情；没有待续剧情时仍打开完整菜单。
- 梦里斗鱼一幕和开场营火那段删掉阿飞的“三、二、一，放轻松”，抹茶的回话随之改成“说得轻巧”。

剧情走向、数值、费用和触发条件不变。151 份脚本、46,736 条离线断言、原生资源、美术和 JavaScript 检查通过；332 个包条目的 CRC 与源码字节一致。酒馆弹窗时序和新文本还没在游戏里实机验收。

已经装了 0.29.1 的玩家直接替换主包即可，存档兼容。

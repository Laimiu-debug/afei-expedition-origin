# v0.28.11：委托种类统计

2026-09-30，已发布至BBMOD，内部版本61。

修复委托完成次数增加、种类却一直为0的问题。原版契约引用对象可读取契约类型，但旧代码先用成员存在性检查，错误地跳过读取；修复后在收款、完成结算时保存实际契约类型，并按不同类型去重累计。原版送信与阿飞送信均排除在人物招募所需的有效契约统计之外。

旧记录若没有保存契约类型，不能仅从完成次数推算过去完成过几种；已有履约次数保留，新完成的契约开始正常累计已记录种类。名册使用“已记录种类”的表述，有履约次数却没有种类记录时显示“暂无（旧记录未保存种类）”。契约后续清理为空类型时，不会覆盖此前已保存的种类。

包含此前觉醒文案精简、传奇蓝光握把、夜间酒馆F8、飞李不可仅限酒馆连续加点、Esc退出和接战卡死修复。阿飞哇哇叫音量增强仍需要独立语音DLC0.1.2。

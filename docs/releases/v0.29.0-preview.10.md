# v0.29.0-preview.10：超级火箭下落动画

2026-10-03，内部版本74，完整本地主包，包含preview.9的梦潮铺垫、头盔显示修复与十人分别配装。

原来的超级火箭只有红圈预告与爆炸烟雾。现在在下一次斗鱼回合，镜头先聚焦可见落点，一枚橙红筒身、黄铜尖头、带尾焰的火箭从高处垂直下落。约0.75秒后落到红圈中心，红圈清除、爆炸、冲击音效、镜头震动与七格伤害在同一落地回调中完成。隐藏落点保留相同伤害时序，但不移动玩家镜头或显示火箭。

火箭素材由内置ImageGen生成，透明原图、完整提示词与导出方法保存在[资源记录](../../art/runtime/douyu-rocket-v01/manifest.json)，实际atlas像素、锚点和原版格式解包验证见[美术报告](../../art/runtime/douyu-rocket-v01/report.json)。

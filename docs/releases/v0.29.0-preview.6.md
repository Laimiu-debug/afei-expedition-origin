# v0.29.0-preview.6：梦潮结局与斗鱼战斗调整

2026-10-03，已发布预览版，内部版本70。包含preview.4的梦境入口修复与preview.5的介绍文案调整。

梦境最终统一由梦潮收束：斗鱼幕第三轮结束、提前击败斗鱼、败战及撤退都会让梦中十人倒下，再接回现实三人；幕间略过也先阅读全军覆没的梦醒页，再进入启程。前三幕胜利仍推进后续故事。剧情杀仅作用于临时角色，现实人物、装备、资源与时间按进入前状态恢复。

全队倒下前先清空原版回合条及其前端选人计时器，结束期间暂停原版战术更新，短暂停留后只退出一次。修复连续原生死亡回调仍试图查询已经移除角色的界面错误。

完整对战还复现了角色在回合开始时死亡后，原版回合条保持选择锁的问题。新增仅作用于梦境与现实斗鱼战的修复：移除队列里的死亡角色，清除旧选人计时器并重新展示存活顺序，由原版回调继续推进；存活角色的AP、疲劳、行动顺序不重设。清空队列时同时作废已发出的旧头像查询，阻止迟到结果更新已经移除的界面。回归测试直接运行安装游戏中的原版回合条。

斗鱼以10–12名11级且装备完整的队伍为挑战目标：4800生命、600/450护甲、9AP，近攻110、远攻85、近防22、远防14；半血后输出提高20%，组合技只触发一次。撕咬110–135、点名110–135、弹幕45–65、火箭125–155。区域蓄力累计受到700点实际生命与护甲伤害可打断，仍保留提前预告、走位规避、正常盾防与命中、毒和流血。火箭落地或打断后的破绽使受伤提高35%，到下次自身回合开始时结束。打断后下一次自身回合改用普通撕咬，随后才重新蓄力，避免持续集火取消所有输出。没有回血、无限增援或额外AP。

实机中，4200生命、500点打断、85–110撕咬的初稿被十名11级传奇配装角色连续两场在第十一轮击败，均无阵亡且损耗很低，因此进一步提高到上述数值。普通撕咬的护甲伤害为110%、直接伤害比例为25%。历史包与最终包的样本分别保留指纹，不混算为最终版验收；原生角色AI的顶配样本不能换算成普通装备队伍或玩家胜率。

调整后的完整原生AI对战在第十四轮正常击败斗鱼：十人剩五人，队伍总生命371/1075、存活者护甲2049（初始4176）。没有使用强制击杀、回血或属性重设；回合开始死亡自然触发回合条修复后继续战斗，该完整对战区间日志没有脚本或界面错误。此样本与最终包的战斗数值、技能、AI和Boss实体字节一致；最后只补上异步头像查询取消，相关收尾独立实机复测。此样本验证了高损耗下仍可战胜，不能单独确定普通配装和多阵容胜率。

最新包已实机复测幕间略过、战斗菜单撤退、第三轮结束和强制提前击败斗鱼后的剧情杀；另外复现回合开始死亡，回合条恢复后继续推进并正常梦醒。四次战斗返回的现实人物与主要资源快照均完全一致，最新日志没有脚本或界面错误。启程文字实际显示无装备奖励剧透。强制击杀用于检查结局，不能作为正常战斗击杀或强度证据。完整原生AI对战、每轮生命与护甲、包指纹及清理记录另见[实机报告](../../build/douyu-balance-0.29-preview.6.json)。

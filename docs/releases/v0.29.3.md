# v0.29.3：修复 MSU 环境下斗鱼回合卡住

2026-10-09，内部版本 81，完整主包。

同时安装 MSU 1.9.0 时，梦境战轮到“斗鱼·深渊之主”可能卡住，日志出现 `the index 'onBeforeExecute' does not exist`。斗鱼初始化 AI 时清空了原有行为，但 MSU 仍保留旧登记，导致移动、挣脱和待机没有重新加入；没有可用攻击时，回合无法继续。

现在通过原版 `removeBehavior()` 逐个移除旧行为，让 MSU 同步清理登记，再加入斗鱼的完整五类行为。修复同时作用于梦境战和现实梦潮祭场，斗鱼数值、技能费用和梦境剧情时限不变。游戏登记的内部版本号也同步为 81。

新增 98 条 AI 兼容回归断言，覆盖装有和未装 MSU 时的初始化、远处目标、特殊攻击、行动点耗尽及正常待机收尾；使用本机游戏原生 AI 脚本和 MSU 1.9.0 的行为登记规则。全部 151 份 Squirrel 脚本、46,834 条离线断言、原生资源、美术和 JavaScript 检查通过。尚未完成群友整套模组组合的实机复测。

退出游戏后替换完整主包，只保留一份 `mod_afeix_expedition.zip`，不用解压。本次未改存档格式；已经卡住的战斗需要退出后读取战前存档，重新进入。体验完整梦境开局请新开战役，旧阿飞存档可以在安全地点按 F8 → 再赴梦潮回看。

# v0.29.0-preview.11：黑潮吞没的收尾动画

2026-10-03，内部版本75，完整本地主包。包含此前的火箭下落、梦潮铺垫、头盔显示修复和十人分别配装。

最后独白读完或按Esc关闭后，蓝黑水面带着波纹与浪沿，从画面下沿和两侧推进。先用约2.4秒漫过地面，然后让存活的梦中队员每隔0.1秒逐个倒下，三位队长留到最后、阿飞最后倒下。3.4秒后画面逐渐淡黑，整段约4.6秒，通过原版加载流程接回梦醒。五轮结局、提前击杀、失败、菜单撤退和退出使用各自独白，再衔接同一演出。

独白和演出期间暂停输入、回合与并行AI。计时使用真实时间，暂停菜单退出也能继续；只有带梦中角色标记且仍存活的临时人物参与倒下。没有前端循环计时器或延迟死亡事件遗留到下一场战斗。演出结束、战术状态销毁、梦境恢复与新建/读档边界会清理水层；前端拒绝过期或重复消息。

153份Squirrel脚本、46,649条离线行为断言、JavaScript、原版资源与美术检查通过；其中黑潮原生流程201条、前端生命周期24条，覆盖阅读先后、逐个倒下、暂停、帧跳跃、异步消息过期、状态退出和真实队伍恢复。生产动画代码还由真实Canvas渲染器生成5个时点的像素帧并人工检查，最终帧确认全黑。浏览器预览工具未能启动；Canvas画面预览不是游戏原生CEF或实机结果。游戏中的层级、实际死亡画面、加载衔接与完整战役仍待验收。

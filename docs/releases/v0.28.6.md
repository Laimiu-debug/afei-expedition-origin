# v0.28.6：飞李不可野外加点修复

2026-09-30，内部版本56，已发布至BBMOD。见[发布记录](publication-0.28.6.md)。

v0.28.5已缩短加点流程，但付款仍沿用其他战团事务的城镇／扎营检查，导致野外打开F8名册后点击属性被拒绝。v0.28.6为飞李不可建立独立检查，**世界地图上的野外也能直接加点，不必扎营或进入酒馆**。接战、战斗、加载和世界状态未就绪时仍拒绝扣款。

选好角色后，点击属性按钮即支付100克朗并永久增加1点基础属性，留在当前页连续操作。付款结果及资金不足等失败原因放在属性列表上方。招募、研习、编队和剧情继续使用各自的地点规则；v0.28.5的Esc退出和接战卡死修复继续保留。

[完整主包](<../../dist/mod_afeix_expedition v0.28.6.zip>)。专项检查使用原版事件复制与按钮输入，在无城镇、未扎营的状态下点击八项属性，核验单次付款和属性变化；另外检查世界状态、接战、加载、余额、过期按钮、付款回滚和属性保存。

完整检查通过124份Squirrel脚本、33,321条离线行为断言、原版资源及JavaScript检查；其中飞李不可746条断言。287个包文件通过完整集合、CRC与全部源码字节核验。按用户要求，官网发布只确认版本、说明和下载入口，不下载公开压缩包与本地比对。

本地包及离线检查记录见 `build/gameplay-validation.json`、`build/gameplay-package.json`。当前游戏正在运行时不会替换其加载中的ZIP；完全退出后才能安装新版。野外加点实机验收仍待复测。

# v0.28.8：夜间酒馆 F8

2026-09-30，已发布至BBMOD，内部版本58。

## 修复行为

已进入友好城镇后，白天和夜间在酒馆按F8均可打开黑旗名册。原逻辑在城镇界面仍调用世界地图事务的安全检查，附近敌人或地图位置条件可能拦截开界面；本版使用原版城镇界面中的实际城镇判断。

Esc关闭名册后回到原酒馆，重复F8不会叠加界面。人物栏、加载、接战、战斗、已有事件、城镇切换动画和不能取消的菜单仍会拦截；被拒绝时不改变名册页面或酒馆记录。

飞李不可仍只能在酒馆内使用，100克朗加1点基础属性，可同页连续点击。其他事务的确认条件沿用各自检查；`canManage()`未修改。

## 证据与边界

现场日志多次记录 `Ledger blocked: another menu or unsafe town`，当前游戏加载的是v0.28.5（内部版本55）。旧日志给出的是联合拦截原因，不能单凭这一行区分城镇可见状态、附近敌人和地图位置。

使用旧名册代码、生产安全检查和本机原版F8／Esc／菜单栈，离线复现夜间已在酒馆、附近有敌人时F8被拒绝。修复后原版UI回归188条断言通过，覆盖昼夜、附近敌人、重复F8、Esc恢复酒馆、人物栏、动画以及拒绝时无页面副作用。

全量检查通过124份Squirrel脚本、33,464条行为断言、原版资源路径和JavaScript检查。完整主包287个文件，ZIP条目集合、CRC与源码字节核验通过。仍未在游戏引擎中复测夜间酒馆；离线回归不代替实机验收。

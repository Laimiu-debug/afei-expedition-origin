# 阿飞远征团 v0.20.0 · 公开试玩版

阿飞、王大谋、午夜抹抹茶带着黑旗启程，在原版世界地图接取契约、参加战斗、结识伙伴。最多 40 人在册，每场自由安排 1～10 人出战；世界地图按 F8 打开黑旗名册。

## 本次更新

- 新增 10 个可重复随机事件、30 个选项及独立后续。四派各有新相遇，伙伴日常包括查账、收零件、看地图、下棋、练舞与记事。
- 事件按行军、营地或城镇及在队人物开放；第 3 天起可抽中，共享 1.5 天间隔，单事件冷却 8～10 天。
- 物资交换支持容量及金钱检查，失败不先扣款；同一事件重复点击不重复结算。

相较网站此前的 v0.16.1，本包还包含此前在本地完成的更新：伙伴 7 级专属技能三选一、11 级自动精通与平衡调整，部分人物胸像及技能图标更新，四派随机相遇、刘青松两段相遇（不可招募）、红装“老马的垂直握把”、小龟体质，以及人物与成长路线的后续对白。旅途对白现合计 32 段、75 个选项。

## 安装与存档

1. 目标环境为 PC《战场兄弟》1.5.2.3 与官方 DLC。
2. 需要 Legacy Modding Script Hooks（`mod_hooks`）及中文字体／汉化环境；已有正常工作的 Hooks 时不要重复安装副本。
3. 完全退出游戏，将 `mod_afeix_expedition.zip` 整包放进游戏 `data` 文件夹，替换同名旧包，**不要解压**，也不要把两个版本改名后一起加载。
4. 重新启动游戏。新战役选择“阿飞远征团”；已有本项目战役可继续读取，更新前建议保留旧档备份。

存档依赖本 MOD。不保证与 Legends、Reforged 或其他改动编队、人物图层的 MOD 兼容；不要同时加载旧工程或阿飞美术测试起源。

## 验证范围

完整构建通过 26 组离线测试，共 20,777 条断言，其中新随机事件测试 356 条；通过 67 个 Squirrel 脚本编译、原版资源检查、图集校验、JS/Python 检查，以及 ZIP CRC 与源文件一致性检查。

v0.20.0 已安装到开发机，但本批尚未启动游戏验证。新增事件的弹窗排版、自然触发频率、实战与长期平衡仍待验收。本版为开发试玩版。

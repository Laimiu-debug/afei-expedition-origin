# v0.26.2：全表实装复核、重甲55与希文招募

本版以新建战役为准；后续每次打包更新均遵循这一口径。同一版本正常保存与读取仍保留候选、技能和事件状态。

- 重甲缓冲目标从25改为55，口径是11级按总表培养、普通320身甲/300头盔、双手武器及包内负重、已学壮实。9名相关人物均值为55～62；随机升级不保证每次相同。
- 重新分配阿飞、小酒瓶、眼子哥、玩蛇、千涵、宋暖阳的基础值与30项培养。阿飞取消额外逐级+30耐力，改为基础106与6次普通疲劳升级，11级均值124；小酒瓶也取消等级加成，将决心三星移给疲劳；基础109加4次普通三星疲劳升级，11级均值127。

- 补级按人物所属招募阶段封顶，晚招早期人物不会获得后期阶段等级。补级属性与专长点未分配，不赠个人参战记录。
- 飞碟揭晓与转职门槛统一为9级/12次个人战斗/个人成长完成/六根开篇。修正永久路线属性占用临时命中+10预算的问题。
- 35人属性、星数、70个固定特质、70条个人成长选择、全部招募装备与门槛、102个技能、3条路线按工作簿逐项检查。原有自行车、电子烟、曹飞派、握把与宠物规则随包保留并回归检查。

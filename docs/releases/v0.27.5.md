# v0.27.5：修复人物背景消失

2026-09-29 已发布至 [BBMOD 作品页](https://bbmod.site/mods/d64a00f6-1d60-4d8d-8d9b-de055fc0b748/)，[直接下载修复主包](https://bbmod.site/files/553f6536-30b0-4671-938b-ce134c2a91dd/download/)。[网站发布记录](publication-0.27.5.md)。

修复创建人物时清理随机特质误删背景的问题。原版背景类型同时包含 `Background` 与 `Trait`；V2 清理使用了特质位掩码，导致背景从技能容器中移除，但人物仍保留原背景对象引用，因此旧测试未发现界面列表里已经没有背景。

现在与原版人物的随机特质筛选一样，仅匹配类型恰为 `Trait` 的普通特质，并继续保留个人专属特质。背景图标、身份名、介绍及正常背景工资计算恢复。人物八维、星级、固定特质、招募、装备、技能、事件与老马握把数值保持既定设置。

新增检查已先在修复前复现阿飞的背景显示查询为空，再验证全部 34 名主包人物与可选 DLC 希文。覆盖原版背景类型、原版容器显示查询、图标和介绍、工资回调、固定特质、表格八维、重复同步、原版背景序列化。测试中使用原版背景与查询代码，人物引擎接口和固定特质增量仍由离线夹具提供，不属于实机测试。

主包通过 **28,849** 项离线断言，背景回归组 **1,502** 项；DLC 相关检查 **5,587** 项通过。283 个包内文件通过 CRC 和源码核对。相比 v0.27.4，仅平衡特质筛选脚本和内部版本号变化；总表及 DLC 压缩包字节不变。此前食尸鬼战斗闪退仍未确认修复。

请完全退出游戏，将新 ZIP 放入 `data`，不解压，移走旧版本主包，并**新开战役**。本次不做旧档迁移。需要 Legacy Modding Script Hooks（`mod_hooks`）及中文字体／汉化环境。

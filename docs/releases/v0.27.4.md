# v0.27.4：老马握把固定红装数值

按作者指定更新老马的垂直握把：

|属性|v0.27.3|v0.27.4|
|---|---|---|
|基础伤害|75～95|84～120|
|穿甲比例|50%|70%|
|护甲伤害效率|210%|235%|
|破盾伤害|26|52|

保留曹飞派领袖老马化身的介绍、单体命中后额外削甲30、负重-18、耐久100、价值12000与商店补货规则。四项数值固定，不再进行原版红装随机增幅。70%是穿甲比例；52是破盾伤害，与专属追加削甲30分别结算。

本机原版名锤的伤害增幅上限为78～117、穿甲上限66%、破甲上限230%；破盾上限为52（原始26乘最大2倍），不是47。原版只抽取两项增幅。本版直接使用用户指定的四项固定值。

修正本武器破甲效率提示的浮点取整问题：原版floor(2.35×100)会显示234%，现在显示235%；战斗倍率仍为2.35，没有更改其他武器提示。

新增17项原版武器回归检查，覆盖继承后的属性读取、完整物品提示及原版破盾技能实际造成52点盾损伤。主包28,203项离线断言通过；DLC相关4,276项通过。283个主包文件通过CRC和源文件核对，相比v0.27.3仅武器脚本和版本标识变化；人物总表与异教徒转化机制保持不变。2026-09-29 已发布主包至 BBMOD，公开下载与本地包逐字节一致，见[网站发布记录](publication-0.27.4.md)。未实机试玩、未更新本机游戏安装包，按新战役使用。

安装前完全退出游戏，将 ZIP 整包放入游戏 `data` 目录，不要解压；替换同名旧包，并移走以前带版本号的本 Mod 旧包，只保留一个版本。需要 Legacy Modding Script Hooks（`mod_hooks`）及中文字体／汉化环境，新建战役选择“阿飞远征团”。网站下载文件名固定为 `mod_afeix_expedition.zip`。本轮未确认修复此前的食尸鬼战斗闪退。

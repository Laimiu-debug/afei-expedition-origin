# v0.27.3：老马握把加强与异教徒转化核查

老马的垂直握把小幅加强，并明确为曹飞派领袖老马的化身。

|属性|更新前|更新后|
|---|---|---|
|基础伤害|70～90|75～95|
|护甲伤害|200%|210%|
|单体命中追加削甲|最多25|最多30|

穿甲50%、负重-18、耐久100、基础价值12000、商店自然补货5%沿用原规则。原版单体锤击另加20伤害；追加削甲在普通伤害后结算，只作用同一部位剩甲，不能溢出为血伤，横扫、反击和免费攻击不触发。

游戏内新介绍：

> 曹飞派领袖老马的化身，一身风骚尽在这根握把。马头一昂，蛤蟆低头；握把一挺，铁甲开口。阿飞嫌它不正经，老马笑得更灿烂：‘飞哥，站稳了——我这一下，专治嘴硬甲也硬。’铁匠叮嘱双手握紧，掌柜补了一句：盔甲可以再买，矜持就别带上战场了。

异教徒转化机制本轮没有改动。当前34名主包队员加希文共35人，正常状态下30人符合原版目标条件；阿飞、午夜抹抹茶、白小帅子、童猪、希文因聪慧被排除，仍保留原版脑损伤或非贵族愚笨等例外。至少4人在队，另需原生异教徒或皈依者传教，事件抽中并允许后才会转化。命名队员初始无人担任传教者。王大谋虽为队长，也可转化。

已用本机原版事件逐人检查，并执行接受皈依的回调，确认背景ID变为皈依者，原人物身份、经历、属性、等级、装备和技能/剧情进度保留。具体名单、例外与证据见[转化检查](../design/cultist-conversion.md)。

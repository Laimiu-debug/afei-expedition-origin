# v0.29.0-preview.12：横扫战场的黑潮

2026-10-03，内部版本76，完整本地主包。包含此前的火箭下落、梦潮铺垫、头盔显示修复和十人分别配装。

最后独白读完或按Esc关闭后，黑色浪墙从右往左刮过战场。浪头带着长条潮雾、侧向飞沫和透明尾流，在约2.4秒内扫出画面。随后存活的梦中队员每隔0.1秒逐个倒下，三位队长留到最后、阿飞最后倒下；3.4秒开始淡黑，整段约4.6秒接回梦醒。后端方向参数支持整层镜像的左往右，游戏默认右往左。

独白和演出期间暂停输入、回合与并行AI。真实时间推进演出，暂停菜单退出也能继续；只有带梦中角色标记且仍存活的临时人物参与倒下。战术状态销毁、梦境恢复及新建/读档边界会清理动画层；前端拒绝过期、重复或倒退的消息。

153份Squirrel脚本、46,659条离线行为断言、JavaScript、原版资源与美术检查通过；其中黑潮原生流程205条、前端生命周期与方向30条。生产动画代码由真实Canvas渲染器生成7个时点的画面帧，像素检查确认右边进入、左边退出，反向镜像正确，2.4秒尾流完全离场，最终帧全黑。0.6秒和1.2秒画面已人工检查。

[横扫动画代码预览](../../build/dream-tide-preview.12/preview.html)使用静止的历史战场参考，可切换两个横扫方向，未展示原生角色倒下；[画面帧报告](../../build/dream-tide-preview.12/render-report.json)记录生产JS指纹与方向检查。[本次修订与安装报告](../../build/dream-tide-0.29-preview.12.json)记录检查、包与备份。

Canvas预览不是游戏原生CEF或实机结果，本版未启动游戏验收。游戏中的图层、实际死亡画面、加载衔接与完整战役仍待[实机检查](../playtest-dream-0.29.md)。本次已发布官网，公开下载校验通过；详见[发布记录](publication-0.29.0-preview.12.md)。

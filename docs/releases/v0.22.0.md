# 阿飞远征团 v0.22.0 · 公开试玩版

[BBMOD 作品页](https://bbmod.site/mods/d64a00f6-1d60-4d8d-8d9b-de055fc0b748/) · [直接下载](https://bbmod.site/files/ca83a7d7-c51d-4957-9fee-7ef7c14c7b1e/download/)

大地图行军与站立队伍图标替换为阿飞，随移动方向左右转向，保留玩家所选战团旗帜、原版帐篷和营火；收营后恢复阿飞图标。其他起源不替换，移动速度和寻路沿用原版。

本版包含 v0.21.0 的战死与结局更新。倒地人物保留原版躯干、护甲和头盔，36 组外观新增专属倒地头部资源，按颈部连接点重新定位，修正仰倒方向及镜像角度；昏迷与复活保留人物身份，特殊死亡不会补回完整头部。本轮没有逐人重绘闭眼表情或新增专属断头动画。

新增 8 种退隐与败亡主结局，34 人各有两种退隐后续和阵亡纪念，共 102 段个人文字；另有 11 段阿飞缺席／路线、六根和自行车回应。按真实在册、生死和已完成选择生成后续，未招募成员不出场。本版也修正了结局在原版资产管理器上的注册入口。

重写小原、哈曼、四哥的酒馆相遇，以及可可、小龟、余初九的旧留言，共六段、十二个选项及回应；保留触发顺序、奖励和存档标记，信件页分开显示回应与补给。沿用此前人物背景、随机事件、技能、平衡和修复。

安装：完全退出游戏，将 `mod_afeix_expedition.zip` 整包替换游戏 `data` 目录下同名旧包，不解压，不同时加载多版本。需要 Legacy Modding Script Hooks（`mod_hooks`）及中文字体／汉化环境。重启后可直接读取本项目旧战役，无需重新开局；更新前建议备份存档。进行中战场已经生成的旧尸体不会即时重绘。

目标环境为 PC《战场兄弟》1.5.2.3 与官方 DLC。存档依赖本 MOD，不保证与 Legends、Reforged 或其他改动编队、人物图层的 MOD 兼容。

22,057 条离线断言、脚本编译、原版资源、图集像素／锚点回读、ZIP CRC 和逐文件源码一致性检查通过。本轮尚未启动游戏验收倒地锚点、头盔变体、大地图动态图标及结局滚动排版；离线合成图不是游戏截图。

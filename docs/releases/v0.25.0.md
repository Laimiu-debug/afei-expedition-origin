# 阿飞远征团 v0.25.0（2026-09-29 战团事务更新）

安装包：[mod_afeix_expedition v0.25.0.ZIP](<../../dist/mod_afeix_expedition v0.25.0.ZIP>)。已发布至 [BBMOD 作品页](https://bbmod.site/mods/d64a00f6-1d60-4d8d-8d9b-de055fc0b748/) · [直接下载](https://bbmod.site/files/7c1f8aed-e3f0-4ca3-9051-3487ca0cc870/download/)；GitHub Release 仍为 v0.16.1。已安装早先 v0.25.0 的玩家请重新下载并覆盖，版本号仍为 0.25.0。

网站当前下载名为固定的 `mod_afeix_expedition.zip`，与本地带版本号包内容完全一致。网站下载可直接覆盖同名旧包；若使用本地带版本号包，按下面步骤安装。

1. 完全退出《战场兄弟》。
2. 将 `mod_afeix_expedition v0.25.0.ZIP` 直接放入游戏 `data` 目录，无需改名或解压；保持原有必要依赖。将之前的本 Mod 旧包移出 `data` 目录（包括无版本号的 `mod_afeix_expedition.zip`），只保留这一份，避免重复加载。
3. 重启游戏后读档。已有 v0.24.0 或此前 v0.25.0 战役可继续使用本轮更新；本轮不再变更角色名单和存档格式，更早版本仍受 v0.24.0 删除陈知含的兼容限制。

本轮修复随机事件错误阻断 8/8 野心结算；新增五款可切换蛤蟆公司旗与原版战旗外观；友好集市、武器店自然补货各有 5% 概率出售“老马的垂直握把”；黑旗战团出战上限为 12 人，名册容量仍为 40。

野心需要回到允许触发事件的安全大地图并继续走时；商店需要等下一轮自然补货。更新不会立即刷新全部库存，反复开关商店也不会重抽。

F8 → 战团事务 → 更换旗帜，可选“建团时选择的旗帜”，以及正面踩球、侧身踩球、圆章蛤蟆、黄金天使蛙、首版黑金蛤蟆。六个选项分两页显示，新增四款均含电子烟与足球。换用任意自定义旗后，都可再改回建团原旗，也可反复切换。没有设置过样式时默认使用建团所选旗帜，已保存的自定义选择继续生效。原始旗帜编号始终保留，选择随存档保存，大地图旗、UI 旗、手持战旗和物品图标同步更换。手持战旗仍通过原有渠道获得。

F8 → 战团事务新增“隐藏全队头盔／显示全队头盔”，仅改变在队成员的外观。头盔仍然装备，防护、耐久、疲劳、技能和掉落不变。正常与破损头盔外观一起隐藏，闭面盔隐藏后显示人物头部；恢复时显示当前装备的头盔。设置随存档保存，新招募成员继承，不影响敌人、未雇佣候选人与其他起源。默认显示，战斗中不可通过名册切换。

**食尸鬼战斗闪退尚未确认修复。**已核查截图死亡掉落堆栈，但现场在其他电脑且没有对应日志，不能确认具体异常原因。

114 个脚本、39 组测试的 24,255 条离线断言、资源及 ZIP 检查通过，尚未实机验收。详见[处理记录与验证范围](../playtest-0.25.md)、[本次网站发布记录](publication-0.25.0-company.md)。

四款新增旗帜已经转换为游戏尺寸并打入上述 Mod，无需另装素材包。原始透明图和提示词仍保存在 `art/runtime/banner-v25/variants/`，用于后续美术修改。

后续分发压缩包名称统一使用空格加版本号、`.ZIP` 后缀。游戏打包命令 `python tools/build_gameplay.py` 从根目录 `VERSION` 读取版本，输出 `dist/mod_afeix_expedition v<版本>.ZIP` 及同名 `.sha256` 校验文件；升级版本时先更新 `VERSION`。游戏可直接加载这个文件名，安装时不需要改名。

如需另存原图，`python tools/package_banner_variants.py` 也读取 `VERSION`，输出 `dist/afeix_banner_variants v<版本>.ZIP` 及校验文件；它只供美术素材归档，游戏所需资源已包含在 Mod 中。

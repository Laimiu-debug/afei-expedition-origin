# v0.28.13：小龟血量、缩头乌龟与头盔遮挡

2026-10-02，已发布至BBMOD，内部版本63。公开下载与本地完整主包、源码一致。

[官网下载](https://bbmod.site/files/836c50e6-dc27-4b3a-8450-dfce74584d20/download/) · [发布记录](publication-0.28.13.md)。请退出游戏后替换旧主包，仅保留一个版本；按新建战役验收。本轮未安装或进行实机复测。

小龟1级基础生命由54提高到69，净增加15点；该数值已包含固定肥胖特质的10点生命，创建时基础反推为59，避免重复加血。其余基础属性、星数、招募规则与觉醒保持原设置。原培养方案11级平均裸血由78变为93。

取消入队赠送钢头，新增独立常驻特性“缩头乌龟”：

- 每次有效头部命中，25%概率免疫本次生命、护甲和受击疲劳伤害。
- 未免疫的75%转移为身体命中，交给原版流程使用身甲、攻击的身体伤害倍率、身体伤势表及对应护甲物品结算。不会按无头甲爆头伤害计算，也不会获得割耳朵等头部伤势。
- 保留禁戴头盔、近防与远防各+5，以及躯干直接武器伤害减少20%；转移后的武器伤害同样受厚壳保护。撤下此前独立的头部50%减伤。
- 原本的身体命中、流血与毒等持续伤害沿用既有规则。转移后的重击仍可能造成身体伤势；该特性不是全身伤势免疫。

已有免费钢头在首次同步时移除一次；之后玩家自行学习的钢头不会被反复删除。属性版本验收仍以新战役为准，既有伤势不会自动治疗。

数值源、运行脚本、总表与当前人物属性文档已同步。总表保留16个工作表、3480条公式和35个原生图表，仅改小龟生命输入和对应定位说明，相关计算与图表缓存随输入更新。

主包33名可戴盔角色的原画按脸、颈部和头发轮廓拆层，沿用原版已有的身体、头部与头发图层，不新增人物图层。不戴盔时重新合成与原画像素完全一致；戴开面盔按 `HideHair` 隐藏发型，戴全罩盔按 `HideHead` 隐藏头部和发型。原有隐藏头盔按钮保留，隐藏时恢复完整原画。戴盔尸体与伤口同步使用去发版头部，未戴盔尸体保留原发型；断头前恢复原版资源，复活保留原角色身份。可选美术DLC的独立外观仍使用原有完整贴图，不纳入本次33人的轮廓拆层。

新增231个画刷，逐一验证实际安装图集解包后的像素与锚点。轮廓源为 `art/runtime/helmet-layers-v01/contours.json`，生成工具为 `tools/build_helmet_layers.py`。参看[离线装备对照](../../build/helmet-layers-20261002/review-1.png)，各列为修复前、开面盔、全罩盔、恢复发型。这是离线合成预览。

离线验证通过35249条断言、125个Squirrel脚本编译及原版资源路径检查。新增测试调用本机原版完整受伤方法，验证免疫、身甲扣除、穿甲、身体伤势、攻击身体倍率、原版角色与其他起源隔离，以及嵌套攻击/异常后的临时状态恢复。美术行为测试覆盖33人的头盔遮挡、隐藏按钮、存读档、保存异常、魅惑翻转、战死、断头、复活与资源缺失回退。

这不是实机验收。开局首次移动停顿仍无计时采集；现有日志无脚本错误且没有诊断标记，尚不能确定原因。下一步需带首次移动诊断包重启游戏，新开战役后首次移动并保持大地图运行12～15秒，再解析日志。参看[诊断用法](../../tests/engine/first_move/README.md)。

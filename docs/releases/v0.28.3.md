# v0.28.3｜小龟玄武血脉限制与提示

2026-09-30，本地构建，尚未发布至 BBMOD。

- 触发条件仍为战场上存活、未濒死且仍在地图内的友方只有阿飞与小龟，并至少还有一名敌人。友军 NPC、战犬计入友方；待命、尸体、濒死和离场单位不计。不限阿飞转职路线，主动只带两人出战也满足条件。
- 每场最多一次。觉醒后小龟须再完成 **5 场未觉醒的参战胜利**，第 6 场后续战斗才可再次觉醒。觉醒当场、待命、撤退和失败不推进冷却。冷却和累计次数随人物存档保存；重复结算不重复计数。
- 触发后通过原版战斗对话弹窗说明本次觉醒、临时强化、战后恢复和冷却。首次与第二次使用独立文字，第三次起轮换三段文字。其他弹窗占用时延后显示，待显示标记支持战中保存读取，同一次觉醒只提示一次。
- 原有效果保持：生命上限 +400、疲劳上限 +120、决心 +100、近攻 +60、远攻 +40、近防/远防各 +100、近战伤害 ×1.5、疲劳恢复 +10，先攻最多 20；立即回满生命、清空疲劳并变为自信。战后移除强化，生命不超过原上限，不提供额外经验。
- 小龟长、短背景介绍中的“他”统一改为“她”。

离线验证涵盖触发条件、一次性恢复、战后清理、5 场边界、待命/撤退排除、重复结算、保存标记、弹窗排队与多次文案。真实游戏中的弹窗排版、暂停行为及完整战役仍待实机验收。

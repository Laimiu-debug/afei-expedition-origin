# v0.28.7：飞李不可仅限酒馆

2026-09-30，已发布至 BBMOD，内部版本57。

## 玩家用法

先进入城镇的**酒馆**，在酒馆黑旗页面选择“飞李不可”；也可在酒馆内按 **F8 → 战团事务 → 飞李不可**。选人后点击属性按钮，即支付100克朗并永久增加1点基础属性；加点后留在当前页，可连续点击。双攻、双防在“后四项属性”，按Esc退出名册。

**野外、扎营、城镇主界面及其他建筑均不可使用。** 在这些位置打开飞李不可会明确提示进入酒馆，不提供加点按钮。离开酒馆后点击旧按钮同样拒绝，属性与克朗均保持原样。

## 本次实现

- 根据当前原版城镇界面是否可见、当前建筑是否为酒馆及实际城镇状态判断位置。曾去过酒馆、在城镇附近或扎营均不能代替进入酒馆。
- 酒馆内手动F8即使没有自动酒馆记录仍可使用；每次付款再次检查位置。
- 酒馆熟人列表每页三人，新增飞李不可入口，连同翻页、关闭最多六个按钮，保持人物顺序和可达性。
- 保留一键付款、同页连续操作、结果置顶、过期按钮保护、属性保存和失败回滚，以及v0.28.5的Esc直接退出与接战卡死修复。

v0.28.6曾允许野外加点，该规则已被本版替代。其他招募、研习、编队和剧情仍沿用各自地点规则。

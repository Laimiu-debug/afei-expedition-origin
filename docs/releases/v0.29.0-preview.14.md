# v0.29.0-preview.14：黑潮铺满全屏，全游戏文本重写

2026-10-07，内部版本 78，完整主包。

## 黑潮全屏

preview.13 在游戏里还是只盖住屏幕左上四分之一（2560×1440 下最明显）。原因是游戏界面引擎 Coherent GT 按 1280×720 的位图画这一层，CSS 拉伸到全屏也没用；`window.innerWidth` 又会随 UI 比例缩小，不能拿来定尺寸。

现在后端每帧用 `Settings.getVideoMode()` 把游戏分辨率传给前端，画布按这个分辨率建，再把原来的横扫画面放大铺满。黑潮层也提到了战斗界面之上。

在游戏主菜单里用 1920×1080 和 2560×1440、140% UI 比例实测过：最终黑屏盖满整个窗口，2560 下浪头从上到下贯穿全高。[原生报告](../../build/dream-tide-native-probe/native-report.json) · [2560 横扫截图](../../build/dream-tide-native-probe/native-2560x1440-wave-0.6.png)。这次没有进战役，完整的倒下和梦醒流程还要在战役里再看一遍。

## 文本重写

游戏里的文字整体改了一遍，去掉“段尾讲道理”“处处转折”这类味道，按《战场兄弟》的口吻来写，再按每个人加上他们自己的梗。

- 梦境四幕、梦醒、启程和结局独白
- 34 人的人物介绍和招募相遇。相遇里不再每段都重复“原价邀请 / 招募优惠”的说明，选完后系统会自己显示花费
- 34 人的成长剧情、小酒瓶告别和自行车回忆
- 四派随机事件和旅途事件里收尾太“圆”的句子
- 8 种战团结局、经历回应和每人的退隐、阵亡后续
- 34 人的出身背景，改成只讲入团前的营生，不再和人物介绍重复

剧情走向、数值、费用和触发条件都没动。

## 其他

- 删除罗一可和眼子的专属后续剧情和专属结局。两人现在和其他伙伴一样，只有招募相遇和 3 级成长，头像和技能不变。旧存档里走过这段剧情的标记会留着，但不会再触发。

# 阿飞远征团 v0.16.1 · 公开试玩版

阿飞、王大谋、午夜抹抹茶三位队长一同启程，在原版世界地图上接取契约、参加战斗，并随着冒险结识和招募新的伙伴。最多 40 人在册，自由选择 1～10 人出战；成员拥有各自的成长与技能。未知成员和隐藏内容由玩家在游戏中探索。

## 这一版

- 修复世界地图附近有敌方队伍时，按 F8 无法打开黑旗名册的问题。危险地点可以查看；确认编队等操作仍要求安全地点。
- 沿用十人队伍强度上限，以及新战役高／中／低初始资金设置。
- 包含自制人物美术、装备叠加、城镇条件招募与成员技能。

## 安装

1. 目标环境为 PC《战场兄弟》1.5.2.3 与官方 DLC。
2. 需要 Legacy Modding Script Hooks（游戏内 ID：`mod_hooks`），以及可显示中文的字体／汉化环境。已有正常工作的 Hooks 时不要重复安装不同副本。
3. 下载 `mod_afeix_expedition.zip`，整包放进游戏的 `data` 文件夹，**不要解压**。替换同名旧包，不要将两个版本改名后一起加载。
4. 完全退出并重新启动游戏。新建战役选择“阿飞远征团”；已有本项目战役可以直接读取。世界地图按 **F8** 打开名册。

当前试玩版不保证与 Legends、Reforged、其他改动编队或人物图层的 MOD 兼容。不要同时加载旧工程或阿飞美术测试起源。游戏存档依赖本 MOD，卸载前请保留备份。

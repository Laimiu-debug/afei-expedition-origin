- **希文的圆圆化妆镜**：新候选随身装备，占饰品栏，无负重、不可出售。仅希文装备时决心 +20；一级本体 **21**、戴镜 **41**，默认个人成长后本体 24、戴镜 44。卸下、放背包或转交其他人物均不加成，不永久写入基础属性。
- **技能与路线**：主包 33 名伙伴共 99 个专属候选，DLC 增加希文后共 102 个；新增眼子哥三项专属技能。按总表更新技能成本、冷却、次数、目标、持续时间、精通和阿飞三条路线；路线不再重写天赋。技能图标和镜子物品图标已随包提供。
- **共同限制**：本 Mod 正向命中加成合计最多 +10，负面另扣；条件被动近防最多 +6，临时护卫近防取最高且最多 +8；群体最多 3 人并按固定顺序选择；每人每轮额外恢复最多 8。原版基础恢复不计入该上限，尼古丁按独立每战一次及后续恢复债务处理。减疲劳取最高一份，武器技能至少支付原费用的一半；特殊位移不返 AP、不追加攻击。

里根继续使用原版战犬机制，新战役随阿飞开局；既有剧情、四派事件、六根、自行车、结局和 F8 修复保留。未新增派系身份或把刘青松变成可招募人物。

## 旧档处理

基础八维只迁移新旧差额一次，保留已分配升级点、名字、装备、伤势、故事进度和已选技能。天赋更新只影响尚未分配的普通升级行及未来升级，不回收已分配点、不重掷老兵升级。

旧档额外或互斥的原版特质保留；遇到互斥项时跳过对应新增固定特质，并保留迁移标记。因此旧人物可能与新档标准模板有差异。已雇佣人物不补级、不补招募装备、不返差价，**旧档已有希文不会自动补镜子**。已有候选保留原报价；新候选按新公式与首次生成的固定等级计价。技能次数、冷却、恢复额度和经济领取记录随存档保存。

已做隔离环境中的迁移和序列化回归，尚未用真实玩家存档实机验收；保留原存档副本后试玩。

## 安装包

1. 主包：[mod_afeix_expedition v0.26.0.ZIP](<../../dist/mod_afeix_expedition v0.26.0.ZIP>)。
2. 要使用希文和里根，再放入 [DLC 0.2.0](<../../dlc/xiwen-regen/dist/mod_afeix_dlc_xiwen_regen v0.2.0.ZIP>)；它依赖主包 v0.26.0 或更新版，不能代替主包。
3. 保持 ZIP 原样放入游戏 `data`，移走同一 Mod 的旧版本 ZIP，避免重复加载。沿用现有 Legacy Modding Script Hooks 依赖。

原 v0.25.2 包及旧 DLC 包保留在工程中。本轮没有覆盖游戏安装目录或线上下载。

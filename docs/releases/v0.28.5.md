# v0.28.5：接战卡死修复与名册交互优化

2026-09-30，内部版本55，已发布至BBMOD原作品“阿飞远征团”。见[发布记录](publication-0.28.5.md)。

- 修复接战后每帧的小龟觉醒弹窗检查访问不存在的 `state.DialogScreen`，中断原版战斗更新。改为读取全局 `DialogScreen`，界面尚未初始化时延后弹窗。觉醒说明仍暂停战斗与AI，关闭动画和菜单返回完成后恢复原先暂停状态。
- 黑旗名册各页可按 **Esc直接关闭**，通过原版事件管理器清理当前页，并恢复大地图或城镇对话。取消未付款加点和未确认编队草稿；剧情事件沿用原版退出规则。
- 飞李不可选好角色后，**点击属性按钮立即支付100克朗并加1点基础属性**，留在当前页连续操作。显示钱包余额、按钮上的属性前后值与付款结果；保留每页四项属性与翻页。旧按钮在页面重建或退出后失效，每次点击重新检查资金和安全条件。
- 角色编号直接按名册匹配，支持有符号编号，避免把角色编号当作分页数字处理。

## 卡死证据与验证

使用本机原版 `tactical_state` 的实际字段布局复现：旧源码在接战更新时抛出同一异常。新回归不再给战斗状态伪造 `DialogScreen`，使用原版弹窗、暂停和菜单方法，验证无觉醒提示时继续原版帧更新、空界面延后、弹窗只出现一次，以及关闭后分别恢复战斗和AI暂停状态。引擎绘制与帧主体由测试替身模拟，尚未完成修复包实机战斗验收。

# v0.29.0-preview.13：修复黑潮的全屏覆盖

2026-10-03，内部版本77，完整主包。

修正黑潮只显示在左上角、覆盖范围随UI缩放变化的问题。画布改为body外的文档根层子元素，抵消根层缩放；采用明确的屏幕像素尺寸，再根据实际显示边界校准，并给右边和下边留2像素余量。画布像素仍按1280宽度上限绘制，再铺满屏幕，避免提高分辨率后工作量无限增加。窗口尺寸与UI缩放在演出期间发生变化也会重新适配。横扫方向、2.4秒黑潮与后续倒下、淡黑和梦醒时序保持preview.12。

真实浏览器读取本机原版main.css，检查1280×720、1920×1080、2560×1080和3840×2160，以及0.5、0.7071068、1、1.5、2缩放，共20组。画布显示范围覆盖整个视口，最终截图四角、四边中点与中心全部为不透明黑色；20组演出中实时改尺寸也覆盖新边缘。另以模拟半宽半高的嵌入浏览器布局，验证能从四分之一面积重新校准到全屏。

检查报告：[真实浏览器布局与像素](../../build/dream-tide-preview.13/viewport-report.json)、[横扫画面帧](../../build/dream-tide-preview.13/render-report.json)。[代码预览](../../build/dream-tide-preview.13/preview.html)仍采用静止的历史战场，不能替代游戏原生CEF、实际倒下和加载衔接的复测。试玩清单见[全屏验收](../playtest-dream-0.29.md)。

安装、离线检查与发布证据见[补丁报告](../../build/dream-tide-0.29-preview.13.json)。

## 两位随机来客

|人物|开始条件|每有效抽取日概率|保底|展示期限|
|---|---|---:|---|---|
|宋暖阳|第16日起、参战6次、有效契约2份、不同合格聚落4座、历史最高3级|35%|连续4次失败，第5次必出|2日|
|溺水小龟|第1日起、进入1座非敌对非军事聚落|25%|连续4次失败，第5次必出|2日|

两人各有一个独立来客位置，不挤占三个常规补员位置，全世界最多同时5名主题候选。位置空闲且资格满足时，每游戏日在合格聚落查看招募最多抽一次；换城、重复打开和当天已保存的结果恢复均不重新抽取。未查看的日期不补抽，候选展示期间不累计保底。

未购买者过期后继续参加抽取；成功展示重置其保底计数，成功雇佣后永久停止生成。缺钱或满员不消耗人物资格，阵亡、永久离队的人不会重生。旧档已在常规位置展示的这两人保留原候选，期限结束后才转入独立随机位置。

两位来客按首次生成时的历史最高等级补级，最高5级，之后固定保存。一级宋暖阳1000、小龟870；五级预算分别1960、1830。实际入队等级低于5时，不收取五级补级费。服务费、装备和日薪没有改动，个人参战次数从真实战斗累计。

# 阿飞远征团 v0.25.1（2026-09-29）

本地修复包：[mod_afeix_expedition v0.25.1.ZIP](<../../dist/mod_afeix_expedition v0.25.1.ZIP>)。本轮未发布 BBMOD，也未替换本机游戏安装包。

## 已学技能仍显示待选择

确认研习会把技能选择写入人物标记，但旧读取函数用 `"getFlags" in actor` 和 `"getLevel" in actor` 检查方法是否存在。原版 `WeakTableRef` 通过 `_get` 转发这些方法，`in` 检查却返回 false，因而把已选技能读成空值，把已学技能等级读成 0。这同时影响名册显示、技能同步、技能生效及 11 级精通。

读取时改为直接调用原版人物方法。保存过的选择会继续使用；若技能曾被错误同步移除，正常读档同步可按已有标记重新补回。没有改动存档结构、三选一规则、等级门槛或奖励，不会自动选择另一个方向。

## 蛤妈离队核查

离线完整流程可达，未复现永久无法触发的问题。本轮保留原有条件：阿飞达到 7 级；阿飞、小酒瓶存活在队；小酒瓶已完成个人成长“这一次球给谁”；在安全的友好非军事城镇附近。

个人成长需要小酒瓶达到 3 级并实际参战 3 次，再完成成长交谈。**7 级专属研习与个人成长是独立选择，学习专属技能不会代替成长剧情。**成长、转职和信件优先于旧车夜话；随机事件有原版调度限制，可进酒馆触发符合条件的下一段交谈。野外安全扎营可以完成成长，但不能开始旧车告别。

已见过但未完成的交谈可从 F8 → 翻看旅途旧事 → 营火旁的交谈继续；若显示旧事分类，先进入“伙伴成长与旧事”。旧车夜话已发现后，从同一目录的“那晚的旧车”继续。选择过继续同行后，不会再次触发离队；选择离队需要另行确认，且行囊须有足够空位收回全部装备。

## 安装

完全退出游戏，将本包放入游戏 `data` 目录，同时移走之前的本 Mod ZIP，只保留一份。重启并读取当前 v0.25.0 存档即可保留技能选择；本轮内部版本为 32，Schema 仍为 8。更早版本沿用已有兼容限制。

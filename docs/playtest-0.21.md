# v0.21.0：战死图层与战团结局

内部 Mod 版本 24，存档 Schema 仍为 8。接续当前工作区的 v0.20.1 玩法及最新人物美术，不需重开战役。

## 战死资源与图层

此前战死回调会清空当前格的尸体图层，再绘制缩小并转动的完整胸像，导致装备与躯干消失。现在死亡期间临时使用原版躯干，让原版创建护甲、附加装备、投射物和伤亡记录，再添加专属头部及实际头盔。不会清掉同格原有尸体、地面效果或掉落物。

36 组外观新增 `_corpse_head` 画刷，图集共 144 个精灵。新画刷复用当前头部像素，以颈部连接点作支点，运行时按倒地姿态叠合；兼容的 `_dead` 资源保留。头像按原版仰倒方向摆放（后脑朝外、下颌朝向躯干），镜像时角度相反；各头部使用已检查的颈部点定位，避免按透明边界中心对位造成头颈错接。没有重绘逐人的闭眼表情。原版装备像素仅用于游戏运行及本地检查，不进入 Mod 安装包。

普通战死、昏迷和复活后再次死亡使用相同身份；昏迷者战后恢复站立形象。斩首、碎颅、吞噬和 Kraken 终结不重新补回完整头部；斩首仍由原版处理掉落头盔等效果，本轮未新增专属断头动画。尸体生成时保留人物身份，覆盖地图尸体与未放置尸体的复活记录。缺少新画刷时回退原版显示。

## 结局

新增 8 种主结局：早期败亡、普通败亡、成名后败亡、传奇退隐、危机后退隐、声名已立、平凡收旗和起步阶段解散。沿用原版退隐／游戏结束入口，以及分数、配图、音乐、成就和铁人模式收尾行为。

34 人均有声名已立、平凡收旗、阵亡纪念三段独立文字，共 102 段；另有 11 段阿飞缺席／路线、六根和自行车回应。按真实在册、死亡和离队状态选择，未招募成员不出场；败亡时仍活着的人不会被写成阵亡。先前留下、后来阵亡的小酒瓶不会在散伙饭上发言，未完成的自行车选择不会被代选。

数据源为 [company-endings.json](../data/company-endings.json)，由 `tools/build_endings.py` 生成运行时数据和[审阅全文](design/company-endings.md)。全部为 Mod 原创虚构剧情，不作为真人经历陈述。

## 验证与安装

完整构建执行 Squirrel 编译、行为测试、JavaScript 检查、原版资源路径检查、图集像素与锚点回读、ZIP CRC 和逐文件源码校验。具体测试数与哈希见[验证报告](../build/gameplay-validation.json)和[包报告](../build/gameplay-package.json)。重点覆盖两种尸体翻转、原版装备保留、同格尸体、资源缺失、死亡异常恢复、昏迷、复活、结局阈值、全员生死离队和其他起源回归。

安装前旧包保存在 `build/corpses-endings-v21/baseline-*/`。更新后完全退出并重启游戏，再读取战役；已经画在进行中战场上的旧尸体不会即时重绘。当前版本尚未实机验收倒地锚点、所有头盔变体、动态翻转和结局滚动排版，也未发布至 BBMOD 或 GitHub。

# v0.16.1｜世界地图 F8 名册修复

日期：2026-09-27；游戏版本：1.5.2.3，原版与官方 DLC。

## 原因与修改

F8 手动打开名册时调用了原版随机事件的 `canFireEvent(true, true)`。两个参数不会跳过附近队伍检查：玩家周围 400 个世界坐标单位内存在非友方实体，就返回 false，导致按键看起来毫无反应。

手动名册现在直接走原版 `fire`、显示和关闭流程。继续阻止战斗、进入战斗、加载、另一个事件以及冲突菜单期间打开；危险地点可以阅读，但确认编队、转职等改变队伍状态的操作仍通过各自的 `canManage` 检查。被其他条件拒绝时写入带原因的日志，便于定位。未改动人物、美术、技能数值或存档格式。

## 验证

- 离线构建通过 17,387 条行为断言，包括新增 20 条执行本机原版事件管理器的回归检查：附近敌方队伍不再阻止阅读、危险地点不能修改编队、不能叠加活动事件、显示失败会清理事件、加载及战斗等状态仍被拦截。
- v0.16 安装包读取第 2 天、三队长的同一 AUTOSAVE，在世界地图按 F8 无反应。完全退出游戏、安装 v0.16.1 并重启，读取同一存档后 F8 成功打开名册，显示同行 3 人、出战 3/10。
- 点击“合上名册，继续上路”，再按 F8 可以重新打开，首页仍显示安全地点管理限制。没有改动出战名单、推进时间或保存覆盖存档。
- 修复包日志无脚本错误，快照见 [游戏日志检查](../build/playtest-facing/f8-v0.16.1.json)。本轮是 F8 定向验收，未重新验证全部技能、城镇名册入口或长期战役流程。

# 梦境开局预览版试玩验收

当前本地版本：`0.29.0-preview.6`，包含梦境入口修复、无奖励剧透的介绍、所有梦境结束路径的剧情杀与斗鱼强度调整。preview.6定向实机记录见[剧情杀与斗鱼测试报告](../build/douyu-balance-0.29-preview.6.json)。下述入口验证执行于preview.4，各报告分别记录具体包指纹与验证范围。preview.6已发布官网，详见[发布记录](releases/publication-0.29.0-preview.6.md)。`0.29.0-preview.3`的历史公开下载与包验证记录保留在文末。目标环境为原版与本项目所需官方DLC、Legacy Modding Script Hooks；其他第三方Mod组合需分别验证。

## 2026-10-03 preview.6剧情杀实机结果

最新包的斗鱼幕验证使用独立开发插件F6定位第四幕，正常撤退通过原版战斗菜单操作；F7只强制斗鱼原生死亡，检查提前击杀的结局；F9只跳过玩家行动，斗鱼按生产AI行动，保留原本三轮限制。幕间略过、菜单撤退、第三轮结束与提前击杀均接入全军覆没的梦醒；后三项各有`REALITY_RESTORED=true roster=3 status=complete`，现实人物的等级、经验、生命、疲劳、全部装备ID与耐久，以及资金、工具、药品、弹药快照一致。剧情杀前原生回合条已清空，三项最新定向测试没有脚本或界面错误。

实际阅读的“黑旗启程”仅介绍招募、组队、11级准备和祭场方位，没有奖励掉落剧透。见[启程截图](../build/douyu-playtest/final/departure-no-spoilers.png)和[提前击杀仍全军覆没](../build/douyu-playtest/final/forced-victory-party-defeat.png)。

完整对战曾在回合开始死亡后停住，日志出现原版回合条查询已移除角色的错误。新增修复后，在最终包上用F12强制下一名梦中角色于自身回合开始死亡，再由F9推进；实机出现`TURNBAR_RECOVER removed=1`，战斗继续并正常梦醒，现实快照一致，未出现脚本或界面错误。F12只用于故障复现，不计入正常对战伤亡。见[死亡后正常梦醒](../build/douyu-playtest/final/turn-start-death-wake.png)。

完整对战另用F10取消梦境时限，十名原始11级传奇配装角色交由原版角色AI行动；斗鱼保持生产属性、技能与AI，命中、AP、疲劳、移动、护甲、伤亡均使用引擎原生结算。回合生命、护甲和实际胜负记录在[实机报告](../build/douyu-balance-0.29-preview.6.json)。这是Boss战斗样本，不是现实战役通关，也没有验证玩家多阵容胜率或所有专属技能的AI使用。强制击杀与完整对战结果分别记录。

4200生命初稿的两场顶配样本均在第十一轮全员存活取胜，因此提升至4800生命、110–135撕咬和700点打断。调整后的样本在第十四轮取胜，只剩五人，总生命371/1075、存活者护甲2049（初始4176）；自然死亡多次触发回合条修复，仍继续正常推进且完整对战区间日志无错误。该样本使用包指纹78596657…，最终包只追加清空回合条时作废旧头像查询的处理，战斗数值、技能、AI和Boss实体经字节比较完全一致；最终包的收尾路径另行实机复测。这是一个完整高损耗胜利样本；不把历史卡死样本计为胜利，不以单场结果保证所有阵容都能取胜。

## 新战役

1. 备份存档，退出游戏后替换主包，确保 `data` 中只有一份阿飞远征团主包。用新建“阿飞远征团”战役验收完整开局。
2. 检查先出现“黑旗未满”的夜营故事与阿飞、大谋头像，继续后同一弹窗改为“三人同梦”，显示斗鱼图与阿飞、抹茶头像；地图应暂停。选进入梦境，人物栏应为刀一十人，全员11级、各自传奇配装与一项精通专属技能。确认可选、移动、攻击，十人都能部署在地图内。
3. 依次通过蜘蛛、恐狼、林德虫。检查每幕均重新恢复十人完整状态；原版林德虫头尾正常运作。
4. 检查斗鱼活体比例、左右朝向、图层遮挡、阴影和技能图标。确认点名和区域红圈提前一回合可见，走位能规避，集中造成700点实际生命与护甲伤害可打断区域蓄力。
5. 第三轮结束应先展示十名临时角色全灭，再醒来。即便提前击杀斗鱼，也要执行相同结局。检查“黑旗初醒”继续翻到“黑旗启程”，道路图配抹茶、阿飞头像，说明找人、招募、自由组队和现实祭场。只剩真实三位队长，等级、装备、资源与开梦前一致；没有梦中传奇装备、死亡、经验或克朗带出。世界时钟没有跳跃，正常行军、招募和F8功能可用。

## 保存与退出

1. 开局两页和幕间分别选择略过梦境，均应先展示全军覆没的“黑旗初醒”，再继续“黑旗启程”；战斗撤离、战斗菜单退出、提前击杀斗鱼与第三轮结束均接入同一剧情杀，临时角色全灭，现实队伍恢复。
2. 梦境中尝试保存，应阻止保存临时状态。读取幕前自动存档应重复当前幕，十人不留在真实队伍或仓库中。
3. 梦醒后正常保存、读档，序章不能重复自动触发。旧战役读取时不自动插入；F8 → 再赴梦潮允许主动回看。
4. 各故事页按Esc应安全关闭、不立刻重弹。F8 → 再赴梦潮继续未读页；第一幕前自动存档读取应回到已阅读的“三人同梦”页，启程页未确认就保存读取应续读该页。窗口动画期间连续按Esc不应损坏菜单层级。
5. 已读启程页后F8回看应只展示背景，不改变队伍、资源、终局胜利和装备掉落标志。旧档有队长离队或阵亡时，仍可阅读，缺少头像的位置保持空白。检查人物界面和城镇酒馆入口，不出现界面重叠或无法取消。

## 终局

1. 新战役和读取旧阿飞战役分别检查大陆只有一个“梦潮祭场”；保存、读档后保持原位置，不重复生成。地点不得在海洋、不可通行地块或已被占用的位置。
2. 在安全地点使用F8 → 再赴梦潮，查看城镇方向情报。点击地图选项应揭示地点、聚焦镜头和暂停；人在城镇中时应先返回地图。人物仍留在原地，需要正常行军抵达并点击祭场接战。
3. 按自己的选择配置队伍，可使用梦中十人之外的角色，最多十二人。测试普通撤退与失败：采用真实伤亡、装备损耗和资源消耗，正常返回世界地图，未击杀Boss时仍能再挑战。
4. 测试胜利：正常结算、尸体显示正确，战利品中应有深渊鲨衣、断潮鱼翅、破浪鲨牙各一件；出现终局文本，祭场消失。再次打开账簿显示已击败，保存读取后不复生、不补发装备。
5. 回看梦境检查零传奇掉落，退出后现实祭场与击杀记录保留。记录高低命中、重轻甲阵容的战斗时长和伤亡，调整Boss数值后再跑相关测试。

## 三件传奇装备

1. 检查库存大图、小图与文字，数值应与[装备设计](design/douyu-world-and-trophies.md)一致；鲨衣460/−26，鱼翅90–120，鲨牙54–62。
2. 给不同角色穿戴鲨衣，检查左右朝向、颈部、头部及手臂遮挡；受损和战死尸体保留正确资源。正常修理、安装附件后保存读取，数值及图像不丢失。
3. 鱼翅检查双手砍刀的砍切、斩首、劈盾、砍刀精通、4AP攻击，以及普通和染血持握图。鲨牙检查单手矛的刺击命中、矛墙、持盾、双握、矛精通，以及普通和染血持握图。
4. 比较技能提示与实际攻击；无其他加成时鱼翅55%穿甲、165%护甲伤害，鲨牙45%穿甲、145%护甲伤害。技能疲劳减免应叠入原版精通流程，保存读取后仍有效。

## 离线检查与打包

运行 `python tools/check_gameplay.py`，读取 `build/gameplay-validation.json` 中的语法、资源、美术、行为测试结果。通过后运行 `python tools/package_verified_gameplay.py`，生成带版本号的ZIP与SHA-256文件，核验CRC、完整条目与源码字节一致。

该检查没有启动游戏，包报告中的 `in_game_tested` 保持 `false`。记录实际试玩结果时应补充游戏版本、启用Mod、重现步骤与日志。

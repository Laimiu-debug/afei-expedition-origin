# 梦境开局预览版试玩验收

版本：`0.29.0-preview.3`。已发布至BBMOD新官网，公开下载与本地包、源码一致，未安装到游戏。目标环境为原版与本项目所需官方DLC、Legacy Modding Script Hooks；未知第三方Mod组合尚未验证。

## 新战役

1. 备份存档，退出游戏后替换主包，确保 `data` 中只有一份阿飞远征团主包。用新建“阿飞远征团”战役验收完整开局。
2. 检查先出现“黑旗未满”的夜营故事与阿飞、大谋头像，继续后同一弹窗改为“三人同梦”，显示斗鱼图与阿飞、抹茶头像；地图应暂停。选进入梦境，人物栏应为刀一十人，全员11级、各自传奇配装与一项精通专属技能。确认可选、移动、攻击，十人都能部署在地图内。
3. 依次通过蜘蛛、恐狼、林德虫。检查每幕均重新恢复十人完整状态；原版林德虫头尾正常运作。
4. 检查斗鱼活体比例、左右朝向、图层遮挡、阴影和技能图标。确认点名和区域红圈提前一回合可见，走位能规避，集中造成160点实际生命与护甲伤害可打断区域蓄力。
5. 第三轮结束应醒来。检查“黑旗初醒”继续翻到“黑旗启程”，道路图配抹茶、阿飞头像，说明找人、招募、自由组队和现实祭场。只剩真实三位队长，等级、装备、资源与开梦前一致；没有梦中传奇装备、死亡、经验或克朗带出。世界时钟没有跳跃，正常行军、招募和F8功能可用。

## 保存与退出

1. 开局两页和幕间分别选择略过梦境，均应在同一事件窗口展示“黑旗启程”；战斗撤离与战斗菜单退出应先醒来，再展示启程介绍。
2. 梦境中尝试保存，应阻止保存临时状态。读取幕前自动存档应重复当前幕，十人不留在真实队伍或仓库中。
3. 梦醒后正常保存、读档，序章不能重复自动触发。旧战役读取时不自动插入；F8 → 再赴梦潮允许主动回看。
4. 各故事页按Esc应安全关闭、不立刻重弹。F8 → 再赴梦潮继续未读页；第一幕前自动存档读取应回到已阅读的“三人同梦”页，启程页未确认就保存读取应续读该页。窗口动画期间连续按Esc不应损坏菜单层级。
5. 已读启程页后F8回看应只展示背景，不改变队伍、资源、终局胜利和装备掉落标志。旧档有队长离队或阵亡时，仍可阅读，缺少头像的位置保持空白。检查人物界面和城镇酒馆入口，不出现界面重叠或无法取消。

## 终局

1. 新战役和读取旧阿飞战役分别检查大陆只有一个“梦潮祭场”；保存、读档后保持原位置，不重复生成。地点不得在海洋、不可通行地块或已被占用的位置。
2. 在安全地点使用F8 → 再赴梦潮，查看城镇方向情报。点击地图选项应揭示地点、聚焦镜头和暂停；人在城镇中时应先返回地图。人物仍留在原地，需要正常行军抵达并点击祭场接战。
3. 按自己的选择配置队伍，可使用梦中十人之外的角色，最多十二人。测试普通撤退与失败：采用真实伤亡、装备损耗和资源消耗，正常返回世界地图，未击杀Boss时仍能再挑战。
4. 测试胜利：正常结算、尸体显示正确，战利品中应有深渊鲨衣、断潮鱼翅、破浪鲨牙各一件；出现终局文本，祭场消失。再次打开账簿显示已击败，保存读取后不复生、不补发装备。
5. 回看梦境检查零传奇掉落，退出后现实祭场与击杀记录保留。记录高低命中、重轻甲阵容的战斗时长和伤亡，调整Boss数值后再跑相关测试。

## 三件传奇装备

1. 检查库存大图、小图与文字，数值应与[装备设计](design/douyu-world-and-trophies.md)一致；鲨衣460/−26，鱼翅90–120，鲨牙54–62。
2. 给不同角色穿戴鲨衣，检查左右朝向、颈部、头部及手臂遮挡；受损和战死尸体保留正确资源。正常修理、安装附件后保存读取，数值及图像不丢失。
3. 鱼翅检查双手砍刀的砍切、斩首、劈盾、砍刀精通、4AP攻击，以及普通和染血持握图。鲨牙检查单手矛的刺击命中、矛墙、持盾、双握、矛精通，以及普通和染血持握图。
4. 比较技能提示与实际攻击；无其他加成时鱼翅55%穿甲、165%护甲伤害，鲨牙45%穿甲、145%护甲伤害。技能疲劳减免应叠入原版精通流程，保存读取后仍有效。

## 离线检查与打包

运行 `python tools/check_gameplay.py`，读取 `build/gameplay-validation.json` 中的语法、资源、美术、行为测试结果。通过后运行 `python tools/package_verified_gameplay.py`，生成带版本号的ZIP与SHA-256文件，核验CRC、完整条目与源码字节一致。

该检查没有启动游戏，包报告中的 `in_game_tested` 保持 `false`。记录实际试玩结果时应补充游戏版本、启用Mod、重现步骤与日志。

2026-10-03本版已通过147个Squirrel文件、45,691条离线行为断言；新增故事原生UI及续页189条，梦境流程223条。324个包文件的CRC、完整条目与源码字节一致。原生故事UI覆盖与包指纹见[教程式序章预览报告](../build/dream-story-0.29-preview.3.json)。原版测试材料只保存在忽略缓存中，可从安装游戏重建，不进入Mod压缩包。前两版报告保存在[梦境预览](../build/dream-opening-0.29-preview.json)与[现实斗鱼预览](../build/douyu-world-0.29-preview.2.json)。

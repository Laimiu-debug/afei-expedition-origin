# 大名单滚动与跨页拖拽修复（2026-09-29）

已并入当前本地 [v0.25.2 安装包](<../dist/mod_afeix_expedition v0.25.2.ZIP>)。滚轮每次移动约半行，可停留在首发和替补之间；拖着人物滚动后，松手按鼠标当前指向的可见格子换位。最多 12 人出战、至少保留 1 人的规则继续生效。

没有滚轮也能全程只用左键：按住人物拖到名单上／下边缘，稍停后自动向上／下滚动；移回名单中间立即停止，在目标格松开左键换位。浏览名单时也可直接用左键拖右侧滚动条，无需按下滚轮中键。

## 原因与复现

此前只给原版名单追加替补格和 `overflow-y: auto`。游戏自带 `jquery.event.drop 2.2` 在开始拖动时缓存格子坐标，滚动后没有更新，第二页替补格因此可能被判成第一页首发格。浏览器使用安装游戏的真实 jQuery、拖拽组件、名单渲染及 `swapSlots`，旧代码明确复现：40 人、10 人出战，将编号 18 的替补拖到编号 27 的替补，实际执行 `18 → 0`，出战人数变成 11。这里的编号从 0 开始。

修复对扩展名单中的人物关闭旧组件落点判定，保留原版拖动显示，在松手时读取最新格子边界与名单可见范围，再调用原版换位和后端位置通知。编号 18 正确换到 27，出战人数保持 10；拖动中经过其他格子不会提前交换。滚轮拦截默认大步滚动，按当前人物行高的一半移动，跟随界面缩放。

边缘自动滚动只在拖动人物时开启，停留 200 毫秒后以小步持续移动，鼠标静止也能继续。移出边缘、松手、窗口失去焦点、名单刷新／隐藏／销毁或离开仓库模式时停止；到最顶端或最底端也会结束定时器。

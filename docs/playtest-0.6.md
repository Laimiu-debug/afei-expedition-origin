# v0.6 战斗朝向修订

本轮把 34 名成员、36 种主体外观统一为朝画面右侧的三分之四胸像：头、胸肩与视线一起转向，保留上一轮脸型、发型及衣装。保持《战场兄弟》的粗暗轮廓、低饱和色和小尺寸手绘块面。敌方沿用原版阵营镜像；尸体沿用原版随机朝向。

源图在 [sources/facing](../art/runtime/portraits-v05/sources/facing/)，实际生成提示词和参考链见 [PROMPTS.md](../art/runtime/portraits-v05/PROMPTS.md)。这些是内置 ImageGen 的编辑结果，导出脚本只做透明裁切、等比缩放和定位。旧原图与 [v0.5 安装包](../dist/archive/v0.5/mod_afeix_expedition.zip)保留。原画刷 ID、图集名称和存档 Schema 4 保持不变。

小月牙、甜筒、美伢、瑶瑶牙仍缺可靠照片：本轮改姿态不能当作补全真人还原。小龟继续采用原创小龟化身。

## 实机环境与修复

本机 Battle Brothers 1.5.2.3、官方 DLC、已有中文包。该中文包内置 Legacy Script Hooks 21.1，未另装重复 Hooks。正式包复制到游戏 data 目录；独立开发测试包仅用于本轮验收，不进入发行 ZIP。

实机启动暴露出离线测试未覆盖的原生继承行为，已增加相应回归检查并修复：

- 挂钩通过 `mods_getMember` 查找继承方法，并以 `mods_override` 替换原定义层。
- 捕获的原生闭包调用前重新绑定实际对象，避免误读父原型的属性。
- 原版独立战斗没有 `World.Assets` 时，起源识别安全返回 false。
- 全员友军朝向、魅惑及解除、飞碟同步、外观更新和存读档的朝向、两种原生尸体朝向都有离线检查。

挂钩用法依据 [Script Hooks 原作者授权镜像的文档](https://github.com/jcsato/modding_script_hooks#modifying-code)。离线测试仅模拟相应接口，不能替代原生引擎结果。

## 实机验收记录

验证正在进行，最终结果与截图将记录在本节。开发场景使用正式渲染方法，临时适配起源和路线读取，以同屏比较三队长、阿飞三种主体、飞碟、女性成员、敌方镜像及原版士兵；不会建立或修改用户战役存档。

## 安装与边界

使用 [mod_afeix_expedition.zip](../dist/mod_afeix_expedition.zip)，不要同时启用旧包或开发测试包。新战役选择“阿飞远征团：完整胸像试玩”；玩法仍见 [v0.3 规则](playtest-0.3.md)。原版装备图层隐藏，装备数值和技能保留；固定立绘不随换装变化。长线招募、平衡与所有存档组合并不因本轮朝向测试而获得完整验收。

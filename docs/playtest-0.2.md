# 阿飞远征团：全员招募试玩 v0.2

历史版本说明。当前版本请看 [v0.3](playtest-0.3.md)，本文保留 v0.2 当时的能力范围。

日期：2026-09-26。环境：PC 原版《战场兄弟》＋官方 DLC、Legacy Modding Script Hooks、可用的中文字体／汉化。

本版完成 34 名成员的起步配置（3 名开局队长、31 名招募伙伴）、分章招募和编队接入。美术暂停，全部使用原版外观、装备与武器技能。**脚本、资源引用及模拟环境检查不代表实机验收；本轮没有安装或启动游戏。**

## 安装与操作

将 [v0.2 归档包](../dist/archive/v0.2/mod_afeix_expedition.zip) 整个放入游戏 `data` 目录，不解压。同名 v0.1 包替换为新版，勿同时放入重命名后的两份代码包。需要 [Legacy Hooks](https://github.com/jcsato/modding_script_hooks)；本机汉化包中已发现对应入口，未更换其内容。

新建战役选择 **“阿飞远征团：全员招募试玩”**，仍只有阿飞、王大谋、午夜抹抹茶三队长开局。世界地图按 **F8** 打开黑旗名册：

1. **查看任务与交付**：在友好城镇附近领信，前往另一座友好城镇交付，每份 180 克朗。完成后可继续领下一封，每封都要重新旅行。
2. **查看伙伴与招募**：按五章查看成员。送信与成功结算且实际收到克朗的普通契约，每份各积累 1 条履约记录。
3. **前往相遇**：章节开放后处理个人小事件。可选择不预付资金的方案，也可支付眼前的费用换取更多招募减免；两种选择的费用与结果分别显示。处理后仍需单独正式邀请，暂缓或没钱不会丢失邀请。
4. **选择出战成员**：从当前队员中选 1～10 人。确认后生效，取消不改阵型；原版人物栏可继续换装、摆站位、安排待命。

## 名册、存档与经济

- **最多 40 人在册，最多 10 人上场**，能同时容纳 34 位主题成员和 6 名普通佣兵；没有预留或锁死某些席位。所有人照常产生原版工资与补给成本，集齐不等于必须同时雇用。
- 编队保留同一个人物、装备、经验和伤势；阿飞也能待命。扩展备用栏支持滚动，39 人待命也有位置。
- 相遇付款和正式雇用是两笔独立交易。每次相遇只能处理一次，优惠不叠加，不直接发送钱；正式雇用失败不再扣钱、不占位置。
- 已入队、阵亡或被辞退的人物不能重复生成；完成相遇但暂未雇用的邀请长期保留。
- v0.1 起源 ID 与既有人物键保持不变，旧首封信若已完成，升级时补记 1 条履约记录，不重发 180 克朗，不重建已有人物。旧装备、经验、伤势及工资优惠保留。**此迁移通过逻辑模拟检查，原生存档仍需备份后实测**；不接管旧归档 Mod 或其他起源的存档。
- 眼子已移出当前制作名单，不再开放新招募。此前 35 人版本存档里已经存在的眼子保留同一实体及原有进度，不强制删除，也仍占用 40 人容量中的一个位置；不会在升级时补发或复制。
- 原有 v0.1 ZIP 已[单独归档](../dist/archive/v0.1/mod_afeix_expedition.zip)。请勿把新版存档当作已经验证可以降级回 v0.1。

## 尚未纳入的内容

34 人本轮完成的是三队长开局与伙伴招募、可上场、可普通升级和换装的成员实现。故事主文档见 [人物故事梗概](design/character-stories.md)：梗概、原创台词和后续成长弧分别记录，写进故事文档不等于支线已经可玩。个人专属主动／被动技能、长线成长支线、阿飞转职、六根飞碟、自行车剧情没有在本轮接入。三位水友代表仍是剧情身份，未纳入 34 人可玩成员范围。

原版人物外观是占位，不是女性队员或未来奇幻种族的定稿。初始资金仍为 1,800 克朗，不发放集齐全员的补贴。十人阵容的敌军平衡与大型名册经济尚待实战。
